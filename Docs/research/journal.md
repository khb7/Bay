## 2. 조사가 실제로 진행된 방식

**요청 → 설명 → "쉽게" → 용어 → 문서화**의 반복이었다.

```
사용자가 논문/주제를 지목
  → 설명
  → 모르는 용어가 나옴 → 용어를 설명 → glossary/terms 에 추가
  → "정리해두자" → papers/params 에 반영
  → 그 과정에서 새 구멍이 드러남 → 다음 주제로
```

**구멍이 대화 중에 드러난 경우가 많았다.**

| 어떻게 드러났나 | 결과 |
|---|---|
| "마르는 건 어느 논문?" | 증발이 그래픽스 공백임을 발견 → E절 |
| "지형은?" | 지형은 독립 영역이 아니라 **이미 있던 것의 결과**였음 |
| "날씨는 프리셋에 없나?" | 축이 두 종류(장소/시간)임을 발견 → params §0 재편 |
| "빗방울 충격 넣고 싶은데 비용은?" | 연속체 극한이 확산 → 패스 하나로 해결 |
| "안전율이 실제 붕괴와 같나?" | **아니다** → 지표/진실 분리 원칙 확립 |

## 3. ★★ 전환점 — 설계를 바꾼 순간들

### ① 목적이 "충실도 우선"으로 명확해진 것

> "이 프로젝트 목적이 시뮬레이션처럼 실제 바다에서 모래성 만드는 것 자체를 구현하는 거라,
> 최대한 시뮬레이션처럼 하고 안 되는 부분들만 타협하고 싶은데"

**이 한마디가 설계를 여러 곳에서 바꿨다.**

| 전 | 후 |
|---|---|
| 모래성을 조건부로 입자화 | **처음부터 끝까지 입자** (전환 자체를 없앰) |
| 안전율로 붕괴를 촉발 | **안전율은 UI 전용.** 물리 되먹임 금지 |
| — | **타협 6가지를 명시적으로 문서화** |
| — | 판단 기준 하나: `if(조건) then 결과`를 쓸 때마다 충실도가 깎인다 |

**그리고 설계가 오히려 단순해졌다** — 조건부 전환, 지표 기반 촉발, 강도 보정을 다 뺄 수 있었다.

### ② 조건부 전환 폐기

원래는 "경사 80° 넘으면 입자화" 같은 조건을 두려 했다. 문제는:
```
(a) 판정이 물리 밖에 있다
(b) 전환 시 [A]와 [B]의 강도 기준이 달라 시각적 팝이 생긴다
```
비용을 계산해보니 **모래성 0.05m³ @ 반지름 5mm = 5만 입자**로 감당 가능했다.
→ **전환을 없애는 게 더 싸고 더 정확했다.**

### ③ "진실 = 시뮬, 지표 = 계기판"

> "안전율 따로 계산하면 실제 모래성 붕괴랑 같은 과정을 거치는 건가?"

**아니다.** 정적이고, 파괴면을 가정하고, 응력 재분배가 없고, 동적 효과가 없다.
→ 지표를 정교하게 만드는 대신 **하이트필드에 하중 전파 패스**를 넣기로 함
(겉에 얹지 말고 안을 채운다). 연쇄 붕괴가 창발한다.

### ④ 게임플레이 = 완전 샌드박스

설계 원칙과 철학이 같다는 게 드러났다.
```
설계 원칙:  창발을 최대화하고 규칙을 최소화한다
샌드박스:   게임이 목표를 주지 않고 플레이어가 만든다
```
그리고 정서적 핵심이 잡혔다 — **"모래성은 없어질 걸 알면서 만드는 것"**,
따라서 **파도가 먹는 장면은 실패가 아니라 클라이맥스**.
→ 렌더링·소리의 우선순위를 이게 정한다.

## 4. ★ 정정 이력 — 틀렸다가 바로잡은 것

**이 절이 이 문서에서 가장 값지다.** 같은 함정에 다시 빠지지 않기 위한 기록.

### ① 논문 읽는 순서를 잘못 잡음
Tampubolon 2017(1번)을 먼저 설명했는데, **Klár 2016(2번)이 그 전제**였다.
→ 이후 papers.md의 "읽는 순서"를 `A2 → A1` 로 명시.

### ② "세립사는 물이 안 스민다" → 틀림
`K ∝ d²` 계산만 보고 그렇게 말했는데, **시간 스케일을 빼먹었다.**
```
세립사 K=5×10⁻⁵ :  swash 5초 → 0.25mm (없는 것)  /  조석 6시간 → 1m 이상
```
**세립사 해변은 오히려 더 젖어 있다** (배수도 느림 + 모세관 상승대 35cm +
지하수면이 조석을 못 따라감). **죽는 건 물이 아니라 동역학이다.**

### ③ "세립사는 잘 안 깎인다" → 반대
Hjulström 곡선에서 **0.1~0.5mm가 지구상에서 가장 깎기 쉬운 물질**이다.
침투/유출(①②③)은 침식의 **엔진이 아니라 변속기** — 양이 아니라 방향을 정한다.
→ glossary "엔진 vs 변속기" 항목이 여기서 나옴.

### ④ 스펙트럼 그림에서 너울/풍파 위치가 뒤바뀜
주파수 축에서 **긴 주기 = 낮은 주파수 = 왼쪽**인데 반대로 그렸다. papers.md G-6c 수정.

### ⑤ "상부 해변이 곱은 건 파도가 골라서" → 원인이 틀림
**바람이 고른 것만 골라 올려서**다(aeolian winnowing). 파도가 아니다.
그리고 해빈면 자체의 입도 패턴은 해변마다 크게 다르다 — 일반화하면 안 된다.

### ⑥ 90°를 물리 한계처럼 적음
`lerp(34°, 90°, W)`의 90°는 **물리 한계가 아니라 하이트필드의 표현 한계**다.
실제 젖은 모래는 오버행·아치·터널이 다 된다.
**점착력이 생기면 "각도 한계"라는 개념 자체가 사라지고 크기 한계가 된다**
(무한사면 해석의 `c` 항에 `h`가 분모로 들어감 — J-3에서 증명).
→ 이 정정이 **[A]/[B] 전환 기준**을 낳았다.

### ⑦ γ를 지역 상수로 쓰려 함
γ는 **"풍파가 얼마나 덜 자랐나"** 이지 지역 상수가 아니다. 게다가 **너울은 JONSWAP으로
표현이 안 된다**(γ를 아무리 키워도 못 좁힘). → **이봉 스펙트럼 + `swellFraction`** 으로.

### ⑧ "안전율로 붕괴를 촉발" → 위험한 제안이었음
§3-③ 참조. 지표가 물리를 대체하면 어긋나는 순간 거짓말이 된다.

### ⑨ Vivace 저자명
`Fratarcangeli, Valentini, Pellacini` 로 적었으나 **Tibaldo**가 맞을 것으로 보임. 확인 필요.

### ⑩ 하이퍼링크 방식
채팅에서 `#앵커` 형식이 안 먹혔다(확장이 `#L숫자`만 해석).
→ 다른 세션에서 **용어 하나 = 파일 하나**(terms/ 156개)로 구조를 바꿔 해결.

## 5. 반복해서 나온 패턴

같은 구조가 다른 이름으로 계속 등장했다.

| 패턴 | 어디서 |
|---|---|
| **클램프** | 소성 리턴 매핑 / 열침식 / PBD 마찰 / 가상 파이프 K보정 |
| **`u³`** | 물의 침식 / 바람의 이동 — 같은 Bagnold 에너지론 |
| **맥놀이** | 파군(세트) / 대조·소조(M2·S2) — 같은 수학 |
| **U자 곡선** | Hjulström(물) / 풍성 최적 입도(바람) — 양 끝이 무게와 점착력 |
| **회전 버리기** | SVD(변형) / 주응력(응력) — 둘 다 등방성 덕 |
| **각도 한계 → 크기 한계** | 점착력이 생기면 개념이 바뀜 (모래성·수직절토·오버행) |
| **통계로 요약** | 입자 충돌음 / 빗방울 충격 / 파랑 스펙트럼 — 개별을 포기하고 분포로 |

## 6. 메타 — 조사에서 배운 것

### ① 새 주제를 팔 때마다 대부분 "이미 갖고 있던 것"이었다

```
지형   →  입도·파랑·조석이 정하는 결과. 새 논문 거의 없음
강수   →  Mei 패스 1이 원래 비를 위한 것이었음
소리   →  구동 파라미터를 전부 이미 계산 중 (특히 ξ가 쇄파음을 가름)
구조   →  입자 시뮬이 이미 만들어냄. 지식은 검증·설계용
```
**수확체감 구간에 들어왔다는 신호.** 물리 조사를 멈춘 근거.

### ② 계층을 내릴수록 공식이 줄고 비용이 는다

```
MPM 2상     운반 공식 없음, 물리에서 나옴    프레임당 수십 초
하이트필드   운반 공식 필요                 실시간
```
**"싼 계층 + 공식"을 고른 것이 하이브리드 결정의 실체다.**
어느 계층에서든 무언가는 공식이다. 공짜로 저절로 되는 계층은 계산이 불가능하다.

### ③ 물리를 정하면 게임 동사가 저절로 나온다

실제 모래조각 기법 9개가 **전부 우리가 이미 모델링한 물리 위에서** 돈다.
**게임 동사를 지어낼 필요가 없었다.**

### ④ 렌더링은 성격이 다르다

```
물리   →  논문을 읽고 이해하면 됨
렌더링 →  읽어도 안 됨. 만들면서 눈으로 맞춰야 함
```
→ 기초(프레넬·미세면·Beer-Lambert)만 먼저 보고 나머지는 프로토타입 이후로.

```

남은 미결:  전부 구현 쪽 — 시간제어 / 날씨조작권한 / 조작방식 /
            저장vs사진 / Niagara vs 커스텀 / F절 서지검증

다음:  프로토타입 4단계 (하이트필드 침식 → W·열침식·하중전파 → 입자 → 경계)
       각 단계에서 물을 것: 이 거동이 창발인가, 내가 규칙으로 적었나
```
