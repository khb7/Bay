# 파라미터 정리 & 지역 프리셋

지금까지 조사에서 나온 **모든 상수를 한 곳에** 모은다.
출처는 [papers.md](papers.md), 용어 정의는 [glossary.md](glossary.md).

> ⚠️ 값들은 **조사 기반 초안**이다. 프로토타입 돌려보고 조정할 것.

## 0. ★★ 축이 두 종류다 — 장소 vs 시간

```
장소 축 (스테이지를 고르면 고정. 플레이 중 안 변함)   → §3
  3a 모래       grainSize, mineral, roundness, sorting
  3b 파랑 기후   swellFraction, swellTp, gamma
  3c 조석       tidalRange, formFactor
  3d 지형       exposure, 프로파일(입도에서 파생)

시간 축 (플레이 중 계속 변함)                        → §4
  4a 날씨       Hs, Tp, dir, 풍속·풍향, 기온, 습도, 일사, 강수, 기압
  4b 시각       태양 고도 → 일사·그림자·기온
  4c 조석 위상   대조/소조 어디쯤, 만조/간조
```

**장소가 무대라면 날씨는 그날의 조건이다.** 그리고 둘은 독립이 아니다 —
```
장소 프리셋  →  날씨의 확률 분포를 정한다  →  매일 그 분포에서 뽑힌다
```
하와이의 `Hs` 분포와 북해의 `Hs` 분포는 다르다. **지역이 날씨를 낳는 구조.**

> §2의 기본값 표에는 둘이 섞여 있다. **어느 축인지는 각 항목에 표시**한다.

## 1. ★ 파생 관계 — 독립 상수는 몇 개 안 된다

**대부분의 값이 서로 묶여 있다.** 이걸 따로 노출하면 물리적으로 모순된 조합이 나온다.

```
┌─ 진짜 입력 (에디터에 노출할 것) ────────────────────────┐
│                                                        │
│  grainSize d ──┬─→ K ∝ d²                투수계수      │
│                ├─→ cohesionMax ∝ 1/d     점착력        │
│                ├─→ capillaryFringe ∝ 1/d 모세관 상승대  │
│                └─→ L_C                   특성 길이      │
│                                                        │
│  광물 mineral ─┬─→ rhoSand               밀도          │
│                ├─→ IOR                   굴절률        │
│                ├─→ dryAlbedo / 색        렌더링        │
│                ├─→ hardness              파쇄 여부      │
│                └─→ thermalAbsorb         증발률 보정    │
│                                                        │
│  원마도 roundness ─→ talusDry            안식각        │
│  분급   sorting   ─→ porosity, K 보정                  │
└────────────────────────────────────────────────────────┘
              ↓
┌─ 2차 파생 ─────────────────────────────────────────────┐
│  K ──┬─→ L = √(2KD / nω)      지하수면 감쇠 길이        │
│      ├─→ infiltrationRate     침투 속도                │
│      └─→ drainRate            배수 속도                │
│                                                        │
│  talusDry + W ─→ talusAngle = lerp(talusDry, 90, W)    │
└────────────────────────────────────────────────────────┘
```

**에디터에 노출할 것은 위 박스의 4개뿐**: `grainSize`, `mineral`, `roundness`, `sorting`.
나머지는 전부 파생시킨다.

### 프리셋별 게임 성격

| | 모래성 짓기 | 마름 압박 | 파도 압박 | 지하수면 동역학 |
|---|---|---|---|---|
| ① 온대 석영 | 보통 | 보통 | 보통 | **잘 보임** |
| ② 열대 조개 | **쉬움** (각짐) | 보통 | 약함 | 잘 보임 |
| ③ 화산 검은모래 | 보통 | **강함** (뜨거움) | 보통 | 잘 보임 |
| ④ 고운모래 완만 | **쉬움** (고움) | **약함** (항상 젖음) | 넓고 약함 | **거의 없음** |
| ⑤ 자갈/조립 | **거의 불가** | **매우 강함** | **강함** | 넓지만 둔함 |

**①이 기본인 이유**: 네 압박(모래성 난이도 / 마름 / 파도 / 지하수면)이 전부 중간이라
어느 하나가 게임을 지배하지 않는다. 나머지는 **변주 스테이지**로 쓸 것.

특히 눈여겨볼 조합:
- **③ 화산**: 검은 모래가 열을 흡수해 증발이 빠름 → **마름 압박이 주 메커니즘인 스테이지**
- **④ 고운모래**: 물 걱정은 없는데 파도가 넓게 밀려옴 → **공간 압박이 주 메커니즘**
- **⑤ 자갈**: 모래성이 거의 안 서고 금방 마름 → **하드모드 / 도전 스테이지**

## 3b. 파랑 기후 프리셋 (모래 프리셋과 **독립**)

모래 프리셋(§3)과 곱해서 조합한다. 예: **③ 제주 검은모래 × 동해 파랑**,
**② 열대 조개 × 태평양 섬 파랑**.

| 프리셋 | `swellFraction` | `swellTp` | 방향 분산 | 성격 |
|---|---|---|---|---|
| **태평양 섬** (하와이) | **0.90** | 16 s | 좁음 | **극적인 세트.** 긴장/이완 리듬이 뚜렷 |
| **외양 노출** (캘리포니아·호주·포르투갈) | 0.70 | 14 s | 중간 | 세트 있되 어수선함도 섞임 |
| **동해** | 0.30 | 11 s | 중간~넓음 | 보통. **가끔 오는 너울이 예외적 위협** |
| **갇힌 바다** (북해·지중해) | 0.05 | — | 넓음 | 계속 어수선. 지속 압박 |
| **내만** (서해·카리브) | 0.00 | — | 넓음 | **파도보다 조석이 지배적** |

> `gamma`는 어느 프리셋에서도 3.3 고정. 지역차는 `swellFraction`이 만든다.
> 근거는 [papers.md G-6c](papers.md).

**게임 성격에 미치는 영향**
```
swellFraction 높음 → 잔잔하다 확 몰려옴 → 리듬을 읽을 수 있음 → 계획·타이밍 게임
swellFraction 낮음 → 계속 어수선함      → 읽을 수 없음       → 지속적 압박·유지보수 게임
```
**같은 `Hs`인데 체감이 완전히 다르다.**

## 3c. 조석 프리셋 (세 번째 독립 축)

프리셋 축이 셋이다. **모래(§3) × 파랑(§3b) × 조석(§3c)** — 서로 독립이라 곱해서 조합한다.

| 프리셋 | `tidalRange` | `formFactor` | RTR* | 성격 |
|---|---|---|---|---|
| **극대조** (서해·펀디만) | **9 m** | <0.25 반일주 | **~18 조석지배** | **조석이 게임을 지배.** 갯벌이 드러남 |
| **대조** (남해·유럽 대서양) | 3 m | ~0.3 반일주 | ~3 경계 | 조석·파랑이 균형 |
| **중조** (캘리포니아) | 1.8 m | ~0.9 혼합 | ~1 파랑지배 | **일조부등이 뚜렷** — 아침/저녁이 다름 |
| **소조** (하와이) | 0.6 m | ~1.2 혼합 | ~0.3 파랑지배 | 조석은 배경, 파도가 주역 |
| **미소조** (동해·지중해) | **0.3 m** | 확인 필요 | **~0.3 파랑지배** | **조석이 거의 무의미** |

\* RTR = `tidalRange / H_b`. 각 프리셋의 대표 파고 기준 대략값.
※ `formFactor` 값은 추정이 섞여 있다. 실제 조위표로 검증 필요.

**리듬이 네 겹으로 쌓인다**
```
12.4 시간   만조·간조                즉각적 압박
24.8 시간   일조부등 (F가 클수록 뚜렷)  하루 계획
14.77 일    대조·소조                ★ 메타 리듬 — 달력을 읽게 만든다
독립        폭풍(파도) 리듬            겹치는 날이 진짜 위기
```

**게임 성격에 미치는 영향**
```
tidalRange 큼 → 물가가 하루에 수십~수백 m 이동 → 위치 선택이 시시각각 무의미해짐
              → "언제 짓는가"가 전부. 시간 압박형

tidalRange 작음 → 물가가 거의 고정 → "어디에 짓는가"가 전부. 공간 판단형
```
**같은 게임인데 조차 하나로 시간 게임 ↔ 공간 게임이 갈린다.**

> 극대조(9m)는 매력적이지만 주의: 물가가 너무 멀리 이동하면 플레이 영역이 통째로 바뀐다.
> **프로토타입은 중조(1.8m) 정도로 시작**하고, 극단은 스테이지 변주로 두는 게 안전하다.

## 3d. 지형 프리셋 (장소 축)

> **지형은 독립적인 조사 영역이 아니었다.** 입도·파랑·조석이 정하는 **결과**다.
> 그래서 새 파라미터가 거의 필요 없다. 근거는 papers.md D/G/H/I절 + Dean (1991).

### 지형은 대부분 파생된다
```
grainSize → 침강속도 w_s → A = 0.067·w_s^0.44 → 수중 프로파일  h = A·x^(2/3)
grainSize → Bascom 관계  → 해빈면(물 위) 경사   1:5(굵음) ~ 1:20(고움)

우리 모래(0.5mm, w_s≈6cm/s) → A ≈ 0.147
   x=10m → h=0.68m   x=50m → h=2.0m   x=100m → h=3.2m
```
**초기 지형을 손으로 조각할 필요가 없다.** 입도 하나에서 나오고, 입도를 바꾸면 따라 바뀐다.
> 물 위(Bascom)와 물 아래(Dean)는 **다른 식**이다. 둘 다 입도에서 나오지만.

### 해변 형태는 숫자 둘이 정한다 (둘 다 이미 계산 중)
```
Ω  = H / (w_s·T)      Wright & Short 1984
RTR = 조차 / H_b       Masselink & Short 1993
```
| Ω | 상태 | 모습 |
|---|---|---|
| <1 | **Reflective** | 가파름, 범 뚜렷, 스텝 뚜렷, 사주 없음 |
| 1~6 | Intermediate | 사주·이안류, 리듬 있는 지형 |
| >6 | **Dissipative** | 완만, 넓음, 사주 여러 줄, 범 약함 |

### 진짜 새 파라미터는 하나뿐 — 노출도
만/곶은 수백 m 규모라 **우리 플레이 영역(수십 m) 밖**이다.
지형으로 만들 게 아니라 계수 하나로 처리한다.
```csharp
float exposure;   // 곶 1.3 / 직선 1.0 / 만 0.6 / 깊은 만 0.4
Hs_local = Hs_offshore * exposure;
```
시각적으로는 배경 메시로 곶을 세우고, 물리는 계수 하나.
**굴절은 플레이 영역 밖에서 일어나는 일이라 충실도 손실이 거의 없다.**

| 프리셋 | `exposure` | 성격 |
|---|---|---|
| 곶 / 돌출부 | **1.3** | 에너지 집중. 침식 우세. 가장 험함 |
| 열린 직선 해변 | **1.0** | 기준 |
| 만 (bay) | 0.6 | 파도가 약함. 짓기 편하고 지루할 수도 |
| 깊은 만 / 포켓 비치 | 0.4 | 거의 잔잔. 조석·마름이 주 압박이 됨 |

### 단면 용어 (papers.md 참조용)
```
 육지                                                            바다
┌─────┬──────┬────────┬──────────┬──────┬──────────┬──────────┐
│ 사구 │ 후빈  │  범    │  해빈면   │ 스텝  │ 사주·트로프│   외해    │
│dune │backsh│ berm   │foreshore │ step │bar/trough│ offshore │
└─────┴──────┴────────┴──────────┴──────┴──────────┴──────────┘
  바람    폭풍때만   여름에 생김  ★모래성  가장굵음  폭풍이 만듦
  저수지            폭풍에 깎임   짓는 곳  (lag)
```
**"범이 있다/없다"가 여름 해빈과 겨울 해빈을 가른다.**

### 우리 스케일(수십 m)에서 관련 있는 것
| | 규모 | |
|---|---|---|
| 단면 프로파일 (Dean) | 전 범위 | ✓ 초기 지형 생성 |
| 해빈면 경사 (Bascom) | 전 범위 | ✓ 이미 파생 중 |
| **beach cusp** | **10~50m** | **✓ 창발 가능. 시각적으로 큼** |
| 범(berm) | 수 m | ✓ 계절/폭풍으로 생겼다 사라짐 |
| 스텝 | 수십 cm | ✓ 이미 입도 필드에 |
| 사주 | 수십~수백 m | △ 화면 밖일 수도 |
| 만/곶 | 수백 m | ✗ `exposure` 계수로 |
| 사취/육계도 | km | ✗ |

### 연안류 — 파향 하나만 넣으면 창발한다
```
uprush   → 파향을 따라 비스듬히 올라감
backwash → 최대경사를 따라 곧게 내려옴
           ↓  톱니 모양으로 모래가 옆으로 이동 (littoral drift)
```
속도장이 방향성을 가지므로 이류가 모래를 옆으로 옮긴다. **별도 구현 불필요.**

## 4. 날씨 (시간 축)

> §3의 장소 프리셋이 **분포**를 정하고, 여기서 매 시점 값이 뽑힌다.

### 4a. 상태 변수

| 변수 | 구동하는 것 | 관련 절 |
|---|---|---|
| `Hs` 유의파고 | 파도 세기, 처오름, 침식 | G |
| `Tp` 첨두 주기 | **처오름 거리에 선형** | G |
| `waveDir` | 굴절, **연안류**, 풍성 fetch | G, H |
| `windSpeed` / `windDir` | 풍성 이동, 증발 가속 | H, E |
| `airTemp` / `humidity` | **증발률** | E |
| `solar` (구름) | 증발률, 조명 | E |
| **`rainRate`** | **모래를 위에서 적심** | ★ 아래 |
| `pressure` | 폭풍해일 (1hPa↓ → 1cm↑) | I-6 |

### ★ 강수(비)

#### ★★ 모래에서는 비가 흘러내리지 않는다 — 계산 하나로 끝나는 결론
```
우리 모래의 투수계수  K = 5×10⁻⁴ m/s = 1.8 m/hr = 1,800 mm/hr

이슬비 0.5 / 보통 2~10 / 호우 10~50 / 폭우 50~100 / 열대 스콜 100~200 mm/hr
세계 기록(1시간) 약 305 mm/hr
```
**가장 극단적인 비도 침투능보다 10배 이상 작다.**
```
→ 마른 모래에서는 어떤 비도 100% 스며든다
→ 표면 유출(runoff)이 사실상 없다
→ 비가 모래성 표면을 씻어 내리지 않는다
```
**진흙·흙과 완전히 다르다.** 흙은 침투능이 수~수십 mm/hr라 금방 넘쳐 물길이 파인다.
게다가 흙에서는 빗방울이 표면을 봉인(surface seal)해 침투능을 더 낮추는데,
**모래는 점토가 없어 봉인이 안 생긴다** — 계속 잘 스며든다.

> **유출이 생기는 예외**: ① 이미 포화된 모래(지하수면 근처·물가) ② **수직면**(모래성 벽 —
> 물이 표면을 타고 내려가 침투할 시간이 짧다) ③ 심하게 다져진 표면.

#### 그래서 비의 진짜 의미 = 침식이 아니라 물 공급
```csharp
// D절 Mei 2007의 패스 1(물 추가)이 원래 비를 위한 것이었다.
// 파도 주입으로 바꿔 썼을 뿐, 비는 원래 용도 그대로.
d += rainRate * dt;
```
```
비 → 과포화(약함) → 배수 → ★ 최적(강함) → 증발 → 마름(약함)
     ↑ 위험          ↑ 골든타임             ↑ 다시 위험
```
**★ 비 온 직후가 모래성 짓기 최적이다.** 실제로도 그렇고, 물리에서 저절로 나온다.
파도·조석과 독립인 **세 번째 리듬**.

**붕괴 모습도 다르다**
```
파도 → 옆에서 깎아냄.   밖에서 안으로
비   → 안에서 물러짐.   아래에서 위로 (주저앉음)
```
비는 위에서 스며 아래로 이동 → 아래쪽 `W`가 먼저 오르고, 아래는 하중도 가장 크다
→ **밑동이 먼저 물러지며 위가 주저앉는다.**

#### ★ 빗방울 충격 (rainsplash) — 확산으로 넣는다

개별 빗방울은 불가능하다.
```
50mm/hr, 100m², 지름 2mm 방울  →  초당 약 330,000 방울
```
**그런데 필요 없다.** 파도와 달리 **언제 어디를 때리는지가 안 중요한 통계적 과정**이라
연속체 극한이 있고, **그 극한이 확산이다.**
```
빗방울 하나 → 알갱이가 무작위 방향으로 조금 튐
수없이 반복 → 무작위 변위의 누적 = 확산
경사가 있으면 → 아래로 조금 더 많이 = 편향

∂b/∂t = D·∇²b − v·∇b
         ↑확산    ↑경사 아래 편향
```
**지어낸 근사가 아니라 지형학의 표준 모델이다** (Culling 1960 이후 모든 지형 진화 모델).

```csharp
// ── [A] 패스 9: rainsplash ─────────────────────
// rainRate == 0 이면 통째로 스킵 → 평상시 비용 0

float dropDia = 0.002f;                        // 대표 빗방울 지름 2mm
float damping = exp(-waterDepth / dropDia);    // ★ 수막이 깊으면 충격이 안 닿음
float bind    = cohesionFactor(W);             // 젖어 뭉치면 덜 튐

float D = Ksplash * rainRate * damping * (1f - bind);

b += D * laplacian(b) * dt;                              // 확산
b -= D * splashBias * dot(gradient(b), downhill) * dt;   // 경사 편향
```

| 항 | 물리적 근거 |
|---|---|
| `∝ rainRate` | 빗방울 운동에너지 총합이 강우강도에 비례 |
| **`exp(−d/dropDia)`** | **수막이 방울 지름 이상이면 충격이 바닥에 안 닿음** (실측된 감쇠) |
| `(1 − bind)` | 젖어 뭉친 모래는 안 튐 |

> **두 번째가 자기 제한 되먹임을 만든다** — 비가 계속 오면 물이 고이고,
> 고이면 splash가 스스로 꺼진다. 실제로 그렇다.

**넣을 가치가 있는 이유 셋**
1. 싸다 — 패스 하나(~5줄), 비 안 오면 비용 0
2. **마른 상부 해변의 유일한 침식원** — 파도도 안 닿고 바람도(우리 입도에선) 잘 안 움직인다.
   비가 없으면 그 구역은 영원히 안 변한다
3. 시각적으로 알아보기 쉽다

#### [B] 입자 계층에서는 splash를 넣지 않는다
[타협 1번](README.md)이 다시 물린다.
```
빗방울이 흔드는 것  →  표면 알갱이 몇 개 (0.5mm 스케일)
우리 입자 하나      →  알갱이 수천 개 (5mm 스케일)     ← 10배 안 맞음
```
그대로 주면 과장되고, 제대로 축소하면 0이라 의미가 없다.
**그리고 모래성에서 비가 하는 일의 99%는 스며드는 것이다** —
splash는 시간당 몇 분의 1mm, 과포화는 몇 분 만에 주저앉힌다.

**단, 시각 효과 하나는 챙긴다** — 비 맞은 모래성은 **모서리가 뭉개진다.**
이것도 확산이므로 한 줄이면 된다.
```csharp
if (isSurfaceParticle && rainRate > 0)
    p.position += smoothRate * rainRate * (localAvgPos - p.position) * dt;
```
무작위 미세 이탈-재퇴적의 통계적 극한이 곧 평활화라 **물리적으로도 정직하다.**

#### 상수
| 상수 | 값 | 비고 |
|---|---|---|
| `rainRate` | 0 ~ 200 mm/hr | 날씨 입력 |
| `dropDia` | **2 mm** | 대표 빗방울 지름 (감쇠 스케일) |
| `Ksplash` | 튜닝 | 확산 계수 |
| `splashBias` | 튜닝 | 경사 편향 강도 |
| `smoothRate` | 튜닝 | [B] 표면 평활화 |

#### 문헌 (개념 확인용. 읽을 필요는 없다)
| | |

### 4b. 시간 구조 — 세 겹

| 주기 | 변하는 것 |
|---|---|
| **하루** | 기온·일사(태양 고도) → **증발률**. 그림자 방향 |

## 5. 구현 노트

### 데이터 구조

```csharp
// UE: UPrimaryDataAsset 또는 DataTable 행으로
struct BeachPreset
{
    // ── 진짜 입력 4개 ─────────────────
    float    grainSize;      // m
    Mineral  mineral;        // enum: Quartz / Carbonate / Basalt / ...
    float    roundness;      // 0 = 각짐, 1 = 둥긂
    float    sorting;        // 0 = 섞임, 1 = 고름

    // ── 나머지는 전부 파생 ────────────
    float K()               => C * grainSize * grainSize;
    float CohesionMax()     => k1 / grainSize;
    float CapillaryFringe() => k2 / grainSize;
    float TalusDry()        => lerp(40f, 30f, roundness);
    float Porosity()        => lerp(0.35f, 0.45f, sorting);
    float RhoSand()         => mineral.Density;
    float IOR()             => mineral.IOR;
    // ...
}
```

**원칙: 파생 가능한 건 절대 따로 노출하지 않는다.**
`grainSize`를 바꿨는데 `K`가 안 따라오면 물리적으로 모순된 상태가 되고,
그 순간부터 조사한 내용이 전부 무의미해진다.

### ★ `grainSize`는 상수가 아니라 필드다 (H-6)

실제 해변은 구역별로 입도가 다르다. 스텝이 가장 굵고(자갈·조개껍질 lag),
후빈/사구가 가장 곱다(바람이 고른 것만 올려서).

```csharp
float d[x][z];   // 하이트필드 채널 하나

// 지형이 옮겨지면 입도도 같이 이류 (기존 s 이류 코드에 채널 하나)
// ★ 바람은 고운 것만 가져간다 — 이 두 줄이 실제 분급 패턴을 만든다
if (windErosion > 0) d += winnowRate * windErosion;   // 남은 것이 굵어짐 (lag)
if (windDeposit > 0) d -= winnowRate * windDeposit;   // 쌓인 것은 곱음
```

**공짜로 따라오는 것 — 아밀링(armoring)**: 바람이 불수록 표면이 굵어지고
`u*t ∝ √d` 가 올라가 스스로 멈춘다. 자연스러운 소강 → 파도가 훑으면 리셋.

**게임 함의**: 고운 모래(모래성에 좋음)는 마른 상부에, 물은 아래에 있다.
**재료와 물이 반대 방향** → "우물 파기"와 엮이는 공간 딜레마.
입도가 경사도 정하므로 위쪽 완만 / 아래쪽 가파름 — 공간감도 달라진다.

### 확장 여지

- **플레이어가 모래를 골라 옮기는 행동** — 좋은 모래를 길어오는 게 자원 관리가 됨
- **플레이어가 모래를 골라 옮기는 행동** — 좋은 모래를 길어오는 게 자원 관리가 됨
- **중광물 줄무늬** — 채널 하나 추가로 파도가 훑고 간 자국 표현 (glossary §8)
- **혼합** — 두 프리셋 사이를 lerp 하면 전이 지대
