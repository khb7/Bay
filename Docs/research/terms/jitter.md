# jitter

> [← 구현 용어집](../glossary-impl.md) › [6. 자원 관리](../glossary-impl.md#6-자원-관리)

값을 의도적으로 조금씩 흔드는 것. **완벽한 규칙성이 만드는 인공적 아티팩트를 깬다.**

```cpp
F[i] = fMin + (fMax-fMin) * (i + Rand01()) / 32;
//                               ^^^^^^^^ 원래 자리엔 상수 0.5(대역 중점)가 들어간다
```

## 왜 필요한가 — 파군이 통째로 반복된다

플레이어가 보는 [파군](wave-group.md)은 성분들의 맥놀이, 즉 주파수 **차이**로 만들어진다.
등간격이면 모든 차이가 `df`의 정수배라 맥놀이가 동시에 위상을 맞춘다.

```
fMin=0.05, fMax=0.25, N=32  →  1/df = 160초마다 똑같은 리듬
```

파도 하나하나가 달라 보여도 "큰 거 세 개 오고 잔잔해지는" 패턴이 2분 40초마다
되풀이되고, **사람은 이걸 놀랄 만큼 잘 알아챈다.**
흔들면 차이들의 공약수가 사라져 반복 주기가 사실상 무한이 된다.

## 규칙

| | |
|---|---|
| **한 번만** | 초기화 시점에 값을 정할 때만. 매 프레임 흔들면 파도가 아니라 노이즈다 |
| **고정 시드** | 난수가 초기 32×2회뿐이라 [시드 하나로 완전히 재현된다](determinism.md) |
| **한 칸 이내** | 자기 [대역](spectral-band.md) 밖으로 나가면 에너지 장부가 깨진다 |

흔드는 것은 **주파수뿐**이다. 진폭은 스펙트럼이 정한 값이라 흔들면 `Hs`가 틀어지고,
위상은 0~2π 균등 난수라 애초에 기준값이 없어 jitter가 아니다.

## 두 번째 jitter — 입자 초기 배치

```
파도 jitter   →  시간축의 규칙성(반복 주기)을 깬다
입자 jitter   →  공간축의 규칙성(격자 대칭)을 깬다
```

입자를 완벽한 격자에 놓으면 실제보다 부자연스럽게 단단하고, 붕괴가 층 단위로
미끄러지는 인공적인 모양이 된다. [안식각](angle-of-repose.md)을 재는 실험이
격자 배열의 각도를 재는 꼴이 되므로, 입자 반경의 몇 % 로 위치를 흔들어 대칭을 깬다.
규칙은 같다 — **한 번, 고정 시드, 간격 이내.**
