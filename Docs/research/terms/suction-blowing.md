# 흡입 / 분출 (suction / blowing)

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

다공성 벽을 통한 수직 흐름이 [경계층](boundary-layer.md)을 바꾸는 고전 효과.
- **흡입 (= 침투)**: 위쪽 빠른 물을 바닥으로 끌어내림 → 속도 프로파일이 벽에 압축됨
  → **δ ↓ → τ ↑ → 더 잘 깎임** (항공기 경계층 흡입이 같은 원리)
- **분출 (= 유출)**: 나오는 물이 프로파일을 벽에서 밀어냄 → **δ ↑ → τ ↓ → 덜 깎임**
  (에어쿠션처럼 흐름이 바닥을 못 붙잡음)
