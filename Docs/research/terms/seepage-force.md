# 침투력 / 유효 중량 (seepage force / effective weight)

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

물이 모래를 통과하며 알갱이에 거는 [항력](drag.md). 방향이 결정적.
- **하향 침투** → 알갱이를 눌러줌 → 무거워짐 → **안정화**
- **상향 유출** → 알갱이를 들어올림 → 가벼워짐 → **불안정화**, 심하면 **액상화**
