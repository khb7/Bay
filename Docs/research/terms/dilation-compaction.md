# ★ 팽창 / 다져짐 (dilation / compaction)

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

**모래 덩어리의 부피 = 알갱이 부피 + 빈틈(공극).**
석영 알갱이 자체는 거의 안 눌리므로, **부피가 변한다 = 빈틈이 변한다.**

```
   다져짐 (σ₁σ₂σ₃ < 1)          팽창 (σ₁σ₂σ₃ > 1)
   ●●●●●●                       ●   ●   ●
   ●●●●●●                        ●  ●  ●
   촘촘히 맞물림                 서로 타고 올라감
   공극률↓ 강도↑ 물 덜 스밈      공극률↑ 강도↓ 물 잘 먹음
```

**부피 변화율 = 행렬식 = 특이값의 곱.** U, V는 회전이라 부피를 안 바꾸므로
`det(F) = det(Σ) = σ₁σ₂σ₃`. 전부 Σ에 들어 있다.
```
σ = (1.5, 1.0, 0.667) → 곱 1.0   한쪽 늘고 한쪽 눌림 = 순수 전단, 부피 그대로
σ = (1.2, 1.1, 1.05)  → 곱 1.39  38% 부풂
σ = (0.9, 0.95, 0.92) → 곱 0.79  21% 다져짐
```
