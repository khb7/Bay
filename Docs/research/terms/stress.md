# 응력 (stress, σ)

> [← 용어집](../glossary.md) › [1. 역학 기초](../glossary.md#1-역학-기초)

재료 내부의 단위면적당 힘 (Pa).

| 종류 | 의미 |
|---|---|
| 인장 (tension) | 당기는 힘. **모래성 벽이 서려면 이걸 버텨야 함** |
| 압축 (compression) | 누르는 힘. 마른 모래도 잘 버팀 |
| 전단 (shear) | 미끄러뜨리는 힘 |
