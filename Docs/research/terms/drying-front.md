# 건조 전선 (drying front)

> [← 용어집](../glossary.md) › [4. 증발 / 건조](../glossary.md#4-증발--건조)

젖은 부분과 마른 부분의 경계. 시간이 지나면 안쪽으로 후퇴한다.
→ **겉은 뽀얗고 부슬거리는데 속은 짙고 단단한** 모래성.
