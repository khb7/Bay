# PBD의 강성 문제와 compliance

> [← 용어집](../glossary.md) › [6. 수치해석 / 시뮬레이션 기법](../glossary.md#6-수치해석--시뮬레이션-기법)

[PBD](pbd.md)는 `k`를 아예 안 쓴다. 대신 매 반복 위반량의 `s`만큼 보정한다.
그런데 n번 반복하면:
```
실효 강성 = 1 − (1−s)ⁿ

s=0.5, 반복 1번  → 0.5        물렁
s=0.5, 반복 5번  → 0.969      꽤 딱딱
s=0.5, 반복 20번 → 0.999999   사실상 강체
```
**같은 s인데 반복 횟수만 바꾸면 다른 재료가 된다.** dt를 바꿔도 마찬가지.
→ 성능 튜닝하려고 반복을 줄였더니 모래가 물처럼 흐물거린다.
(원논문의 `k' = 1−(1−k)^(1/n)` 보정은 반복 의존만 줄일 뿐 dt 의존과 단위 부재는 그대로)

**[XPBD](xpbd.md)의 해결 — 유연도([compliance](compliance.md)) `α = 1/k`**
```
α = 0   → 완전 강체        α 크다 → 물렁
α̃ = α / dt²

Δλ = (−C − α̃·λ) / (∇C·M⁻¹·∇Cᵀ + α̃)
```
`α`는 진짜 물리 단위(m/N)를 갖고, 결과가 **반복 횟수·dt에 무관하게 수렴한다.**
반복을 늘리면 더 정확해질 뿐 재료가 바뀌지 않는다.
