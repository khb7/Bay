# reflective / dissipative 해변

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

- **reflective**: 가파르고 굵은 입자. 침투가 강해 백워시가 약함 → 퇴적 → 더 가팔라짐
- **dissipative**: 완만하고 고운 입자. 침투가 거의 없음 → 파도가 넓게 퍼져 에너지 소산
