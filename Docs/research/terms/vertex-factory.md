# Vertex Factory

> [← 구현 용어집](../glossary-impl.md) › [5. 표현과 렌더링](../glossary-impl.md#5-표현과-렌더링)

**정점 데이터가 셰이더에 어떻게 전달되는지를 기술하는 것.**
C++ 클래스와 `.ush` 셰이더 파일이 짝을 이룬다.

## 왜 필요한가

정점마다 위치·노멀·UV만 있으면 표준 `LocalVertexFactory`로 충분하다.
그런데 **표준 포맷에 없는 값**을 실어 보내려면 커스텀이 필요하다.

이 프로젝트는 정점에 `W`(수분)와 `φ`(공극률)를 실어야 한다 —
그래야 픽셀 셰이더에서 보간된 값으로 **젖은 부분이 그라데이션으로** 보인다.

## 무엇을 만드나

```
C++   FVertexFactory 파생 클래스
      - 정점 스트림 선언 (어떤 버퍼가 어떤 슬롯에)
      - 셰이더 파라미터 바인딩
.ush  셰이더 쪽 인터페이스
      - 정점 입력 구조체
      - VertexFactoryGetWorldPosition() 등 규약 함수 구현
```

## ⚠ UE5에서 문서화가 가장 부실한 영역 중 하나

엔진 소스를 읽어야 한다. 참고할 예제는 엔진 안에 있다.

| 예제 | 위치 |
|---|---|
| `LocalVertexFactory` | 가장 기본. 여기서 시작 |
| `GeometryCacheVertexFactory` | 매 프레임 바뀌는 정점 |
| Niagara 메시 렌더러 | GPU 데이터로 인스턴싱 |

머티리얼 시스템과 함께 쓰면 **셰이더 순열이 폭발**할 수 있다는 점도 주의.

## 이 프로젝트에서

[3단계 경로](../../design/system-design.md)의 3단계에서만 필요하다.
1단계(`UDynamicMeshComponent`)는 표준 포맷을 쓰므로 `W`를 정점 컬러에 실어 우회할 수 있다.
