# 팽창을 시뮬레이션이 읽어야 하는 이유

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

**(a) 팽창하면 약해진다** — 알갱이가 제대로 안 닿아 힘을 전달 못 함.
Klár 2016의 [경화](hardening.md)가 이걸 누적해 [마찰각](friction-angle.md)을 낮춘다.
다시 눌린다고 즉시 회복되면 안 되고, 벌어진 틈이 메워져야 강도가 돌아온다.

**(b) ★ [리턴 매핑](return-mapping.md) Case 2의 판정 조건이 바로 이것** — 로그가 여기서 아름답게 작동한다.
```
ε = ln(Σ)  이므로   tr(ε) = ln σ₁ + ln σ₂ + ln σ₃ = ln(σ₁σ₂σ₃)

∴  tr(ε) > 0  ⟺  σ₁σ₂σ₃ > 1  ⟺  부피 팽창
```
**곱이 합이 된다.** 그래서 "부피 변화"가 그냥 대각합이 되고,
그게 곧 항복 조건 `‖ε_dev‖ + α·tr(ε) ≤ c` 의 체적 성분이다.
→ [SVD](svd.md) → 로그 → 편차/체적 분해 → [항복면](yield-surface.md)이 전부 한 줄로 이어지는 지점.

**(c) 공극률 → 투과율 → 물이 스미는 속도** — φ가 바뀌면 `K`가 바뀐다.
Tampubolon 2017의 "공극률 추적". **물 시스템과 역학 시스템이 만나는 지점.**

**게임 함의**
| 상태 | 결과 |
|---|---|
| 밟아서 **다진** 모래 | 강해짐 + 물 덜 먹음 → **모래성 기초 다지기가 실제 행동이 됨** |
| 파도가 훑고 간 **느슨한** 모래 | 약함 + 물 잘 먹음 → 다시 다져야 함 |
| 밟는 순간 | 발 주변이 하얘짐 → **VFX가 아니라 물리에서 저절로 나옴** |
