# 지하수면 (water table)

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

**정확한 정의: 공극수압이 대기압과 같아지는 면.** ("포화가 시작되는 높이"가 아니다 —
그러면 위쪽 [모세관 상승대](capillary-fringe.md)와 구분이 안 된다.)

```
지하수면 위   →  압력 음수 (빨아들임)  →  구멍으로 안 나옴. 짜면 나옴
지하수면      →  압력 = 대기압
지하수면 아래  →  압력 양수 (밀어냄)   →  구멍으로 스며들어 고인다
```

**땅을 파면**: 마른 모래 → 축축 → 아주 젖음([모세관 상승대](capillary-fringe.md), 우리 모래 기준 약 15cm)
→ **여기서부터 물이 고인다**. 그리고 **그 순간 벽이 무너지기 시작한다** —
과포화라 [강도 곡선](dilation-compaction.md)의 오른쪽으로 넘어가기 때문.
해변에서 판 구멍에 자연스러운 깊이 한계가 있는 이유.

해변에서는 조석에 따라 오르내리고, **평균 해수면보다 높다**
([super-elevation](super-elevation.md)). 육지 쪽으로 갈수록 높아지는 완만한 쐐기 모양.
높은 이유 넷: ① 흐르려면 경사가 필요([Darcy](darcy-law.md)) ② 강수 보충 ③ 조석 비대칭 ④ 파도 [처오름](runup.md).
모래 해변 기준 수십 cm ~ 1m 안팎.
