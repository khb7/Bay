# Darcy의 법칙

> [← 용어집](../glossary.md) › [3. 다공성 매질 / 물의 이동](../glossary.md#3-다공성-매질--물의-이동)

```
유량 ∝ (투과율 k / 점성) × 압력차
```
[항력](drag.md) 계수가 `1/k`에 비례하는 이유. **투과율이 낮으면 항력이 크다 = 물이 잘 못 지나간다.**
항력과 Darcy는 같은 식의 앞뒤.
