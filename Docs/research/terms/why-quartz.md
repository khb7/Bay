# 왜 석영인가

> [← 용어집](../glossary.md) › [8. 모래알 자체](../glossary.md#8-모래알-자체)

암석이 풍화되면 온갖 광물이 나오지만 대부분 화학적으로 분해되거나 물러서 부서진다.
**석영만 살아남는다.**

| 성질 | 석영 SiO₂ |
|---|---|
| 화학적 안정성 | 거의 안 녹고 안 변함 |
| 경도 | **Mohs 7** — 매우 단단 |
| 벽개(쪼개짐) | **없음.** 잘 안 쪼개지고 모서리만 둥글어짐 |
| 지각 내 함량 | 화강암의 20~30% |
| **밀도** | **2.65 g/cm³ → ρs = 2650 kg/m³** |

"최후까지 남는 광물". 나머지가 사라진 자리에 석영만 쌓인 게 모래사장이다.
