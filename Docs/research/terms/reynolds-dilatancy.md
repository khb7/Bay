# Reynolds 팽창 (Reynolds dilatancy)

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

**촘촘히 맞물린 모래를 옆으로 밀면 부피가 늘어난다.** 알갱이가 서로를 타고 넘어가야 하므로.
(Osborne Reynolds, 1885)

```
  밀기 전        미는 중
  ●●●●          ●● ●●
  ●●●●   ──>     ● ● ●    ← 넘어가려면 위로 올라가야 함
  ●●●●          ●● ●●       → 전체 부피가 늘어남
```

**해변에서 보는 현상**: 젖은 모래를 밟으면 발 주변이 순간 하얗게 마른다.
```
밟음 → 전단 → 팽창으로 공극 커짐 → 표면 물이 빈틈으로 빨려 들어감
     → 표면 불포화 → 반들거림이 사라지고 뽀얗게 보임
발 뗌 → 다시 다져짐 → 물이 배어나옴 → 도로 젖어 보임
```
