# 항복면 (yield surface) ★

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

## ⚠ 먼저: 허용 영역은 물리 공간에 있는 게 아니다
```
❌ "모래가 어느 위치까지 갈 수 있다"
✅ "모래 내부의 응력이 어떤 값까지 갈 수 있다"
```
**[응력](stress.md) 공간(stress space)** 이라는 추상 공간. **점 하나 = 응력 상태 하나.**

## 응력 공간의 구조
응력은 3×3 대칭 행렬(성분 6개)이지만 [등방성](isotropy.md)이면 **주응력 3개**면 충분
(회전은 무관 — [SVD](svd.md)에서 회전 버린 것과 같은 논리). 그래서 **3차원 공간** `(σ₁,σ₂,σ₃)`.

```
     σ₃
      │      ╱ 정수압 축 (σ₁=σ₂=σ₃)
      │    ╱    사방에서 똑같이 누름 = 부피만 변하고 모양은 그대로
      │  ╱
      │╱______ σ₂
     ╱
   σ₁
```
- **정수압 축(대각선)** = 체적 성분 `tr(σ)`
- **그 축에 수직인 편차 평면** = 모양 성분 `‖s‖`

**어떤 응력 상태든 이 둘로 분해된다** — [편차/체적 분해](deviatoric-volumetric.md)의 기하학적 정체가 이것.
축 방향이냐 평면 방향이냐일 뿐.

## 항복면 = 이 공간을 두 영역으로 가르는 경계
```
안쪽 → 탄성. 힘 빼면 되돌아옴
경계 → 항복 시작
바깥 → 존재할 수 없음
```
**"바깥은 존재할 수 없다"가 핵심.** 응력이 밖으로 나가는 게 아니라,
**나가려는 순간 재료가 찌그러져 안으로 되돌아온다.** 그 찌그러진 만큼이 영구 [변형](strain.md).
3D 공간에서 영역의 경계는 2D 면이므로 "항복**면**".

## ★ 모양이 곧 재료 — 자오면 단면으로 비교
```
  ‖s‖ (편차 = 모양 변형)
    ↑
    │                    ╱  Drucker-Prager (모래) — 원뿔
    │                  ╱
    │────────────────────────  von Mises (금속) — 원기둥
    │              ╱
  ──◆──────────────────────────→ 정수압 (압축 →)
   꼭짓점
```

**금속 = 원기둥 (압력과 무관)**
원자 결합으로 버티고, 소성은 결정면 미끄러짐(전위 이동)이라 **전단만이 문제**.
사방에서 누르는 건 결합 거리만 줄일 뿐 = 탄성. → 축 방향으로 무한한 원기둥.

**모래 = 원뿔 (마찰로만 버팀)**
```
마찰력 = μ × 수직항력      수직항력이 없으면 마찰도 0
```
누를수록 버틸 전단이 비례해 커짐 → 선형 → **원뿔**. 기울기가 [마찰각](friction-angle.md).
인장 쪽으로 가면 반지름이 0이 되어 **꼭짓점에서 닫힌다** —
당기면 알갱이가 안 닿고, 안 닿으면 마찰이 없고, 마찰이 없으면 아무것도 못 버틴다.

| 항복면 | 모양 | 재료 |
|---|---|---|
| von Mises | 원기둥 | 금속 |
| Tresca | 육각기둥 | 금속 (보수적) |
| **[Drucker-Prager](drucker-prager.md)** | **원뿔** | **모래, 흙** |
| Mohr-Coulomb | 육각뿔 | 흙 (원뿔의 각진 버전) |
| Cam-Clay | **닫힌 물방울** | 점토 — **너무 눌러도 항복(압밀)한다** |

> Cam-Clay는 오른쪽이 닫혀 있다. 점토는 지나치게 누르면 공극이 무너지며 소성 변형한다.
> 모래(원뿔)는 오른쪽이 열려 있어 아무리 눌러도 안 항복한다.

## 우리가 그려온 2D 그림의 정체
`전단응력 ↑ / 압축 →` 그림은 **3D 원뿔을 축을 포함하는 평면으로 세로로 자른 단면**(자오면).
원뿔을 세로로 자르면 V자가 나오고 그 위쪽 절반만 그린 것.

**축을 따라 내려다보면(편차 평면)** 다르게 보인다:
```
 Drucker-Prager     Mohr-Coulomb
     ╭───╮            ╱‾‾‾╲
    │  ·  │          │  ·  │
     ╰───╯            ╲___╱
      원               육각형
```
von Mises도 여기선 원이다. **차이(반지름이 축 위치에 의존하는가)는 자오면에서만 보인다.**

## 리턴 매핑이 왜 하필 3분기인가 — 원뿔의 기하학
```
       ╱ 옆면
     ╱
   ╱      ← ① 여기 밖의 점: 옆면으로 수직 투영
  ◆ 꼭짓점
  ┊╲
  ┊  ╲    ← ② 이 뒤쪽(인장 방향) 점: 가장 가까운 점이 꼭짓점 자체
```
**뾰족한 점이 있으면 투영이 그 점으로 모이는 영역이 반드시 생긴다.** 기하학적 필연.

| | 조건 | 처리 | 물리적 의미 |
|---|---|---|---|
| Case 1 | 원뿔 안 | 아무것도 안 함 | 탄성. 형태 유지 |
| Case 2 | 꼭짓점 뒤 (부피 팽창) | 탄성 변형 **전부 0** | 알갱이가 놓아버림. 흩날림 |
| Case 3 | 옆면 밖 | 옆면으로 수직 투영 | 경사면을 따라 흘러내림 |

→ **Case 2가 "전부 0"인 이유**: 꼭짓점이 원점이면 꼭짓점으로 투영 = 응력을 0으로 만드는 것.

## 흐름 법칙 (flow rule) — 투영 방향은 물리가 정한다
- **연관(associated)**: 항복면에 **수직** 투영. 수학적으로 깔끔
- **비연관(non-associated)**: 다른 방향

**모래는 실제로 비연관이다.** 연관 흐름을 쓰면 **팽창을 과대예측한다**
(실측 팽창각 < 마찰각). Klár 2016은 로그 변형 공간에서 수직 투영을 쓰고,
그로 인한 부피 문제를 **[경화](hardening.md) 변수로 보정**한다.

## 경화/연화 = 항복면 자체가 움직인다
```
① 팽창 누적 → 마찰각 감소 → 원뿔이 완만해짐 → 면이 작아짐 (연화)  [Klár 2016]
② 수분 증가 → 점착력 c 증가 → 꼭짓점이 인장 쪽으로 평행이동     [Tampubolon 2017]

   마른 모래              젖은 모래
      ╱                      ╱
    ╱                      ╱
  ◆────────→          ◆──────────→
  원점               ←c─┘
```
**우리 프로젝트에서 `W`가 하는 일이 정확히 ②다 — 항복면을 왼쪽으로 미는 것.**

## 하이트필드에서는
우리는 응력 공간을 다루지 않는다. **[안식각](angle-of-repose.md) 하나로 압축했다.**
```
응력 공간의 원뿔  →  실공간의 경사각
     기울기 α     →     tan(talusAngle)
     점착력 c     →     talusAngle을 90°까지 끌어올림
```
이웃 셀 경사가 안식각을 넘으면 모래를 옮기는 [열침식](thermal-erosion.md)이
**원뿔 밖으로 나간 걸 안으로 되돌리는 [리턴 매핑](return-mapping.md)의 [하이트필드](heightfield.md) 버전.** 구조가 같다.
