# 바닥 전단응력 (bed shear stress, τ)

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

모래 알갱이를 실제로 끌고 가는 힘.
```
τ = μ · (du/dy)|바닥  ≈  μ · U / δ        →  τ ∝ 1/δ
```
**핵심: 모래를 움직이는 건 물의 속도가 아니라 바닥 근처에서 속도가 얼마나 급격히 바뀌는가다.**
같은 속도라도 [경계층](boundary-layer.md)이 얇으면 더 세게 긁힌다.
