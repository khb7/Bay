# Iribarren 수 (surf similarity parameter, ξ)

> [← 용어집](../glossary.md) › [7. 파도](../glossary.md#7-파도)

`ξ = tanβ / √(H/L₀)` — 쇄파 유형을 가른다.

| ξ | 유형 | 모습 |
|---|---|---|
| < 0.5 | spilling | 거품 내며 서서히 무너짐 (완만·세립사) |
| 0.5~3.3 | **plunging** | 말려서 통째로 꽂힘. 가장 격렬 |
| > 3.3 | surging | 안 부서지고 그대로 밀고 올라옴 (급경사·조립사) |
