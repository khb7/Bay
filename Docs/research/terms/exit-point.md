# exit point

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

[지하수면](water-table.md)이 해변 표면과 만나는 지점. 해변을 둘로 가른다.
```
        ┌── 상부: 불포화. 스며듦(influent) → 퇴적
 exit ──┤
        └── 하부: 포화. 배어나옴(effluent) → 침식
```
