인접한 두 셀이 파이프로 연결됐다고 보는 [하이트필드](heightfield.md) 물 흐름 모델. (Mei 2007)
```csharp
f += dt * A * g * dh / l;   // "=" 가 아니라 "+=" → 흐름에 관성이 있다
```
**관성이 있어서 확산이 아니라 넘실거린다 → 파도가 표현된다.**

---

## 구현 관점 (UE5 / Niagara)

인접한 두 셀이 파이프로 연결됐다고 보고, 수면 높이차를 압력으로 삼아 유량을 갱신하는 방식.
```
f += dt · A · g · Δh / l     // "=" 가 아니라 "+=" → 흐름에 관성이 있다
```
관성이 있어서 물이 퍼지는 게 아니라 **넘실거린다**. 파도와 backwash 충돌이 여기서 공짜로 나온다.
