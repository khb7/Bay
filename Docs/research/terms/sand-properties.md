# 시뮬레이션에 들어가는 물성 4가지

> [← 용어집](../glossary.md) › [8. 모래알 자체](../glossary.md#8-모래알-자체)

**① 밀도** — [유효 중량](seepage-force.md), [Shields](shields-parameter.md), [침강속도](settling-velocity.md)의 기준
```
수중 유효 밀도 = 2650 − 1000 = 1650 kg/m³
```

**② 경도** — Mohs 7이라 파도에 안 부서진다.
→ **[팽창/다져짐](dilation-compaction.md)이 성립하는 전제**
(부피 변화 = 알갱이가 눌리는 게 아니라 빈틈이 변하는 것).
탄산염 모래(Mohs 3)는 실제로 부서지면서 점점 고와진다.

**③ ★ 형상(원마도)** — 모래성 강도를 결정
```
   각진 알갱이            둥근 알갱이
   ◣◤◥◢                  ●●●●
   ◥◢◣◤  서로 맞물림      ●●●●   잘 구름
   마찰각 높음            마찰각 낮음
```
| 형상 | [안식각](angle-of-repose.md) | 모래성 |
|---|---|---|
| 아주 각짐 (분쇄) | 40°+ | 아주 잘 뭉침 |
| 각짐 (강모래, 석산) | 35~40° | 잘 뭉침 |
| 중간 | **~34°** ← 우리 값 | 보통 |
| 둥긂 (오래된 해변 모래) | 30~32° | 잘 무너짐 |

**해변 모래는 파도에 수만 년 굴러서 둥글다.** 모래성에 불리.
→ 모래성 대회 선수들이 강모래·석산 모래를 쓰는 이유 = **고운 입도 + 각진 형상**, 둘 다.

**④ 분급(sorting)** — 공극률과 투수성
```
잘 분급됨 (크기 고름)      나쁘게 분급됨 (섞임)
 ●  ●  ●                   ● ·● ·●    작은 알갱이가 빈틈을 채움
●  ●  ●                   ·● ·●· ●
 공극률 0.35~0.45           공극률 낮음, 투수성 낮음, 더 단단히 다져짐
```
**해변 모래는 파도가 계속 체질을 해서 매우 잘 분급돼 있다.**
→ **우리의 "균일 입도" 가정이 물리적으로 방어되는 이유. 해변이라서 그렇다.**
