# 처오름 (runup, R) ★

> [← 용어집](../glossary.md) › [7. 파도](../glossary.md#7-파도)

파도가 부서진 뒤 물이 해변을 올라오는 높이. Hunt 공식:
```
수직 R = tanβ · √(H₀·L₀)
수평 X = √(H₀·L₀) ≈ 1.25 · √H₀ · T      ← 경사가 상쇄된다
```
**파고는 제곱근으로, 주기는 그대로.** 1m/14s 너울(17.5m)이 2m/6s [풍파](wind-sea-vs-swell.md)(10.6m)보다 멀리 온다.
→ **모래성 안전선.**
