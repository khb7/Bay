# 구조 이방성 / 조직 (fabric anisotropy) ★

> [← 용어집](../glossary.md) › [1. 역학 기초](../glossary.md#1-역학-기초)

**지금 이 순간 접촉이 어느 방향으로 쏠려 있는가.**

[등방성 (isotropy)](isotropy.md)이 **재료의 물성**을 말한다면 이건 **충전 구조의 상태**다.
같은 단어를 쓰지만 층위가 다르므로 구분해서 볼 것.

```
나무의 이방성    재료에 새겨져 있다. 안 변한다.              ← 물성
모래의 이방성    지금 어떻게 눌리고 있느냐로 정해진다.        ← 상태
                 힘을 빼면 사라지고, 하중 방향을 바꾸면 따라 돈다
```

모래알 하나하나는 방향성이 없다. **그런데 쌓인 모양(fabric)은 방향성을 갖는다.**

## 보는 법 — 장미 그림

접촉을 방향별로 세어 그린다.

```
     등방 (a = 0)                  이방 (a ≈ 0.4)

         ·  ·  ·                        ·
      ·   ╱│╲   ·                    ·  │  ·
      ·  ─ ● ─  ·                    ── ● ──          위아래로 눌린 상태
      ·   ╲│╱   ·                    ·  │  ·
         ·  ·  ·                        ·

   모든 방향에 고르게                누르는 방향에 몰려 있다
   → 원                             → 땅콩 모양
```

`a` 는 **이 그림이 원에서 얼마나 찌그러졌는지**를 나타내는 숫자 하나다.

```
a = 0      완전한 원 = 등방
a ≈ 0.4    전단받는 모래의 전형값
a = 1      한 방향으로만 접촉이 있음 (극단)
```

## 셋으로 나뉜다

쏠릴 수 있는 것이 세 가지다.

| | 무엇이 쏠리나 | 질문 |
|---|---|---|
| `a_c` | 접촉의 **개수** | 어느 방향에 **많이** 붙어 있나 |
| `a_n` | **수직력**의 크기 | 어느 방향 접촉이 **더 세게** 미나 |
| `a_t` | **접선력**의 크기 | 어느 방향에서 **마찰이 더** 걸리나 |

개수는 같은데 힘만 몰릴 수도 있으므로 `a_c` 와 `a_n` 은 별개다.

## ★ 이게 곧 전단강도다 — 응력-힘-조직 관계 (SFF)

**전단 = 한 축으로 누르면서 직교 축으로 벌리는 것.** 버티려면 누르는 축으로 힘을 전달할
접촉이 있어야 하고, 그게 곧 `a` 가 크다는 뜻이다.

**목표는 하나다: 알갱이에 걸린 힘 → 재료 전체의 응력.**

### ① 응력은 결국 "면을 가로지르는 힘의 합"

[응력](stress.md)의 정의로 돌아간다. 덩어리 속에 가상의 평면을 긋는다.
이 면 위로 무엇이 힘을 전달하나? **면을 가로지르는 접촉들뿐이다.**

```
        ┄┄┄┄┄┄┄┄┄┄┄┄┄┄            1
   ●━━━●   ●     ●━━━●   σ_ij =  ───  Σ   ℓ_i · f_j        Love-Weber
     ●   ●━━━●     ●              V   접촉
        ┄┄┄┄┄┄┄┄┄┄┄┄┄┄
```

`ℓ` 이 왜 필요한가 — 힘만 더하면 방향 정보가 없다. `ℓ ⊗ f` 로 써야
**"어느 방향에 놓인 접촉이 어느 방향으로 힘을 내는가"** 가 한 덩어리로 들어간다.
정적 평형에서 이건 근사가 아니라 **항등식**이다. 여기까진 물리가 아니라 회계.

### ② 항이 수만 개다 → 방향별로 묶는다

20만 입자면 접촉이 60만 개다. 그대로는 아무것도 안 보인다.

```
합                    →              적분

Σ (접촉 60만 개)          n_b · ∫ P(n) · ⟨ℓ·f⟩(n) dΩ
                          ↑      ↑        ↑
                    결합 밀도  그 방향에  그 방향 접촉들의
                    (개/부피)  몇 %가 있나   평균 힘
```

**정보를 버린 게 아니라 정리만 했다.** `P(n)` 이 위의 장미 그림이다.

### ③ 장미 그림을 숫자 하나로 — 여기가 핵심

`P(n)` 은 여전히 함수다. 이걸 **"원 + 찌그러짐"** 으로 쪼갠다.

```
   실제 분포        =        원          +       찌그러짐

      ·                    ·  ·  ·                 ·
   ·  │  ·               ·       ·              ·     ·
   ── ● ──        =      ·   ●   ·        +     ─  ●  ─
   ·  │  ·               ·       ·              ·     ·
      ·                    ·  ·  ·                 ·

                        크기가 얼마         어느 방향으로 얼마나
                          (등방)              (이방 = a)
```

```
P(θ)      = (1/4π)·[ 1 + a_c · (3cos²θ − 1)/2 ]     접촉 방향
⟨f_n⟩(θ)  =    f₀ ·[ 1 + a_n · (3cos²θ − 1)/2 ]     수직력
⟨f_t⟩(θ)  =    f₀ ·      a_t · sin 2θ                접선력
                          ↑
              모양은 고정된 함수. 자유도는 진폭 a 하나뿐
```

> **접선력에만 `1 +` 이 없는 이유**: 마찰은 방향이 뒤집히면 부호도 뒤집혀 전 방향 평균이 0이다.
> **접선력은 오로지 쏠림으로만 존재한다.**

이 단계에서 **접촉 60만 개가 숫자 5개**(`n_b`, `f₀`, `a_c`, `a_n`, `a_t`)가 된다.

### ④ 적분하면 두 줄

①에 ③을 넣고 전 방향으로 적분한다.

```
   압력 (크기)    p   = (1/3) · n_b · ℓ · f₀
   전단 (모양)    q/p = (2/5) · (a_c + a_n + a_t)      ← 3D.  2D면 1/2
```

**`p` 에 `a` 가 없는 이유** — `(3cos²θ−1)/2` 는 전 방향 적분이 정확히 0이다.
한쪽으로 몰린 만큼 다른 쪽이 빈다. **이방성은 평균이 아니라 편차에만 기여한다.**

**`2/5` 는 물리가 아니라 구면 적분의 기하**다 (2D 원에서 하면 `1/2`). 재료와 무관한 상수.

### ⑤ 그래서 무슨 말인가

```
 sin φ  ≈  q/p  =  (2/5)(a_c + a_n + a_t)
   ↑
 마찰각
```

알갱이 표면의 마찰계수 `μ` 는 `a_t` 의 **상한만** 정하고, 실제 값은 구조가 정한다.

**등방이면 `a = 0` 이고 전단저항이 0이다. 그게 물이다** — 방향을 안 가리므로 밀면 흐른다.
**모래가 안 흐르는 이유가 곧 쏠릴 수 있기 때문**이고,
[마찰각](friction-angle.md)은 재료 상수가 아니라 **구조의 쏠림이 만드는 결과**다.

> 그래서 [안식각](angle-of-repose.md)을 `μ` 하나로 못 맞춘다 — 최종 각도는 마찰계수만이 아니라
> **입자 배열이 얼마나 쏠릴 수 있는가**가 같이 정한다. M0 3-0이 스윕으로 답을 찾는 이유.

| 문헌 | |
|---|---|
| Satake (1982) | 조직 텐서(fabric tensor) 개념 |
| **Rothenburg & Bathurst (1989), Géotechnique 39** | SFF 관계의 원전 (2D) |
| Ouadfel & Rothenburg (2001), Mechanics of Materials 33 | 3D 확장. 위의 `2/5` |
| **Radjaï, Wolf, Jean, Moreau (1998), PRL 80, 61** | 강한/약한 힘사슬 — `a_n` 이 왜 생기는지 |

## 젖으면 이방성이 **둘**이 된다

```
              마른 모래              젖은 모래

  누르는 축    접촉 정렬 → 밀어냄     접촉 정렬 → 밀어냄        ← 둘 다
  벌어지는 축  접촉 끊김 → 없음       ★ 물다리가 남음 → 붙잡음   ← 젖은 것만
```

마른 모래는 **미는 것만** 한다. 젖은 모래는 반대쪽에서 **당겨서도** 버틴다.
둘이 같은 변형에 동시에 저항하므로 강도가 단순 합보다 크게 나온다.

**Radjaï & Richefeu (2009)** 의 기여가 이 두 번째 항의 정량화이고,
[papers.md §B-S2](../papers.md)의 Rumpf 가 놓친 것도 이것이다 —
결합이 등방으로 흩어져 있다고 가정하면 **당기는 쪽의 정렬이 통째로 사라진다.**

## ⚠ 우리 프로젝트 — "전부 등방성 가정"과 모순 아닌가

층위가 다르다.

| 계층 | 이방성을 어떻게 다루나 |
|---|---|
| 격자 ([Drucker-Prager](drucker-prager.md)) | **등방 가정.** 원뿔 하나 + 꼭짓점 이동 `c`. 이방성은 안 쓴다 |
| **입자 ([XPBD](xpbd.md))** | **모델링하지 않지만 결과로 갖는다.** 접촉·결합이 실제로 방향별로 다르게 생기고 끊긴다 |

**입자 계층은 코드에 안 적어도 이방성을 저절로 갖는다.** 알갱이를 실제로 놓고 미는 시뮬이니
쏠림이 생길 수밖에 없다. 그래서 [다지기](tamping-vs-stomping.md)로 강해지는 것,
형틀에서 뺀 성이 단단한 것이 **별도 규칙 없이 창발할 자격이 있다.**

> ⚠ **단 `a_t` 는 우리에게 거의 없다.** 접선력 이방성은 알갱이가 회전할 수 있어야 제대로 쌓이는데
> 우리 입자는 **회전 자유도가 없다.** 셋 중 하나가 빠진 채 도는 셈이고, 그만큼 강도를 과소평가한다.
> ([papers.md A-R3](../papers.md) 의 "구름이 불가능하니 논의 밖" 과 같은 뿌리)
