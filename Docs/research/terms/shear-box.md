# 전단 상자 (direct shear box)

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

**덩어리를 강제로 잘라보고 얼마나 버티는지 재는 시험.** 지반공학의 가장 기본 장비다.

[안식각](angle-of-repose.md)이 각도 **하나**를 주는 데 비해 전단 상자는 **응력을 직접 읽고 출력이 넷**이다.
[캘리브레이션](dem-calibration.md) ①(모호성)의 실질적 해법이 여기 있다.

---

## 장치

상자를 **위아래 두 짝으로 쪼개놓고**, 뚜껑으로 수직응력 `σ` 를 누른 채 아래짝을 옆으로 민다.

```
        ↓↓↓↓ σ   수직응력 — 뚜껑으로 일정하게
   ┌─────────────┐
   │ ▒▒▒▒▒▒▒▒▒▒▒ │   윗짝 — 고정
   ├─────────────┤   ← 전단면이 여기로 강제된다
   │ ▒▒▒▒▒▒▒▒▒▒▒ │   아랫짝 — 일정 속도로 →
   └─────────────┘
         →  τ 를 기록
```

절차는 **다짐 → 예비전단 → 전단** 3단계. `σ` 를 3~4개 값으로 바꿔 반복한다.

## 출력 넷 — 여기가 핵심

```
τ
│        ╱ 기울기 = tan φ          τ = c + σ·tan φ     (Mohr-Coulomb)
│      ╱
│    ╱
│  ╱
├╱ ← 절편 = c                      무점착이면 c = 0
└──────────────── σ
```

| 출력 | 어떻게 나오나 | 우리에게 |
|---|---|---|
| **첨두 마찰각 `φ_peak`** | τ-σ 직선의 기울기 (최대 τ 기준) | [마찰각](friction-angle.md) — `μ` 교정의 두 번째 자 |
| **잔류 마찰각 `φ_cv`** | 계속 밀어 τ 가 평평해진 뒤의 기울기 | [임계상태](critical-state.md)를 **직접** 준다 |
| **점착력 `c` [Pa]** | 직선의 세로 절편 | ★ [B-S3](../papers.md) 이 원하는 바로 그 값 |
| **다일레이턴시 각 `ψ`** | 미는 동안 **뚜껑이 뜨는 높이** ÷ 수평 변위 | [팽창/다져짐](dilation-compaction.md) · [Reynolds 팽창](reynolds-dilatancy.md) 검증 |

**`c` 를 직접 읽는 게 크다.** [B-S3](../papers.md) 은 지금 벽 붕괴 높이 `H_c` 에서 Terzaghi 식으로
`c` 를 **역산**하는 구조인데, 그 식이 `φ` 를 이미 알아야 성립한다.
전단 상자는 `c` 와 `φ` 를 **한 그림에서 동시에** 준다 — 역산 경로가 하나 줄어든다.

첨두와 잔류가 **둘 다** 나오는 것도 그냥 얻는 게 아니다.
[순차 파단](progressive-failure.md)(Skempton)이 "첨두가 아니라 잔류로 무너진다"고 한 그 두 값이다.

## 왜 3-0 의 두 번째 실험인가

### ① 준정적을 "바라는" 게 아니라 **설계한다**

[A-R6](../papers.md) 에서 기울기 속도 1°/s 와 4°/s 가 11° 차이를 냈다.
전단 상자는 **전단율 `γ̇` 가 입력**이라 [관성수](rheology.md)를 직접 맞출 수 있다.

```
σ = 4,000 Pa · ρ = 2650 · d = 5cm   →   √(P/ρ) = 1.23 m/s
I ≤ 10⁻³   →   γ̇ ≤ 0.025 /s
전단대 60cm 기준                    →   뚜껑 속도 ≤ 1.5 cm/s
10cm 밀기 = 6.7초 = 400 프레임
```

**400 프레임이다.** 부어 쌓기가 입자를 한 알씩 떨어뜨려 더미를 키우는 것과 비교하면 훨씬 짧고,
이것이 Roessler & Katterfeld (2018) 의 *"시험 시간이 더 짧다"* 의 실체다.

### ② 자유표면 사태가 없다

[3-0-D 원통 인상](../../design/m0-spike.md)이 실패한 구조 — *"밑동이 풀리면 위 전체가 지지를 잃는다"* —
가 여기선 생기지 않는다. **파괴가 국소적이도록 상자가 강제**한다.

### ③ 업스케일 입자에서 크기 불변이다

**Roessler & Katterfeld (2018)** 이 비교한 결과: 원통 인상 안식각은 **느린 인상 속도에서만** 입경 불변,
**전단 상자는 불변이면서 더 짧다.** 우리 입자는 실물의 50~100배라 이 성질이 그냥 좋은 게 아니라 필수다.

---

## ★ 전단대가 들어가는 유일한 실험

[B-S5](../papers.md) 가 전단대 두께를 **8~16·d = 40~80cm** 로 잡았고,
그게 터널 30cm 보다 커서 **붕괴 메커니즘이 도메인에 안 들어간다**고 했다.

**전단 상자는 그 전단대가 들어가게 만들 수 있는 유일한 실험이다** — 상자 크기가 우리 선택이므로.

```
전단대 80cm 을 담으려면        H ≈ 100cm  (20d)
REV 요건  W/d ≥ 12.5          W = L = 100cm 이면 20d — 여유
입자 수   100³ × 0.6 ÷ 65.4 cm³  ≈  9,000 입자
```

**9천 입자면 공짜다** (20만 목표의 4.5%).
M0 에서 **파괴 메커니즘이 도메인 안에 온전히 들어가는 실험을 하나는 갖게 된다**는 뜻이고,
B-S5 가 경고한 *"과대 안정 쪽으로 틀린다"* 를 **측정으로 잡을 수 있는 자리**가 생긴다.

> 크기 요건 출처: ASTM D3080 이 `W/d_max ≥ 10`, 두께 `≥ 6·d_max`.
> DEM 쪽 REV 연구는 `W/d > 12.5` **또한** 응력 전달 입자 3,000개 초과를 함께 요구한다.
> (척도효과를 **완전히** 없애려면 58~60 배라는 보고도 있다 — 우리 예산 밖. 절대값이 아니라 **조합 간 비교**에 쓴다.)

## ⚠ 주의 셋

**① 전단면이 강제된다.** 재료가 스스로 고른 파괴면이 아니라 상자가 정한 수평면에서 잘린다.
삼축시험 대비 직접전단의 고전적 비판이고 `φ` 가 몇 도 높게 나오는 경향이 있다.
→ **절대값보다 조합 간 비교에 쓸 것.**

**② 회전 없음이 여기서는 불리하다.** 첨두-잔류 차이와 다일레이턴시는 전단대 안에서
**알갱이가 굴러 재배열**하며 생기는데 우리 입자는 그걸 못 한다.
[캘리브레이션](dem-calibration.md) 의 "회전 없음 = 무한 구름 마찰"이 여기서는 각을 부풀리는 쪽이다.
→ **`φ_peak` 과 `ψ` 는 왜곡을 전제하고, `φ_cv`(잔류)를 더 믿는다.**
[구조 이방성](anisotropy-fabric.md) 의 `a_t` 부재와 같은 뿌리다.

**③ 뚜껑에 수직 자유도를 줘야 한다.** 높이를 고정하면 팽창을 막아 `φ` 가 통째로 달라진다.
**일정 힘으로 누르되 위아래로는 자유롭게.**
(Powder Technology 2022, *"Shear lid motion in DEM shear calibration…"* 이 이 문제를 다룬다)

---

## 구현 — 기존 자산이 거의 그대로 간다

[3-0-D 에서 남긴 것](../../design/m0-spike.md) 중 **벽 SP 규약(#18)** 과 **거친 바닥(#19)** 이
상자 벽과 상하면에 그대로 쓰인다. 뚜껑은 일정 힘 + 수직 자유도라 kinematic 벽 하나면 된다.

`τ` 는 아랫짝 벽이 받는 **접선 반력의 합**이므로 이미 계산 중인
[제약](constraint.md) 임펄스를 모으기만 하면 된다. 새 계기가 거의 필요 없다.

> ⚠ 상자 벽 마찰이 `τ` 에 섞인다. 벽을 마찰 0 으로 두거나, 아랫짝 접촉만 따로 합산할 것.
