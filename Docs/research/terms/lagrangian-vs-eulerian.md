# 라그랑주 vs 오일러 (MPM의 전제)

> [← 용어집](../glossary.md) › [6. 수치해석 / 시뮬레이션 기법](../glossary.md#6-수치해석--시뮬레이션-기법)

| | **라그랑주** — 재료를 따라다닌다 | **오일러** — 고정 격자에서 지켜본다 |
|---|---|---|
| 예 | [FEM 메시](fem.md), SPH 입자 | 유체 격자, 텍스처 |
| Unity 비유 | 파티클 시스템 | 텍스처 / 그리드 |
| 장점 | 재료 위치 정확, 질량 보존 자동, **이력을 들고 다님** | **이웃이 고정 → 미분이 쉽고 정확**, 충돌·연립 풀이 편함, 병렬화 쉬움 |
| 단점 | **크게 변형되면 메시가 뒤틀려 터짐**, [이웃 탐색](neighbor-search.md) 비쌈 | 이동 시 뭉개짐(수치 확산), **이력을 못 들고 다님**, 재료 경계가 흐려짐 |
