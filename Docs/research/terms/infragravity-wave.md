# 장주기파 (infragravity wave)

> [← 용어집](../glossary.md) › [7. 파도](../glossary.md#7-파도)

20~200초의 아주 긴 파동. [파군](wave-group.md)에서 생성된다.
완만한 dissipative 해변에서는 짧은 파도가 전부 수심 제한으로 포화되므로,
물가에 남는 에너지는 **장주기파가 지배한다** → 길고 느린 밀물 같은 [처오름](runup.md).
급경사 [reflective](reflective-dissipative.md) 해변에서는 처오름이 원래 파도 주기로 일어난다.
