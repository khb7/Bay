# 점착력 (cohesion, c)

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

**원뿔 꼭짓점을 인장 쪽으로 밀어낸 거리.** 당기는 힘도 c만큼은 버티게 됨.
```
   ↑         ╱
   │       ╱
───┼─◆──────────→
  인장│ 압축
   ←─┤ c 만큼 이동 = 수직 벽이 선다 = 모래성
```
**Tampubolon 2017의 한 문장 요약: [포화도](saturation.md)를 읽어서 c를 정한다.**

## ★ 왜 꼭짓점이 밀리나 — 겉보기 점착력 (apparent cohesion)
젖은 모래가 뭉치는 건 물이 **접착제처럼 붙여서가 아니다.**
```
물이 알갱이 사이를 빨아당김 → 알갱이들이 서로 눌림
→ 겉으로는 아무 힘도 안 주는데 내부적으로 압축 상태
→ Drucker-Prager 원뿔은 "누를수록 강하다"
→ 공짜로 눌러주는 힘이 생긴 것 = 꼭짓점이 인장 쪽으로 밀림
```
**실제 점착이 아니라 마찰이 작동하는 것.** 그래서 "겉보기" 점착력.

## 물리적 유도의 사슬 (참고 — 우리는 안 씀)
```
① W → 흡입력      ψ = P_entry · Se^(−1/λ)      물이 적을수록 작은 틈에 갇혀 흡입력↑
② 유효응력        σ' = σ + χ·ψ                 χ ≈ 포화도 (Bishop)
③ 전단강도        τ_f = (σ+χψ)·tanφ = σ·tanφ + χψ·tanφ
④                                                 ↑ 이게 c
```

**⚠ 이 유도는 정작 중요한 곳에서 틀린다.**
```
c ∝ χ·ψ = P_entry · Se^(1−1/λ)      모래는 λ≈2~5 → 지수 양수
→ "완전히 잠겼을 때 가장 강하다"는 결론. 실제로는 정반대로 0이다.
```
물에 잠기면 **공기-물 경계면(메니스커스)이 사라져** 표면장력이 작용할 면이 없다 → c = 0.
→ 모래성이 물에 녹는 것. (Tampubolon 2017의 대표 영상)

진짜 곡선의 봉우리는 **메니스커스 개수**가 결정한다:
```
물 적음   → 다리 몇 개, 각각 강함
늘어남    → 다리 개수 증가 → 강해짐        ← 봉우리
더 늘어남 → 다리들이 합쳐지며 경계면 감소
포화      → 경계면 0 → 강도 0
```
공극 크기 분포와 메니스커스 병합 통계까지 모델링해야 하는 작업이라
**그래픽스에서 아무도 안 한다.** Tampubolon 2017조차 "[현상론적](phenomenological.md)"이라 인정하고 넘어간다.

## 우리 선택: 하이브리드
| | 어떻게 | 왜 |
|---|---|---|
| **곡선의 모양** | 실측 커브 (Pakpour 2012, Scheel 2008) | 유도로는 봉우리를 못 냄 |
| **곡선의 크기** | 물리 유도 `cohesionMax ∝ 1/d` | 입도를 바꾸면 자동으로 따라와야 함 |

```csharp
float cohesion = cohesionMax(grainSize) * cohesionCurve.Evaluate(W);
//                    ↑ 유도                    ↑ 실측 커브 (언리얼 커브 에셋)
```
**모양은 손으로 그리고 스케일만 물리에서 파생.**
"유도 가능한 것도 커브로 대체한다"는 결정의 구체적 형태 —
단, **파라미터가 바뀔 때 자동으로 따라와야 하는 부분만 유도로 남긴다.**
