# 무차원 침강속도 Ω (Dean number)

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

`Ω = H / (w_s · T)` — 해변 형태 분류의 표준 지표.
- `Ω < 1` → **[reflective](reflective-dissipative.md)** (굵음, 가파름, 안정적)
- `Ω > 6` → **dissipative** (고움, 완만, 매우 활발, 계절 프로파일 변화 큼)
