# 임계상태 (critical state)

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

- **촘촘한** 모래를 계속 밀면 → 팽창해서 느슨해짐
- **느슨한** 모래를 계속 밀면 → 수축해서 촘촘해짐
- **양쪽 다 같은 밀도로 수렴한다** = 임계상태

[경화](hardening.md) 변수가 무한정 쌓이지 않고 안정점으로 수렴하는 이유.
(Schofield & Wroth, *Critical State Soil Mechanics*, 1968)
