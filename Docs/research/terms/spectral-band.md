# 스펙트럼 대역 (spectral band) — 연속 스펙트럼을 사인파 N개로

> [← 용어집](../glossary.md) › [7. 파도](../glossary.md#7-파도)

실제 바다에는 파도가 "몇 개" 있는 게 아니다. 바람은 **모든 주기에 조금씩** 에너지를 넣으므로
바다 상태는 파도 목록이 아니라 함수 하나 `S(f)`로 기술된다.

`S(f)`의 단위는 **m²/Hz — 밀도다.** 확률 밀도 함수처럼, 한 점의 값이 아니라
**구간의 넓이만 의미가 있다.** "주기 정확히 8초인 파도의 에너지"는 정의되지 않는다.

```
대역 폭      df = (fMax − fMin) / N          = (0.25 − 0.05)/32 = 0.00625 Hz
대역 i의 에너지 = S(fᵢ)·df                     ← 직사각형 하나의 넓이
```

```
S(f)
  │       ╱╲ 너울
  │      ╱  ╲            ╱‾╲ 풍파
  │     ╱    ╲___    ___╱    ╲___
  └──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──→  f
   0.05                          0.25 Hz
     │0 │1 │2 │3 │  ...32칸...  │31│
      ↑ 이 칸의 넓이를 사인파 1개가 통째로 대표한다
```

## 진폭 공식이 여기서 나온다

```
사인파 a·sin(⋯) 의 분산 = a²/2
대역 i가 담당할 에너지    = S(fᵢ)·df
                          ─────────────
        a²/2 = S(fᵢ)·df  →  a = √(2·S(fᵢ)·df)
```

`A[i] = sqrt(2*S(F[i])*df)`에 `df`가 끼어 있는 이유가 이것이다.

**대역 분할은 에너지 장부다.** 32개를 다 더했을 때 총 분산이 원래 스펙트럼과 같아야
`Σ aᵢ²/2 ≈ ∫S df = m₀` → `Hs = 4√m₀`, 즉 **입력한 유의파고가 그대로 나온다.**
대역이 겹치면 그 구간을 두 번 세어 파도가 커지고, 틈이 벌어지면 그만큼 샌다.

## 리만 합으로 보면 — jitter가 공짜인 이유

대역 분할은 적분 `∫S(f)df`를 직사각형 N개로 근사하는 것, 곧 **리만 합**이다.
`df`가 폭, `S(fᵢ)`가 높이. 그렇다면 높이를 구간의 **어디서** 재는가는 선택지다.

| | 대표점 | 이름 |
|---|---|---|
| 등간격 | 구간 중점 | 중점법 (midpoint rule) |
| **[jitter](jitter.md)** | 구간 안 랜덤 위치 | 몬테카를로 표본 |

`S`는 0.00625 Hz 폭 안에서 거의 평평하므로 **둘의 넓이는 사실상 같다.**
적분값(=에너지=`Hs`)은 보존한 채 주파수 간격의 규칙성만 깨는 것 — 그래서 공짜다.

> ⚠ 흔드는 폭이 **자기 대역 하나를 넘으면 안 된다.** 성분이 겹치거나 순서가 뒤바뀌면
> 위의 에너지 장부가 깨진다.

## ★ N=32인 이유는 이봉 스펙트럼

우리 스펙트럼은 봉우리가 둘이다 — 너울(`swellTp` 11~16 s ≈ 0.06~0.09 Hz)과
풍파(`Tp` ~6 s ≈ 0.17 Hz).

| N | df | 너울 | 풍파 | 결과 |
|---|---|---|---|---|
| **32** | 0.00625 Hz | 대역 5 | 대역 19 | **14칸 떨어짐 — 두 봉우리가 또렷** |
| 8 | 0.025 Hz | 대역 1 | 대역 4 | 3칸 — 뭉개져 하나로 보임 |

해상도가 모자라면 **`swellFraction`이라는 지역 파라미터 자체가 무의미해진다.**
"겉보기엔 잔잔한데 너울이 성을 먹는다"는 메커니즘이 여기 걸려 있다.
반대로 N을 키우면 매 프레임 경계 셀마다 사인 계산이 그만큼 늘어난다. 20~50이 절충선.
