# ★ 다지기 vs 밟기 — 방향이 반대다

> [← 용어집](../glossary.md) › [2. 소성과 항복](../glossary.md#2-소성과-항복)

```
밟기     → 발 주변이 뽀얗게 마름  (팽창. 물이 안으로 빨려 들어감)
두드리기 → 표면에 물이 배어나옴   (수축. 물이 밖으로 밀려 나옴)
```
**둘 다 힘을 주는데 왜 반대인가 → 시작 상태가 조밀한가 느슨한가.**
```
  φ
 0.44 ┤ ●──────────╲              느슨한 모래: 다져짐 (두드리기)
      │              ╲___
 0.40 ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ φ_c (임계 공극률)
      │             ╱‾‾‾
 0.36 ┤ ●──────────╱              조밀한 모래: 부풀음 (밟기)
      └──────────────────────→ 전단 변형
```
**해변 모래는 파도가 수없이 다져놔 조밀** → 밟으면 팽창.
**방금 퍼서 쌓은 모래는 느슨** → 두드리면 다져짐. 같은 물리, 반대 방향.

## 두드리기가 하는 일
**① 진동이 접촉을 풀어 아치를 무너뜨린다**
```
  ●  ●  ●        두드림      ● ● ● ●
   ╲╱ ╲╱     ──────────→     ●●●●●●
  ● ── ● ← 아치               ●●●●●
   (빈 공간)                  빈틈이 메워짐
```

**② 젖은 모래에선 순간 액상화가 더해진다** (마른 모래와의 큰 차이)
포화에 가까운 모래를 진동시키면 공극수압이 치솟아 알갱이가 접촉을 잃고 짧게 흐른다.
```
두드림 → 순간 액상화 → 자유롭게 재배치 → 진동 멈춤
       → 조밀하게 안착 → 남는 물이 밀려나옴 → 표면이 반들거림
```
**모래조각가들이 실제로 쓰는 기법**(jiggle). 지진 액상화와 같은 물리를 의도적으로 일으키는 것.

**③ 물이 밖으로 밀려난다** — φ가 줄면 들어갈 자리를 잃은 물이 표면으로.

## 다짐이 강도를 올리는 경로
| 경로 | 내용 |
|---|---|
| 접촉점 증가 | 알갱이당 이웃 증가 → **[모세관 다리](capillary-bridge.md) 개수 증가** |
| 맞물림 강화 | 서로 파고들어 마찰이 잘 작동 |
| **팽창 저항** | 조밀할수록 전단하려면 부피를 늘려야 함 → **[Reynolds 팽창](reynolds-dilatancy.md)이 방어로 작동** |

## ⚠ 다짐만으로는 안 된다
```
강도 = 수분곡선(W) × 다짐인자(φ)
        ↑ 0이면 곱해도 0
```
**마른 모래는 아무리 두드려도 모래성이 안 된다.** 다짐은 곱셈 인자, 수분이 필수 조건.

## 실제 모래조각 대회
```
1. 거푸집에 모래를 넣고  2. 물을 흥건히 붓고  3. 다지고 진동 (액상화→재배치→배수)
4. 틀을 빼면 아주 단단한 블록  5. 위에서부터 깎아 내려감
```
**쌓아 올리는 게 아니라 블록을 만들어 깎는다** — φ를 최대한 낮추려고.
"고운 각진 강모래를 쓴다"와 함께 대회용 모래성이 높이 서는 이유.

## 게임 메커니즘
| 행동 | φ | 결과 | 시각 피드백 |
|---|---|---|---|
| 모래 퍼서 쌓기 | 0.44 (느슨) | 약함 | 부슬부슬 |
| **두드리기/다지기** | → 0.36 | **강해짐** | **물이 배어나와 반들거림** |
| **밟기** (다져진 곳) | → 0.40 | 약해짐 | **뽀얗게 마름** |
| 파도가 훑고 감 | 리셋 | | |

**시각 피드백이 물리에서 그대로 나온다** — 같은 φ 변화의 반대 방향이라
플레이어가 "다져지는 중 / 풀리는 중"을 색으로 읽는다.
그리고 **다지기가 물을 소모한다**(표면으로 밀려난 물은 증발·유출) → 우물 파기와 엮인다.
