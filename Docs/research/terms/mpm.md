# MPM (Material Point Method)

> [← 용어집](../glossary.md) › [6. 수치해석 / 시뮬레이션 기법](../glossary.md#6-수치해석--시뮬레이션-기법)

**재료 정보는 입자가 들고 다니고, 계산은 격자에서 한다. 매 프레임 왕복.**

```
 ① 입자 상태      ② P2G        ③ 격자 계산     ④ G2P        ⑤ 입자 이동
  ●  ●  ●        ●→┼←●        ┌─┬─┬─┐       ┼→●←┼        ●  ●  ●
    ●  ●    ──>    ↘┼↙   ──>  ├─┼─┼─┤  ──>   ↓●↓    ──>     ●  ●
  ●   ● ●        ●→┼←●        └─┴─┴─┘       ┼→●←┼        ●   ● ●
  질량·속도·F     격자점에      힘 계산       새 속도를     그 속도로
  를 들고 있음     뿌린다        속도 갱신     받아옴        움직임
                              ↑ 격자는 매 프레임 초기화
```

**핵심: 격자는 계산용 임시 작업대다.** 진짜 상태는 전부 입자가 들고 있다.
> **격자 = 계산기, 입자 = 노트.** 매번 켜서 계산하고, 노트에 적고, 끈다.
> → **격자가 뒤틀릴 일이 없다.** [FEM 메시](fem.md) 뒤틀림 문제가 통째로 사라진다.

| 원래 문제 | MPM의 해결 |
|---|---|
| 메시 뒤틀림 (FEM) | 격자를 매 프레임 새로 깖 |
| [이웃 탐색](neighbor-search.md) 비쌈 (SPH) | 격자가 이웃 관계를 공짜로 줌 |
| 재료 이력 못 들고 다님 (오일러) | 입자가 들고 다님 |
| 수치 확산 (오일러) | 입자가 직접 이동 → 이류가 정확 |
| 자기 충돌 | 같은 격자를 쓰면 자동 (겹칠 수 없음) |
| **여러 재료 결합** | **같은 격자에 얹으면 끝** ← Tampubolon 2017이 MPM을 쓴 이유 |
