# 유변학 (rheology)

> [← 용어집](../glossary.md) › [3. 다공성 매질 / 물의 이동](../glossary.md#3-다공성-매질--물의-이동)

**물질이 어떻게 흐르고 변형되는지를 다루는 학문.** 그리스어 rheo(흐르다)에서 왔다.

## 핵심 질문 — 응력이 무엇에 비례하는가

```
탄성 고체:  σ = E · ε      응력 ∝ 변형(얼마나 찌그러졌나)       — 후크
점성 유체:  τ = μ · γ̇      응력 ∝ 변형률(얼마나 빨리 찌그러지나) — 뉴턴
```

**이 둘 사이의 모든 것이 유변학의 영역이다.** 사실상 [구성 모델](constitutive-model.md)과
같은 얘기 — 고체와 액체 사이에 걸친 물질의 구성 모델을 다룬다.

## 뉴턴 유체 vs 비뉴턴 유체

**뉴턴 유체**는 점도 `μ`가 상수다 (물, 공기, 묽은 기름).

| 종류 | 성질 | 예 |
|---|---|---|
| **전단담화** | 빠르게 저을수록 **묽어짐** | 케첩, 페인트, 샴푸, 혈액 |
| **전단농화** | 빠르게 저을수록 **되직해짐** | 옥수수전분 물(우블렉) |
| **빙엄 소성체** | **항복응력이 있음.** 넘어야 흐름 | 치약, 마요네즈, **진흙** |
| 점탄성 | 탄성 + 점성 동시에 | 실리퍼티, 반죽 |

## ★ 항복응력 — 모래성이 서 있는 이유

```
꿀:     점도가 물의 수천 배. 그런데 항복응력 = 0
        → 시간을 주면 결국 완전히 평평해진다

모래성: 항복응력이 있다
        → 건드리지 않으면 영원히 그 모양
```

**점도가 아무리 커도 항복응력이 0이면 결국 퍼진다.**
모래성이 안 퍼지는 건 끈적해서가 아니라 **항복응력이 있어서**다.

```
빙엄 소성체:   τ < τ_y  →  안 흐름 (고체처럼)
              τ > τ_y  →  흐름:  τ = τ_y + μ·γ̇
```

**`τ_y` 가 곧 [항복면](yield-surface.md)이다.** 소성역학과 유변학이 여기서 만난다 —
같은 것의 다른 이름이다.
```
소성역학 관점:  항복면 안 = 탄성, 밖 = 소성 흐름
유변학 관점:    항복응력 아래 = 안 흐름, 위 = 흐름
```

## 농도가 유변학을 결정한다

papers.md D1-b(Gao 2018)의 **"마찰 지배 → 점성 지배로 연속 전이"** 가 이것이다.

```
높은 농도 → 알갱이가 서로 닿음  → 마찰 지배 → 항복응력 있는 고체 (Drucker-Prager)
중간 농도 → 가끔 닿음          → 점도가 급격히 상승
낮은 농도 → 거의 안 닿음        → 점성 지배 → 그냥 좀 걸쭉한 물
```

```
묽을 때 (Einstein):        μ = μ₀ · (1 + 2.5φ)
일반 (Krieger-Dougherty):  μ = μ₀ · (1 − φ/φ_max)^(−2.5·φ_max)
                                        ↑ φ → φ_max(≈0.6) 에서 점도가 발산
```
**농도가 최대 충전에 가까워지면 점도가 무한대로 간다.** 그게 액체에서 고체로 넘어가는
지점이고, 그래서 스위치가 아니라 **연속 전이**가 된다.

## 우리 재료가 유변학적으로 어디 있나

| 상태 | 유변학 | 우리 프로젝트 |
|---|---|---|
| 마른 모래(정지) | 마찰 고체, 항복응력 큼 | 부슬부슬 |
| **젖은 모래** | **빙엄 소성체** | **모래성** |
| 과포화 슬러리 | 전단담화 유체 | 녹아내리는 모래성 |
| 흙탕물 | 거의 뉴턴 (점성 약간↑) | `s` 가 실린 탁류 |
| 맑은 물 | 뉴턴 | |

**한 게임 안에서 이 다섯 상태를 다 오간다.** Gao 2018 같은 통합 유변학이 필요했던 이유.

## 덤 — 입상체의 현대 유변학 `μ(I)`

[Drucker-Prager](drucker-prager.md)는 **정지 직전** 상태에 맞춘 모델이라 빠르게 흐르는
모래를 잘 못 다룬다. 현대적 답이 `μ(I)` 유변학이다.
```
관성수  I = γ̇·d / √(P/ρ)          전단 속도, 입도, 압력
마찰계수가 상수가 아니라 I의 함수:  μ = μ(I)

I 작음(느림) → 준정적. Drucker-Prager와 일치
I 큼  (빠름) → 마찰이 커짐. 흐르는 모래
```
**Jop, Forterre, Pouliquen (2006), "A constitutive law for dense granular flows", Nature 441**
— 원전. GDR MiDi (2004)가 선행, Dunatunga & Kamrin (2015)이 연속체 시뮬로 가져왔다.

> **우리는 안 쓴다.** 하이트필드는 유변학 자체가 없고 안식각으로 대체했으며,
> 입자 계층도 마찰 계수 하나면 충분하다.
> 다만 **"왜 Drucker-Prager 하나로는 부족할 수 있는가"** 를 아는 값은 있다.
