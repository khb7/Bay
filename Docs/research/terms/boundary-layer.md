# 경계층 (boundary layer)

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

바닥의 유속 0에서 자유흐름 속도 U까지 바뀌는 얇은 전이층. 두께 `δ`.
```
   ────────────────→  U (자유흐름)
   ──────────→
   ──────→              ← 경계층 δ
   ──→
   ▓▓▓▓▓▓▓▓▓▓▓▓  바닥 (속도 0)
```
