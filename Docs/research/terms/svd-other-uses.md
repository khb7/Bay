# SVD의 다른 용도

> [← 용어집](../glossary.md) › [6. 수치해석 / 시뮬레이션 기법](../glossary.md#6-수치해석--시뮬레이션-기법)

| 분야 | 용도 |
|---|---|
| PCA (주성분 분석) | 사실상 [SVD](svd.md)와 같은 것 |
| 이미지 압축 | 큰 특이값 몇 개만 남기고 버림 (저랭크 근사) |
| 최소제곱 / 유사역행렬 | 역행렬 없는 행렬을 "최대한" 뒤집기 |
| 노이즈 제거 | 작은 특이값을 노이즈로 보고 잘라냄 |
