# ②와 ③의 대립 ★

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

침투/유출이 퇴적물에 미치는 영향은 두 메커니즘이 **정확히 반대 방향**이다.

|  | 침투 | 유출 |
|---|---|---|
| [유효 중량](seepage-force.md) | 눌러줌 → 안 움직임 | 들어줌 → 잘 움직임 |
| [경계층](boundary-layer.md) | 세게 긁음 | 살살 긁음 |
| **합** | **무겁지만 세게 긁힌다** | **가볍지만 살살 긁힌다** |

어느 쪽이 이기는지는 미결 문제. 단, `K ∝ d²` 라 **고운 모래에서는 셋 다 사라진다** —
swash 한 주기 동안 스며드는 깊이가 굵은 모래 5mm vs 고운 모래 0.1mm.
침투/유출은 **굵은 해변의 현상**이다.
