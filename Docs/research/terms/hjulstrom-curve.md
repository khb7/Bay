# Hjulström 곡선

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

입도별로 침식에 필요한 유속을 그린 곡선. **양쪽 끝이 올라간 U자.**
```
 필요 유속
   ↑╲                                    ╱
   │ ╲   점착력이 붙잡음              ╱   무게가 붙잡음
   │  ╲  (실트·점토)               ╱     (조립사·자갈)
   │       ╲______________╱
   └──────┴────┴────┴────┴──────┴──→ 입도
        실트  0.1  0.3  0.5   1mm   자갈
               └─ 가장 잘 깎임 ─┘
```
**0.1~0.5mm(세립~중립사)가 지구상에서 가장 깎기 쉬운 물질.**
가볍고 [점착력](cohesion.md)도 없어서 최소 에너지로 움직인다.
→ 일반적인 모래사장이 정확히 이 구간이다.
