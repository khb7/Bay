# ★ 젖으면 왜 어두워지는가 (Jensen 1999의 물리적 근거)

> [← 용어집](../glossary.md) › [8. 모래알 자체](../glossary.md#8-모래알-자체)

```
공기  n = 1.00
물    n = 1.33
석영  n = 1.54
```
**마른 모래**: 공기↔석영 굴절률 차가 큼 → 표면 첫 알갱이에서 강하게 반사·산란
→ 바로 눈으로 돌아옴 → **밝음**

**젖은 모래**: 물↔석영 차가 작음 → 표면에서 덜 튕기고 알갱이 사이로 **깊이 들어감**
→ 안에서 여러 번 산란하며 매번 흡수 + 표면 물막에서 전반사되어 잘 못 빠져나옴
→ **어두움**

```csharp
albedo    = lerp(dryAlbedo, dryAlbedo * 0.5f, W);
roughness = lerp(0.9f, 0.2f, W);
```
**굴절률 차가 작을수록 어두워지므로 광물이 바뀌면 젖었을 때의 대비도 달라진다.**
현무암 모래는 원래 검어서 변화가 덜 보이고, 흰 조개 모래는 대비가 극적이다.
