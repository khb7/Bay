# stiff (수치적으로 뻣뻣하다)

> [← 용어집](../glossary.md) › [6. 수치해석 / 시뮬레이션 기법](../glossary.md#6-수치해석--시뮬레이션-기법)

힘이 너무 강해 타임스텝을 작게 안 하면 **발산하는** 상태.
Unity에서 스프링 상수를 극단적으로 키우면 오브젝트가 날아가는 그것.

> **[강성](stiffness.md)과 연결되지만 같은 말이 아니다.**
> [강성](stiffness.md)은 **재료**의 성질, stiff는 **방정식 계**의 성질. k가 크면 계가 stiff해진다.
