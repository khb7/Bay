# 풍파 (wind sea) vs 너울 (swell) ★

> [← 용어집](../glossary.md) › [7. 파도](../glossary.md#7-파도)

| | 풍파 | 너울 |
|---|---|---|
| 발생 | 지금 여기 부는 바람 | 먼바다 폭풍이 만들어 이동해 옴 |
| 주기 | 2~8초 | **10~20초** |
| 모양 | 가파르고 어지럽고 방향 제각각 | 매끈하고 규칙적이고 한 방향 |
| 겉보기 | 거칠어 보임 | **잔잔해 보임** |
| 실제 위력 | 보통 | **훨씬 강함** |
