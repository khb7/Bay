# 편차 / 체적 분해

> [← 용어집](../glossary.md) › [1. 역학 기초](../glossary.md#1-역학-기초)

[응력](stress.md)(또는 [변형](strain.md))을 두 성분으로 쪼갬.
- **체적 성분 (volumetric)** = `tr(ε)`, 대각합. **부피가 변하는** 부분
- **편차 성분 (deviatoric)** = 나머지. **부피는 그대로고 모양만 바뀌는** 부분. 전단이 여기

항복 조건이 이 둘로 쓰이므로 중요.
