# 공극률 φ (porosity) ★

> [← 용어집](../glossary.md) › [3. 다공성 매질 / 물의 이동](../glossary.md#3-다공성-매질--물의-이동)

```
φ = 빈틈 부피 / 전체 부피        모래는 0.35~0.45
```
**모래 더미의 약 40%는 사실 공기다.** 1m³ 모래통에 물을 **400리터** 부을 수 있다는 뜻.

## ★ 입도와 거의 무관하다
```
지름 1mm 구슬 더미    → φ ≈ 0.40
지름 0.1mm 구슬 더미  → φ ≈ 0.40     똑같다
```
비율이라 스케일에 무관하다. 전체를 확대해도 빈틈과 알갱이의 비율은 그대로.

**[투수계수](permeability.md)와 대비하면 선명하다**
```
K ∝ d²   → 입도에 크게 의존 (0.5mm ↔ 0.15mm 가 50배 차이)
φ        → 입도와 거의 무관 (대부분 0.35~0.45)
```
**빈틈의 "비율"은 같은데 빈틈 하나하나의 "크기"가 다른 것.** 그래서 통과 속도만 달라진다.

## 무엇이 φ를 바꾸나
| 요인 | 효과 |
|---|---|
| **분급(sorting)** | 크기가 섞이면 작은 게 빈틈을 채움 → **φ 하락** |
| **형상(원마도)** | 각진 알갱이는 성기게 쌓임 → **φ 상승** |
| **다짐(packing)** | 흔들거나 눌러 재배치 → **φ 하락** |

해변 모래는 파도가 계속 체질해서 **매우 잘 분급돼 있다** → φ가 일정하고 예측 가능.
**"균일 입도 가정"이 방어되는 근거.**

## 이론적 한계 — 구 충전 문제
| 배열 | φ | |
|---|---|---|
| 단순 입방 | 0.476 | 격자로 반듯하게. 가장 성김 |
| **무작위 최소 충전 (RLP)** | **≈ 0.44** | **살살 부어놓은 상태** |
| **무작위 최밀 충전 (RCP)** | **≈ 0.36** | **흔들어 다진 상태** |
| 최밀 충전 (FCC/HCP) | 0.260 | 이론적 최소. 오렌지 쌓기 |

**실제 모래는 0.36~0.44 사이에서만 산다.** 우리 값 0.40은 그 중간.

**왜 무작위가 최밀(0.26)보다 훨씬 성긴가**: 알갱이가 스스로 완벽한 결정 배열을 못 만든다.
쏟아지면 서로 걸리고 아치가 생겨 빈틈이 남는다.
**모래통을 흔들면 부피가 주는 게 0.44 → 0.36으로 가는 것.**

## [Reynolds 팽창](reynolds-dilatancy.md)·[임계상태](critical-state.md)와의 연결
```
다져진 모래 (φ=0.36) 전단 → φ 상승 (팽창)
느슨한 모래 (φ=0.44) 전단 → φ 하락 (수축)
양쪽 다 임계 공극률 φ_c ≈ 0.40 으로 수렴
```
**[임계상태](critical-state.md)의 실체가 "임계 공극률"이다.**
부피 변화는 전부 공극에서 일어난다 — 알갱이(석영, Mohs 7)는 안 눌리므로.

## 간극비 e (토질역학 관행)
```
φ = 빈틈/전체  (0~1)        e = 빈틈/고체  (0~∞)
e = φ/(1−φ)    φ = e/(1+e)      φ=0.40 ⟺ e=0.667
```
**`e`를 쓰는 이유: 분모(고체 부피)가 절대 안 변한다.**
압축돼도 알갱이는 그대로라 `e`의 변화가 곧 부피 변화. 모래는 보통 `e = 0.5~0.8`.

## ⚠ φ = 0.40 vs n = 0.3 — 다른 값이다
[지하수면](water-table.md) 공식의 `n`은 전체 공극률이 아니다.
```
φ = 전체 공극률            = 0.40   물을 담을 수 있는 총량
n = 유효 공극률(비산출률)   = 0.30   중력으로 실제 오갈 수 있는 양
φ − n                     = 0.10   모세관이 붙잡은 잔류량 (= field capacity)
```
지하수면이 내려갈 때 배출되는 건 **중력이 빼낼 수 있는 부분만**.
그래서 `L = √(2KD/nω)` 에는 `n`이 들어간다.

## 밀도
```
마른 모래  ρ = (1−φ)·2650        ≈ 1590 kg/m³
포화 모래  ρ = 1590 + φ·1000     ≈ 1990 kg/m³
```
**젖은 모래가 마른 모래보다 25% 무겁다.** 플레이어가 모래를 옮기는 행동을 넣으면 그대로 비용.

## 우리 프로젝트에서 쓰이는 곳
| 어디 | 어떻게 |
|---|---|
| 물 저장 용량 | 셀 최대 물 = `φ`. `W × φ` 가 실제 물 부피 |
| 투수계수 | Kozeny-Carman `K ∝ φ³/(1−φ)² × d²` — **범위는 `d²`가 지배** |
| 지하수면 감쇠 길이 | `L = √(2KD/nω)` — 여기는 `n` |
| 팽창/다져짐 | `φ` 변화가 곧 강도·투수성 변화 |
| 밀도 | 렌더링·게임플레이(무게) |
