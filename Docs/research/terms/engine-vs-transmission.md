# 엔진 vs 변속기 (침식 메커니즘 정리) ★

> [← 용어집](../glossary.md) › [5. 해변](../glossary.md#5-해변)

- **엔진** = 파도 에너지 → [바닥 전단응력](bed-shear-stress.md) → 알갱이가 들림. **고울수록 잘 들림**
- **변속기** = 침투/유출(①②③)이 uprush/backwash 비대칭을 조절 → 순 이동의 **방향**을 정함.
  굵은 모래에서만 유의미

| | 세립사 | 조립사 |
|---|---|---|
| 엔진 | 강함 | 약함 (알갱이가 무거움) |
| 변속기 | 중립 | 육지 쪽 편향 |
| 결과 | 많이 움직이되 방향은 파랑 조건이 정함 | 모래가 쌓여 급경사로 안정화 |

**"세립사에서 ①②③이 죽는다" = 변속기가 중립이 된다는 뜻이지, 침식이 안 일어난다는 뜻이 아니다.**
