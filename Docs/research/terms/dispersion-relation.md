# 분산 관계 (dispersion relation)

> [← 용어집](../glossary.md) › [7. 파도](../glossary.md#7-파도)

심해에서 `ω² = gk`. 여기서:
```
위상속도  C   = gT/2π ≈ 1.56 T   (m/s)
군속도    C_g = C/2   ≈ 0.78 T   (m/s)   ← 에너지가 이동하는 속도
```
**긴 파도가 더 빠르다.** 이것이 [너울](wind-sea-vs-swell.md)이 정렬되는 이유.
