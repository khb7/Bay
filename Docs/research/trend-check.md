## 기록

### C4 처오름 정상성 (2026-11-22, 기존 eq2 · hb2 재분석, papers D-M7-13, `tools_swashwin.py`)
- 120 s 창, 4 줄 평균. 문헌: 2–3 분 창 CV ~0.2 (입사) ~ 0.65–0.8 (IG 지배) 은 표본 변동으로 정상.
| 실행 | 0–120 s 최대 | 120–900 s 창 최대 (범위) | 창 최대 CV |
|---|---|---|---|
| eq2 (`-tke -breakratio=0.3 -eqenergy`) | **1.24 m** | 0.71–1.03 | 0.12 |
| hb2 (기본) | 0.88 | 0.90–1.13 | 0.08 |
- **판정 ✘ (eq2 만)**: 시작 창 최대가 뒤 창의 1.2–1.7 배 — 실제 바다엔 없는 **시작 과도** (사용자 P2 "처음 ~3 번 아주 높이" 와 일치). 뒤 창끼리 변동 (CV 0.12) 은 문헌 표본 변동보다 작아 정상 범위. 기본 물리 hb2 는 시작 과도 없음.
- 원인 후보: eq2 의 등에너지 성분 · TKE 가 처음 파군을 크게 입사 (램프 없음?) — 다음 확인 (C13 신규).
- 한계: 분석 구간 780 s (문헌 권장 17–20 분 이상), 창당 최댓값 5–11 개.

### C5 내림 최저점 (2026-11-22, 같은 자료)

| 실행 | η (setup) | S = 4σ | 기대 η − S/2 | 측정 하위 2 % | Stockdon 식 기대 (η 0.35 · S 1.17) |
|---|---|---|---|---|---|
| eq2 | 0.23 | 1.38 | −0.46 | **−0.44** | −0.23 |
| hb2 | 0.38 | 1.23 | −0.23 | **−0.25** | −0.23 |
- 모델 안에서 내림 = η − S/2 관계는 둘 다 성립 (분포 모양 정상). **eq2 는 setup 이 작고 (0.23 vs 0.35) swash 가 커 내림이 Stockdon 기대보다 0.2 m 낮다** — Dean 바닥에서 물가로부터 ~3.5 m → ~9 m, 약 5–6 m 더 드러남 (사용자 P3 "내림 때 바닥이 넓게 드러남" 후보 설명). hb2 는 Stockdon 기대와 같음.
- 판정 △: rundown 직접 측정 식이 문헌에 없어 (O'Dea 2025) 기대값 자체가 추정. 비교는 η · S 각각 (C7 · B2 에서 IG 와 같이).

### C1 쇄파대 Hs/h (2026-11-22, hb2 · eq2 너울 + 새 실행 c1hbW · c1eqW 풍파 Tp 5, 모두 H₀ 1 m · 1:15 · 900 s)
- 기준 (papers D-M7-12): γs = 0.19 + 1.05 β/kh (산포 ±0.09–0.15), setup 포함 h, k = 대역 centroid 주파수. `tools_surfgamma.py`. 풍파 첨두 0.2 Hz 는 문헌 대역 (0.05–0.18) 밖이라 같은 비교는 0.05–0.5 Hz.

| 0.3 | 0.82 / 0.76 | 1.03 / 0.53 | 0.95 / 0.41 | 0.77 / 0.66 | 0.90 / 0.49 | 0.88 / 0.42 |

- **수심 방향 ✔**: 모든 경우 얕을수록 커짐, 식과 평행.
- **크기 ✘**: 너울 (문헌 대역) 측정 / 식 1.2–1.6, 풍파 2.5–3.3. 풍파는 h 3.3 → 2 m 사이 Hs 가 거의 안 줄어 (Hs/h 0.29 → 0.49) 쇄파 소산이 늦다. 기본 물리 (hb2) 가 eq2 보다 더 큼.
- **주기 추세 ✘ (없음 · eq2 는 반대)**: 문헌은 같은 h 에서 너울 γs 가 풍파의 1.3–1.7 배. 모델 (같은 0.05–0.5 대역) 은 너울 ≈ 풍파 (hb2 0.72 vs 0.75, eq2 0.54 vs 0.60 @ h 1 m). 이유: 너울이 얕아지며 에너지 44–58 % 를 0.18 Hz 이상으로 넘겨 평균 주기가 12 → ~4.5 s (풍파와 같아짐) → C14 로 분리.
- 한계: 경사는 Dean 고정이라 β 따로 못 바꿈 (`-beachslope` 는 물 위만) — 한 실행 안의 β/kh 변화로만 봄. 기록 780 s (문헌 68 분).

### C3 거품 단면 · 먼 바다 거품 (2026-11-22, #74 게임 실행 fd2 재분석, papers D-M7-14)
- 기준: Qb (BJ78 · Baldock98 · TG83) — Hs/h 0.3 → 0.1–7 %, 0.4 → 2–20 %, 0.5 → 8–50 %, 0.6 → 18–100 %. 쇄파 시작 지점은 띄엄띄엄, 포화 구간은 거품이 남아 거의 연속 (Aarninkhof & Ruessink 2004). 바람 없는 너울은 쇄파대 밖 whitecap 없음.

|---|---|---|---|
| 190 (3.1) | 0.03 | 0.28 한 번 (90–120 s) 뒤 0 | 0.04 |
| 130 (2.3) | 0.05 | 60–120 s 만 + 끝 한 번 | 0.12 |
| 90 (1.7) | 0.11 | 시작 + 끝 | 0.20 |
| 50 (1.0) | 0.29 | 거의 매 구간 0.2–0.4 | 0.60 |

- **판정 ✔ (방향 · 크기)**: 해안 쪽으로 증가, 각 수심 비율이 Qb 문헌 범위 안. 시작 120 s 뒤 h ≥ 2.3 m 거품은 거의 없음 — 사용자 P1 "먼 바다 거품이 계속" 은 #74 수정 전 현상.
- **남은 것**: 먼 바다 거품 대부분이 **시작 90–150 s 에 몰림** → C13 (시작 과도) 과 같은 뿌리.
