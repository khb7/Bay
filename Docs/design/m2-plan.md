## 결정

1. **스탬프는 GPU 에서 소비한다** (`StampCS`, 시뮬 스텝 맨 앞 = system-design 패스 0). CPU 는 스탬프 구조체(수십 바이트)만 올린다. 내려받기 없음.
2. **입자 풀 + 살아있음 표시** — 압축(번호 바꾸기)을 하지 않는다. 접촉 · 결합 · 메셔가 번호를 쥐고 있어 압축은 전 버퍼 재배치다.
   - 제거 = Dead 표시 → 해시 · 접촉 · 메셔가 건너뛴다. 붙어 있던 결합은 그 프레임에 끊는다.
   - 추가 = 빈 칸 목록(GPU append/consume)에서 꺼낸다. 풀 용량은 시작 때 정한다 (기본 입자 수 × 2).
3. **커서 = 입자 광선 행진** (GPU, 결과 1 프레임 늦게 비동기 리드백). M2 장면엔 입자와 평면 바닥뿐이라 깊이 버퍼보다 단순하고 정확하다. 격자 · 물이 들어오는 M3 에서 `FScenePicker`(깊이 버퍼)로 바꾼다 — 인터페이스(`화면 좌표 → 점 · 법선`)는 같게.
4. **연속 브러시** — 지난 프레임 커서와 이번 커서 사이를 반지름 1/4 간격으로 스탬프를 나눠 보낸다 (빠르게 그어도 끊기지 않게).

## 도구

| 도구 | 스탬프가 하는 일 | 근거 |
|---|---|---|
| **파기** | 구 안 입자를 **손(삽)으로 옮긴다** — 풀에서 Dead 로 빼고 손 재고에 넣는다. 세기 < 1 이면 확률로 일부만 (깎기 감). 붙은 결합 끊기. 손이 차면 더 안 파진다 | system-design §5 · 질량 보존 (사용자, 2026-10-27) |
| **쌓기** | **손 재고에서만** 꺼내 커서 위 반 구에 지터 격자로 놓는다 (겹침 없이). 손이 비면 안 쌓인다 · **W = 퍼 온 모래의 W** (손 재고가 W 를 같이 가진다) · 스탬프 영역 안에서 결합 생성 한 번 (누르며 붙이기) | §5 ★ · milestones "쌓기의 W 상속" |

**손 재고 (질량 보존)** — 모래는 생기거나 사라지지 않는다. 파기 = 퍼 담기, 쌓기 = 내려놓기.
- 재고 = 입자 수 + W 목록 (입자마다 W 를 그대로 — 평균하지 않는다. 젖은 것 · 마른 것을 섞어 퍼면 섞인 채 놓인다). GPU 버퍼, 순서 = 넣은 순서 (먼저 퍼 온 것이 먼저 나온다 — 큐).
- 용량 = 한 손/삽 분량 (기본 반지름 10cm 구 ≈ 입자 수백 개). UI 에 재고량 표시.
- milestones 의 "젖은 곳 근처에서 쌓아야 잘 뭉친다" 는 **"젖은 곳에서 퍼 와야 잘 뭉친다"** 가 된다 — 실제 해변 그대로 (물가에서 퍼서 위로 나른다).
- 시작 재고 0. 빈 손으로 쌓으려 하면 아무 일 없음.
| **물붓기** | 구 안 입자 W += 유량·dt (상한 1) · 아래로 속도 충격 √(2gh) 비례 · 결합 Coh 는 매 프레임 W 에서 다시 계산 | §5 물붓기 3효과 |

**물붓기 ③ 과포화**: cohesion(W) 곡선이 WSat 0.9 넘으면 떨어진다 (B1) → 부은 직후 약해짐은 곡선만으로 나온다. **배수**(W → 장 용수량으로 서서히)는 M5 의 일인데, 없으면 한 번 과포화된 모래가 영영 약하다 → M2 에선 상수 속도 이완 하나만 둔다 (`W > WOptEnd` 면 WOptEnd 쪽으로 τ ≈ 10 s). M5 에서 교체.
- 주의: 지금 곡선은 W ≥ WSat(0.9) 에서 cohesion 0 → **결합이 끊기고 스스로 되붙지 않는다** (§ 결합 규칙). 즉 과포화로 끊긴 곳은 마른 뒤에도 쌓기(누르며 붙이기)로 다시 붙여야 한다. 의도와 맞는지 T2 화면에서 사용자 판정.
- 재질 광택(Wg, W 0.8~1)과 점착 하락(W 0.7~0.9) 구간이 겹친다 — 반들거리는 곳이 약한 곳. 물리와 화면이 같은 신호를 준다.

## 단계

| 단계 | 내용 | 검증 |
|---|---|---|
| **T1** 풀 · Dead | GPU 버퍼를 용량만큼 잡고 Alive 수 대신 Dead 표시. 해시 · 접촉 · 결합 · 메셔 · 내려받기가 Dead 를 건너뜀 | Dead 0 개면 기존과 비트 일치 (CPU=GPU 회귀) · 반을 Dead 로 하면 나머지 반만 남은 장면과 같은 모양 |
| **T2** `FToolStamp` · `StampCS` (파기 · 물붓기) | 스탬프 배열 업로드 → 스텝 앞에서 소비. 결합 Coh 갱신 패스 | 커맨드릿: 블록 가운데를 파면 구멍 · 줄어든 입자 수 = 재고 증가. 반쪽 물붓기 = M1 W3 반 젖은 장면과 같은 결과 |
| **T3** 손 재고 · 쌓기 | 파기 → 재고 큐 (W 같이), 쌓기 = 재고에서 꺼내 빈 칸에 지터 배치 · 영역 결합 생성 (GPU) | **총 입자 수 + 재고 = 일정** (매 프레임) · 마른 곳 / 젖은 곳에서 같은 양을 퍼서 쌓고 무너짐 비교 (젖은 모래가 더 높이 서야) |
| **T4** 커서 · 입력 · 연속 브러시 | 입자 광선 행진 + 비동기 리드백. 플레이 맵: 자유 카메라, 좌클릭 파기 · 우클릭 쌓기 · F 물붓기 · 휠 반지름 · Shift 세기 | 화면에서 직접 — **손맛 · 지연 체감은 사용자 판정** |
| **T5** 비용 | 스탬프 · 쌓기 패스 ms (타임스탬프) | 브러시를 계속 문질러도 프레임 예산 안 |
