## 실행 #1 — 첫 안식각 (2026-09-05)

`aor_mu0.70_ss10_it2_n4620.csv`

```
입자 4620   기둥 R=H=58.4cm   μ=0.70   substep 10 × 반복 2   시드 1337
```

| 항목 | 값 | 판정 |
|---|---|---|
| **안식각 최빈** | **26.5°** | **불통과** (34 ± 3) |
| 중앙 / 평균 | 26.5° / 26.3° | 최빈과 일치 — 중심값은 신뢰 가능 |
| 표면 / 표본 | 725 / 417 | 표본 충분 |
| 정지 프레임 | 892 (14.87초) | — |
| `step` | 36~38ms | ★ **CPU 기준선** (4620 입자, 단일 스레드) |

### 문제 셋

**① 각이 낮다.** `atan(μ) = atan(0.7) = 35.0°`가 나와야 하는데 26.5°.
`tan(26.5°) = 0.50` → **공급된 마찰이 명목값의 71%.** 0%가 아니라 새는 것이다.

**② "정지"가 실은 정지가 아니다.** 판정이 걸린 마지막 프레임들:

```
avgSpeed 1.36~1.40  (임계 1.50 — 겨우 아래)
peakHeight 40.081 → 40.007   ← 0.067초에 0.74mm 계속 내려앉는 중
maxSpeed 13~31 cm/s
```

평균이 임계 바로 밑에 붙어 판정만 통과했다. **26.5°는 최종 각이 아니라 지나가는 중의 각**이고 더 두면 더 낮아진다.

**③ 히스토그램이 평평하다.** 1°~62°에 고르게 퍼지고 최대 빈이 19개(27°)뿐.
경사면이 한 각으로 모이지 않는다 — ①②와 같은 원인을 가리킨다.

### 진단 — 마찰 클램프의 `dt²` 누수 (가설)

마찰 한계를 `μ × 침투량`으로 잡는데([SandSpike.cpp](../../BeachSimulator/Source/BeachSimulator/Spike/SandSpike.cpp) `SolveContacts`),
접촉 컴플라이언스가 0이라 침투가 매 반복 해소된다.

```
현실   밑바닥 접촉 = 위에 쌓인 전부의 하중  →  마찰 크다
우리   Depth ≈ 0                          →  마찰 예산 ≈ 0
```

**하중 정보가 마찰에 전달되지 않는다.** 여기에 서브스텝이 기름을 붓는다.

```
½ g·dt_sub² = ½ × 980 × (1/600)² ≈ 14μm   →  마찰 예산 μ × 14μm ≈ 10μm
```

Macklin 2019(Small Steps)를 따라 substep을 늘렸는데, **이 마찰 공식에 한해서는 그게 마찰을 약화시킨다.**

> ⚠ `α`(컴플라이언스)를 키우면 침투가 남아 각이 올라간다. **하지만 그건 모래알을 스펀지로 만드는 것**이고,
> 대가는 성이 자기 무게로 가라앉는 것이다. `α = 0`은 맞는 선택이고 **틀린 마찰 공식을 드러냈을 뿐이다.**

선형이라고 가정하면 필요한 μ는 `0.70 × tan34/tan26.5 ≈ 0.95`.
다만 누수가 μ에 비례한다는 보장이 없어서 **계산이 아니라 스윕이 판정한다.**

### 다음 — 스윕 27실행

값과 축은 [m0-spike.md §3-0 실패 분기](m0-spike.md). 세 갈래 중 어디인지가 나온다.

```
μ에 비례해 오름          → 값 문제. μ 확정하고 3-1로
포화                     → 클램프가 하중을 못 받음
substep 늘릴수록 내려감  → dt² 누수 확정 → λ 기반 마찰로 교체
```

교체안은 이미 정해져 있다 — 침투량 대신 **누적 라그랑주 승수로 클램프**(`|Δλ_t| ≤ μ λ_n`).
`λ_n`은 서브스텝 동안 누적되어 실제 접촉력에 비례하므로 하중이 반영된다.
대신 **접촉을 반복 간에 유지하는 목록**이 필요한데, 점착 결합(3-2)에서 어차피 만들어야 하는 구조다.

## 실행 #3 — 장면 3: 마찰 off (2026-09-05)

**★ 진단 확정. 마찰 보정이 에너지원이다.**

벽 안 다지기 단계만 비교 (같은 조건, μ만 다름):

| μ | 최고점 | 정지 |
|---|---|---|
| 0.00 | 58.68 → **46.27** (다져짐) | frame 196 |
| 0.70 | 58.53 → 59.08 (살짝 부풂) | frame 420 |
| 1.00 | 58.61 → **71.40** (계속 부풂) | 못 함 |
| 1.30 | — | 못 함 |

μ=1.00의 30초:

```
frame  150   peak 60.55   com 28.05
frame  600   peak 64.81   com 25.73
frame 1800   peak 71.40   com 25.51
```

**질량중심은 내려가는데 최고점은 계속 올라간다.** 아래는 다져지고 위로 튀어나간다.

### 접촉 솔버 자체는 결백하다

μ=0 실행이 증명한다. 붕괴 후 단층으로 퍼진 뒤:

```
frame 300 ~ 1800 :  avgSpeed 124.16   ← 1500프레임 내내 소수점 둘째까지 동일
```

**에너지가 정확히 보존된다.** 접촉 투영은 넣지도 빼지도 않는다.
→ 후보 B(일반 PBD 지터) 기각. 남은 건 마찰 하나.

### 기구 — Gauss-Seidel 안에서 도는 되먹임 고리

```
법선으로 밀침 → 침투량 갱신 → 그 침투량으로 마찰 예산 → 접선으로 밀침 → 새 겹침 → ↺
```

한 훑기 안에서 위치가 즉시 갱신되기 때문에 고리가 돈다. **μ가 클수록 이득이 커지고 1을 넘으면 발산.**
μ=0.7이 아슬아슬하게 버티고 1.0에서 넘어갔다.

순서 의존 자체도 같은 뿌리다. 대칭인 `A—B—C`에서 A—B를 먼저 처리하면 B가 왼쪽으로 0.1 밀린다 —
**대칭 입력에 비대칭 출력.** 그 잔여 이동이 `v = (x−x_prev)/dt`로 속도가 되고, 더미가 안 멈추는 이유가 된다.

### 결정 — Jacobi + 입자별 평균으로 교체

```
지금   접촉마다 즉시 Pos 수정        한 입자가 한 훑기에 6~12번 밀림
바꿈   Δ를 입자별로 누적 → 접촉 수로 나눠 한 번만 적용   (완화 계수 ω 추가)
```

| 얻는 것 | |
|---|---|
| 되먹임 고리 차단 | 모든 접촉이 같은 스냅샷을 본다. 훑기 중엔 침투량이 안 변한다 |
| 과보정 불가 | 접촉이 몇 개든 이동은 한 번 |
| **순서 무관** | 결정성이 알고리즘 구조에서 나온다 |
| **M0-b가 요구하는 형태** | Gauss-Seidel은 순차 의존이라 GPU 불가(graph coloring 필요). Jacobi는 그대로 병렬 |

대가는 훑기당 정보 전달이 접촉 한 칸 → **반복 수를 올려야 한다.** 그 비용이 재스윕의 질문이 된다.

## 실행 #4 — Jacobi 교체 후 재스윕 (2026-09-05)

솔버를 Jacobi + 입자별 평균으로 바꾼 뒤. **발산은 잡혔고, 다른 병이 드러났다.**

### 잡힌 것

```
Gauss-Seidel :  μ=1.0·1.3 은 다지기조차 못 끝냄 (30초 내내 부풂)
Jacobi       :  9실행 전부 유효. 다지기 420→215프레임, 최종 정지 851→432
```

μ를 1.3까지 올려도 안 터진다. 실행 #3의 되먹임 고리는 끊겼다.

### 드러난 것 — 마찰이 반복 횟수에 비례한다

| μ | 반복 | 벽 제거 | 최종 정지 | 최고점 | 중앙각 |
|---|---|---|---|---|---|
| 0.7 | 2 | 215 | 432 | 41.7 | 22.7° |
| 0.7 | 4 | 247 | 489 | 44.5 | 27.5° |
| 0.7 | 8 | 302 | 550 | 46.7 | 34.1° |
| 0.7 | 16 | 94 | 618 | 49.7 | 43.0° |
| 0.7 | 32 | 94 | 154 | **57.4** | 55.8° |
| 1.3 | 16 | 94 | 154 | **60.0** | 86.0° |
| 1.3 | 32 | 94 | 155 | **61.1** | 50.8° |

반복 16 이상에서 벽 제거가 94프레임에 일어나고(= 64프레임 만에 정지) **벽을 빼도 아무 일이 없다.**
최고점이 초기 기둥 높이(58.4) 그대로 — 마른 모래 기둥이 수직으로 서 있다. **수치적으로 굳었다.**

**반복 8의 34.1°는 수렴값이 아니라 지나가는 값이었다.**

### 원인

마찰 보정이 매 반복 `Pos − PrevPos`의 접선 성분을 **다시** 지운다. 이미 지운 것을 또 지운다.

```
반복마다 예산이 새로 주어짐  →  반복이 충분하면 접선 변위를 전부 지움  →  무한 정지마찰
```

μ는 도달점을 못 바꾸고 **몇 번째 반복에 도달하는지만** 바꾼다. 그래서 μ축이 계속 평평했던 것.

> 이건 [pbd-stiffness-compliance.md](../research/terms/pbd-stiffness-compliance.md)가 설명하는 병과 같은 구조다 —
> 실효 강성 `1−(1−s)ⁿ`. **강성은 컴플라이언스로 고쳤는데 마찰에는 같은 병이 남아 있었다.**

### 결정 — 접촉별 누적 임펄스 클램프 (= λ 기반 마찰)

```
지금   반복마다   |Δx_t| ≤ μ · Depth
바꿈   누적으로   |Σ Δx_t| ≤ μ · |Σ Δx_n|      예산 = μ·λn − λt
```

반복을 늘리면 같은 총량을 잘게 나눠 쓸 뿐이라 **반복 수와 무관**해진다.
그리고 λn은 서브스텝 동안 누적되므로 **하중이 큰 접촉일수록 예산이 커진다** —
실행 #1에서 "하중 정보가 마찰에 전달되지 않는다"고 한 문제가 여기서 풀린다.

필요한 것은 **서브스텝 동안 유지되는 접촉 목록**(`i, j, N, λn, λt`).
부수 효과로 이웃 탐색이 반복마다 → 서브스텝당 1회가 되어 **반복 비용이 거의 사라진다**
(반복 32가 실행당 86초 걸리는 게 대부분 이 탐색이다).
점착 결합(3-2)도 같은 목록 위에 얹는다.

## 논문 대조 — Müller 2020 §3.5–3.6 (2026-09-05)

실행 #4의 결정을 원문과 대조했다. 정리는 [papers.md C2](../research/papers.md).
**제안과 세 군데 달랐고, 전부 논문 쪽으로 간다.**

| | 실행 #4의 제안 | 논문 |
|---|---|---|
| 마찰 한계 | 예산 `μ·λn − λt` 만큼 **잘라서** 적용 | **게이트** — `λt < μs·λn` 이면 접선 변위를 통째로 지움 |
| 구조 | 위치 마찰 하나 | **정지마찰=위치 / 동마찰=속도** 로 분리 |
| 반복 | 몇 회가 적정인지 스윕으로 찾기 | **1회 고정.** 표 1이 전부 `iters/substep = 1` |

게이트 쪽이 단순하고 정지마찰의 물리("붙거나 미끄러지거나")에 가깝다.
총량이 `μs·λn`으로 묶이는 효과는 같다.

**동마찰이 우리에게 없던 것이다.**

```
Δv ← −(v_t/|v_t|) · min(h·μd·|f_n|, |v_t|)        f_n = λn / h²
```

`f_n`이 실제 법선력이라 **하중이 정직하게 들어온다** — 실행 #1의 "하중 정보가 마찰에 전달되지 않는다"의 진짜 해답이 여기다.

그리고 떨림에 대해 논문이 임계를 정해뒀다: 반발 `e = 0` if `|v_n| ≤ 2|g|h`.
**우리가 겪은 "정지인데 안 멈춤"에 대응하는 장치다.**

### 구현 목록

```
① 접촉 목록 { i, j, n, λn, λt }      서브스텝마다 λ 를 0으로
② 정지마찰 게이트  λt < μs·λn
③ 동마찰 속도 패스  Δv = −v_t/|v_t| · min(h·μd·λn/h², |v_t|)
④ 브로드페이즈 프레임당 1회 (반경 여유) + substep 20 × 반복 1
```

④ 덕에 서브스텝마다 돌던 27셀 탐색이 프레임당 1회가 된다.

## 실행 #5 — 논문 형태 마찰 (2026-09-05)

Müller 2020 형태로 다시 쓴 뒤. **두 가지가 확실히 고쳐졌고, μ는 여전히 안 움직였다.**

```
반복 의존   반복 1 vs 2 에서 28.2 vs 30.4°   (이전 22.7 → 55.8°)   ★ 해결
속도        8실행 8.5초  (이전 9실행 90초)                          ★ 브로드페이즈 프레임당 1회
μ 반응      0.3 → 1.0 에서 29.9 → 28.4°                            여전히 평평
```

### λ 초기화 시점 — 논문 문장의 두 독법

```
"At each substep ... we initialize λn and λt with zero"
```

**서브스텝마다 리셋**으로 읽으면 게이트 `λt < μs·λn` 이 첫 적용에서 항상 참이다(λt = 0).
**μ 가 검사에 참여조차 못 한다.** 위치 단계에서 접선 변위를 다 지우니 `v_t ≈ 0`이 되어
동마찰 패스도 할 일이 없다 — μ 가 개입할 자리가 양쪽 다 사라진다.

**접촉 생성 시 초기화**(= 프레임당 브로드페이즈)로 바꾸니 μ=0.3 에서 5° 내려갔다.
게이트가 작동은 하지만 0.5 이상에서 28°에 포화. **누적으로 읽는 쪽을 채택.**

## 실행 #6 — ★ 자 교정 (2026-09-05)

**측정기를 한 번도 검증하지 않았다는 것을 깨닫고 합성 원뿔로 교정했다.**

### 1차 — 자가 고장나 있었다

```
 실제 15/20/25/30/34° →  표본 0개.  측정 불가
 실제 40/45/55°       →  39.8 / 39.8 / 55.3
```

**통과 기준(34±3)이 있는 구간에서 표면 입자를 하나도 못 건졌다.** 원인 둘:

| | 문제 |
|---|---|
| 표면 판정 | "이웃 수 < **이 더미 중앙값의** 70%" — 얇은 더미는 중앙값이 이미 표면급이라 아무도 안 뽑힌다 |
| 제외 구간 | 바닥 15cm·꼭대기 반경 15cm **절대값** — 34° 원뿔은 전체 높이가 40cm다 |

### 2차 — 시험체가 문제였다

표면 판정을 **이웃 중심의 밀림 거리**(절대 기준)로, 제외 구간을 **더미 크기 비율**로 바꿨더니
전 구간에서 표본이 나왔지만 15~40°에서 4~6° 낮게 읽혔다.

**원인은 측정기가 아니라 합성 원뿔이었다** — 완벽한 격자로 만든 원뿔의 계단 표면.
jitter를 넣어 실제로 안착한 더미처럼 흐트러뜨리자 편향이 사라졌다.

> **검증용 시험체가 비현실적이면 멀쩡한 자를 불량으로 판정한다.**

### 교정 통과

```
 실제 | 프로파일  오차 | 법선중앙  오차
 15.0 |    14.7   -0.3 |    17.9   +2.9
 30.0 |    29.6   -0.4 |    29.2   -0.8
 34.0 |    33.2   -0.8 |    34.6   +0.6
 45.0 |    43.8   -1.2 |    45.4   +0.4
 55.0 |    55.3   +0.3 |    55.3   +0.3
```

독립적인 두 방식이 ±1~3° 안에서 일치. **자는 이제 믿을 수 있다.**

### 그런데 시험체가 또 틀렸다 — 더미는 원뿔이 아니다

검증된 자로 다시 재니 두 방식이 실제 더미에서 14° 벌어졌다(프로파일 17.4° vs 법선중앙 31.4°).
단면을 찍어보니:

```
반경  2.5 → 42.5cm :  42.1 → 37.5cm    평평한 꼭대기
반경 47.5 → 77.5cm :  34.7 → 20.4cm    옆면 ≈ 26°
```

**꼭대기가 평평하고 옆면만 경사졌다.** 전체 직선 맞춤은 평탄부에 끌려가고,
법선 중앙값은 꼭대기·옆면·자락이 섞인 분포의 중앙이다. **둘 다 옆면을 안 재고 있었다.**

### 문헌 확인 — 애초에 측정법이 틀렸다

[papers.md A-R](../research/papers.md) 신설. 요지:

- **안식각은 측정법마다 값이 다르다** (Al-Hashemi 2018). 값과 측정법을 함께 적어야 한다
- **기둥 붕괴는 안식각 측정법이 아니다.** 런아웃·최종높이를 종횡비의 함수로 보는 실험이고,
  퇴적물 경사는 종횡비와 **기둥반지름/입자지름 비**에도 의존한다 → 재료의 안식각과 같지 않다
- 구형 입자의 안식각은 구름 마찰에도 의존한다 (Zhou 2002). **우리 입자는 회전이 없어 문헌 밖**

### 결정

```
① 옆면만 재기        하강 구간에만 직선을 맞춘다 (평탄부·자락 제외)
② ★ 경사판 추가      중력을 서서히 기울여 사태 개시각을 잰다 — μ 교정은 이걸로
                     기둥 붕괴는 원래 목적(★덩어리 붕괴 3-2) 관찰용으로 남긴다
```

경사판(tilting box)은 **결정적이면서 문헌이 인정하는 표준 측정법**이고,
퇴적물 모양 해석이 필요 없다 — "언제 움직이기 시작하는가" 하나만 본다.

## 실행 #7~#12 — 경사판 구축과 솔버 재작성 (2026-09-05)

문서: 측정 프로토콜은 [papers.md A-R](../research/papers.md), 솔버는 [C4](../research/papers.md).

### #7 경사판을 세 번 다시 만들었다

| 형태 | 결과 | 왜 틀렸나 |
|---|---|---|
| 닫힌 상자 + 속도 판정 | `atan(μ)` 보다 +20~31° | 내리막 벽이 덩어리를 받친다. 기울이는 중엔 늘 미세 재배치가 있어 속도 임계가 오작동 |
| 열린 수로 + 변위 판정 | 전부 3° 에 걸림 | 열어두면 **내부 파괴 없이도 퍼진다.** 트리거가 사태가 아니라 퍼짐을 잼 |
| **닫힌 상자 + 정적 유지** | ★ 채택 | 각도마다 붙잡고 "정지하는가"를 묻는다. 기울기 속도라는 변수가 사라진다 |

정적 판정은 이분 탐색 8회로 0.3° 해상도. 다진 상태를 스냅샷해 모든 시험이 공유한다.

### #8 ★ 마찰의 최소 단위 시험 — 진단이 뒤집혔다

거친 바닥 위 입자 **하나**를 기울였다.

```
μ 0.1 → 1.88°   0.4 → 18.15°   1.0 → 41.33°   1.5 → 52.00°
오차가 μ 를 15배 바꾸는 동안 −3.7° 로 일정
```

**마찰 공식은 정상이었다.** 비례가 완벽하다. 무너지는 건 더미에서만이고,
차이는 하나 — 단일 입자는 접촉이 한 층이라 **하중 전달이 필요 없다.**

### #9 Jacobi vs Gauss-Seidel — 둘 다 실패

```
Jacobi   유효 마찰이 tan 8° 에서 포화     하중이 아래로 못 감
GS       μ 를 올릴수록 빨리 무너짐        에너지 주입 (실행 #3의 지문)
```

**C4 §6이 원인을 정정해줬다** — 고리의 출처는 GS의 즉시 갱신이 아니라 **PBD가 `v = (p−x)/h` 로
속도를 역산한다는 것**이다. 위치 보정이 곧 속도가 되므로, GS를 버려도 PBD인 한 고리는 남는다.

### #10 λ 누적 범위 — 반복도 서브스텝도 예산을 부풀렸다

```
λn  서브스텝·반복마다 무조건 쌓임 (중력이 계속 누른다)
λt  실제로 미끄러질 때만 쌓임
→ 범위가 프레임이면 둘 중 무엇을 늘려도 예산 μ·λn 만 커진다
```

실측: 서브스텝 5→20 에서 15.2° → 무한, 반복 1→16 에서 8° → 무한.
**범위를 스텝 하나로 맞췄다** (Catto 2005 / C4 §6). 그것만으로는 부족했고 —

### #11 ★ Sequential Positions 로 교체 (C4 §6 Algorithm 1)

```
이전   위치를 민다 → 반복 끝나고 v = (p−x)/h 로 역산
지금   Δλ 하나에서   v += W Jᵀ Δλ,  x += h·W Jᵀ Δλ
       잔차 r = kv·ν + (kc/h)·δ,  kv = 0.1
       접선은 2차원 원뿔 투영 |λt| ≤ μ·λn (누적 후 클램프)
```

**단일 입자가 지금까지 중 가장 정확해졌다** — 오차 −3.7° 상수 → **−0.9 ~ −2.5°**.
역산을 없앤 것 하나로 마찰의 절편 오차가 사라졌다.

### #12 ★★ 안정성 임계 — 그 아래 측정은 전부 무효였다

`λn` 깊이 프로파일을 재려다 발견했다. 6층(27.5cm) 더미를 수평에서 다지기만 했을 때:

| 반복 | 정지 | 최종 높이 | |
|---|---|---|---|
| 20 | 못 함 | 94.6cm | 부풂 |
| 30 | 못 함 | 79.1cm | 부풂 |
| **45** | 169프레임 | **27.5cm** | ★ 정상 |
| 60 | 152프레임 | 27.5cm | ★ |
| 90 | 411프레임 | 27.5cm | ★ |

**반복 45 미만은 부정확한 게 아니라 불안정하다.** 그 아래에서 잰 각도는 터지는 더미 위의 값이다.
μ 축이 역전으로 보였던 것도 이것 — 강한 재료일수록 더 심하게 터지고 있었다.

이걸 알고 나니 모멘텀 판정도 뒤집혔다.

```
불안정 영역(it=30)   a=0 → 18.2°,  a=0.5 → 9.2°     둘 다 무의미
안정 영역(it=60)     a=0 → 10.3°,  a=0.5 → 18.5° ★  모멘텀이 오차를 −11.6 → −3.3° 로
```

> **터진 더미 위에서 판단하면 결론의 부호가 뒤집힌다.** 이번 세션에서 두 번 겪었다
> (자 교정의 격자 계단, 안정성 임계). 계기를 먼저 검증하라는 원칙이 두 층 더 필요했다.

## 실행 #13~#15 — 붕괴 판정이 −3.5° 를 만들고 있었다 (2026-09-06)

근거 문헌은 [papers.md §A-R4~A-R6](../research/papers.md).

### #13 크리프 계측 — 임계 이하에서도 안 멈춘다

`μ=0.4`(임계 17.6°)에서 **5°로 붙잡고 16초**. 물리적으로는 확실히 버텨야 하는 각이다.

```
 초 | 누적변위(cm) | 평균속력(cm/s)
  1 |     0.0156  |     0.361
  4 |     0.0785  |     0.288
 16 |     0.4978  |     0.144
```

**두 양이 다르게 움직인다.** 평균 속력은 죽어가는데(0.36 → 0.14) 초당 변위는 6초 이후
0.035 cm/s 로 일정하다 — **흔들림은 잦아들고 방향성 드리프트만 남는다.**

```
정상 상태 드리프트   0.035 cm/s = 스텝당 5.8μm
판정이 요구하는 것   4초에 0.5r = 스텝당 52μm
```

5°에서는 9배 모자라 오판이 안 난다. 하지만 **크리프 기구는 실재한다.**

> 램프 직후 60μm/스텝은 정상 크리프가 아니라 전이다. **램프 1초로는 전이가 안 끝난다.**

### #14 ★ 유지 시간 스윕 — 크리프 오판 확정

사태라면 유지 시간과 무관해야 한다.

```
유지 시간    μ=0.3            μ=0.4
 1초        15.72° (−0.98)   20.10° (−1.70)
 4초        13.81° (−2.89)   17.64° (−4.16)
16초         8.07° (−8.63)    9.16° (−12.64)
```

**단조 감소 = 판정이 사태가 아니라 크리프 누적을 재고 있다.**

그리고 뜻밖의 소득 — **유지 1초에서 오차가 −1.0 / −1.7°.**
단일 입자 시험의 −0.9~−2.5° 와 같은 크기다.
**솔버의 마찰은 이미 1~2° 안에서 맞았고, −3.5° 는 전부 판정이 만든 것이었다.**

### #15 판정 4종 — 실패 방식이 매번 달랐다

| 판정 | 유지 시간 무관 | μ 단조 | 실패한 지점 |
|---|---|---|---|
| 누적 변위 > 0.5r | ✗ | ○ | 크리프를 사태로 읽음 (#14) |
| §2-2 그대로 | ○ | ✗ | **60프레임 "연속" 이 스파이크 한 번에 부러진다.** 구간 평균은 임계의 1/10인데도 거의 모든 각이 "정지 못 함" |
| 앞/뒤 속도 비교 (전체) | ○ | ○ | 닫힌 상자의 **벽에 눌린 입자**가 섞여 안 죽는다 → 1°에서도 무너짐 |
| **앞/뒤 속도 비교 (중앙 60%)** | △ | ○ | 창이 길면 앞뒤 평균이 가까워져 **잡음이 부등호를 결정** |

채택(중앙 60% · 유지 4초)의 실측:

```
μ=0.2 → 7.25° (−4.06)    μ=0.3 → 13.26° (−3.44)    μ=0.4 → 17.64° (−4.16)
```

오차가 균일하고 단조다. 다만 유지 2/4/8초에서 값이 흔들린다(μ=0.4: 22.8 / 17.6 / 15.2).

> **한 시험으로는 못 걸렀다.** 유지 시간 스윕과 μ 단조성을 **둘 다** 봐야 네 판정이 갈렸다.
> 어느 하나만 봤으면 §2-2(유지 시간 무관)나 변위(μ 단조)를 통과시켰을 것이다.

### 판단 — `θ_start` 측정은 원리적으로 취약하다

네 판정이 전부 같은 자리에서 흔들렸다. **개시각은 "아무 일도 없음"과 "막 시작함"의 경계**라
판정이 언제나 잡음과 크리프 위에 놓인다.

**대안은 `θ_stop`** ([A-R5](../research/papers.md)):

```
θ_start   정지 상태에서 기울여 개시를 본다      경계가 흐리다
θ_stop    흐르는 상태에서 각을 낮춰 멈춤을 본다  끝 상태. 경계가 뚜렷하다
          두 곡선은 모양이 같고 약 1° 차이
```

흐르던 것이 멈추는 것은 크게 움직이다 완전히 서는 것이라 **크리프와 혼동될 여지가 없다.**
Pouliquen 이 `h_stop` 을 "흘려보낸 뒤 남은 층 두께"로 정의한 것과 같은 성질이고,
우리 다지기 단계가 이미 그 과정이다.

## 실행 #16 — 재는 값이 틀렸다 (`θm` vs `θr`) (2026-09-06)

실행이 아니라 판단이다. [A-R4](../research/papers.md) 를 우리 문서에 대조한 결과.

### 각도가 하나가 아니었다

```
θm  최대안정각   정지한 더미가 무너지기 시작하는 각    ← 경사판이 재는 것
θr  안식각      사태가 끝난 뒤 남은 표면의 각          ← 34° 가 가리키는 것
                2~5° 차이 (Jaeger 1989)
```

**`talusDry` 34° 가 `θr` 이라는 근거 둘:**

1. 문헌 표의 "모래 안식각"은 부어 쌓은 더미의 경사다
2. **[열침식](../research/terms/thermal-erosion.md)의 정의가 결정적** — `경사 > talus 면 아래로 옮긴다`.
   옮기기를 멈추는 각이 `talusDry` 이므로 정의상 "흐른 뒤 남는 각" = `θr`

→ **경사판으로 `θm` 을 재서 `θr` 기준과 비교하고 있었다.** 오늘 쫓던 −3.5° 와 같은 크기의
계통 오차이고, 방향도 나쁘다 — 기준을 `θm`(36~39°)으로 올리면 격차가 **더 벌어진다.**

### 격자와 입자의 구조적 차이 — 결함이 아니라 존재 이유

```
격자   각도 하나뿐. talus 보다 가파른 경사를 만들 수 없다        이력 없음
입자   θr ~ θm 사이에서 불안정하지만 서 있는 상태를 가진다        이력 있음
```

**이 이력이 ★덩어리 붕괴(3-2)가 요구하는 "버티다 갑자기 무너진다"의 물리적 정체**이고,
하이트필드로는 낼 수 없어서 입자 계층을 도입한 이유다.

### 그리고 우리가 한 것은 부어 쌓기가 아니었다

```
문헌 hollow cylinder   원통을 천천히 들어올린다  →  준정적  →  원뿔  →  θr
우리 기둥 붕괴          벽을 한순간에 없앴다      →  관성    →  평평한 꼭대기 + 옆면
```

**"천천히"가 방법의 전부**였고, 종횡비도 어긋나 있었다 —
`H/R=1` 에서는 안쪽 심이 안 무너져 원뿔이 안 나온다(단면 실측이 그것이었다).

> **자는 원뿔로 검증했는데 시험체가 원뿔이 아니었다.** 실행 #6의 자 교정이 합성 원뿔
> 15~55° 를 ±1~3° 로 통과했다 — **원뿔을 주면 잘 재는 자를 만들어놓고 원뿔 아닌 것을 재고 있었다.**

### 문서의 "부어 쌓기 기각" 근거는 시뮬에서 약하다

원 문구: *"쏟는 속도·낙하 높이·구멍 크기가 전부 변수라 두 번 돌려도 다른 더미가 나온다"*
— **실험실 논리다.** 시드를 고정한 시뮬은 바이트 단위로 재현된다.
남는 것은 "결과가 그 변수에 의존한다"인데, 경사판은 임의 상수가 **더 많다**
(유지 시간·트리거·관찰 구역·이분 탐색).

### 결정 — `θr` 은 원통 들어올리기로, `θm` 은 경사판으로

절차는 [m0-spike.md §3-0-D](m0-spike.md) (당시 3-0-A, #20에서 기각). 요점:

```
계단식으로 들어올리고 매 단계 완전히 멈춘다   → 준정적이 정의상 보장, 속도 변수가 사라진다
종횡비 H/R = 2.5                            → 원뿔이 나온다 → 검증된 자를 그대로 쓴다
판정은 프로파일·법선 두 방식 교차            → 3° 안에서 일치해야 원뿔이다
```

경사판은 버리지 않는다 — `θm` 을 재고, **`θm − θr` 이 곧 이력 폭**이라 3-2의 극적임을 예고한다.

### #18 ★★ 벽 제약이 SP 규약을 어기고 있었다

```cpp
// SolveWalls — 위치만 자르고 속도는 그대로
Pos[i].X *= Sc;  Pos[i].Y *= Sc;
```

SP 의 핵심은 **임펄스 하나에서 `v` 와 `x` 를 함께 내는 것**인데 벽만 위치를 잘랐다.
낡은 속도가 다음 스텝에 다시 벽을 파고들고 그 보정이 `v` 로 환원되지 않아 **에너지가 쌓인다** —
실행 #11에서 없앤 바로 그 고리를 벽에서 되살린 꼴이다.

PBD 경로에서는 어차피 속도를 역산했으므로 무해했고, 6층 상자는 벽 접촉 비율이 작아 안 드러났다.
좁은 원통(반경 12입자)에 18층 하중이 걸리자 크게 터졌다.

`SolveWallsSP` 로 교체 후:

```
78cm → 63cm 로 다져진다     입방 충전 0.52 → 조밀 0.64 의 19% 수축과 일치
```

> **솔버 규약을 바꿀 때 일부만 바꾸면 안 바꾼 쪽이 통째로 오염원이 된다.**
> 지면은 `SolveGroundSP` 로 옮기고 벽은 "형틀은 비계니까"라며 남겨둔 판단이 틀렸다.
> 같은 계 안에 있으면 비계도 같은 규약을 따라야 한다.
> **경사판 결과(`θm`)도 상자 벽이 같은 결함일 때 잰 것이라 재측정이 필요하다.**

### #19 거친 바닥의 범위 + 새 계기

**거친 바닥이 기둥 밑에만 깔려 있었다.** 고정층 반경 31cm, 퇴적 원뿔 반경 63cm —
바깥 절반이 매끄러운 지면 위라 **바닥 마찰이 반경에 따라 달라졌다.**
기울기가 둘인 퇴적물이 되어 두 측정 방식이 6~8° 어긋났다.
→ 고정층을 기둥 반경의 2.5배로 확장(`BaseRadiusScale`). 문헌의 rough plane 은 더미보다 넓다.

**★ 잡음 바닥 — 가장 값싼 계기**

기울이지 않은 수평 상태에서 10초. 물리적으로 완전히 정지해야 하므로 남는 속력은 전부 솔버 잡음이다.

```

반복  90 :  0.0069 → 0.0055       ← 내려간다 = 수렴
```

반복 90의 바닥은 `√(gd)` 대비 **7×10⁻⁵** 로, 새 임계 `ε=0.002` 보다 **28배 아래**다.
**임계는 문제가 아니었고 반복 45가 이 장면에서 수렴하지 않는 것이 문제였다.**

> 기둥을 통째로 다져보는 것보다 훨씬 싸다. **10초 돌려 부호와 기울기만 보면**
> 그 설정이 쓸 만한지 알 수 있다. 새 장면·새 설정마다 이것부터 통과시킬 것.

## 실행 #20~#22 — 원통 들어올리기 기각, 부어 쌓기로 (2026-09-06)

### #20 계단식 들어올리기는 원리적으로 실패한다

계단별 계측을 넣고 나서야 보였다.

```
계단 | 높이 | 정지프레임 | 최대속력 | 최고점 | 이동입자
   1 |  5cm |    780     |    35    |  66.0  |     0
   2 | 10cm |   3000★    |   299    |  62.5  |   322
   3 | 15cm |   3000★    |   650    |  51.6  |  1599
   4 | 20cm |   3000★    |   450    |  39.3  |  1621
   5 | 25cm |    711     |    65    |  37.9  |  1622   ← 이후 12계단은 빈 작업
```

**바닥 15cm 를 푸는 순간 기둥 전체가 한 번에 무너진다.** 최대속력 650 cm/s 는 준정적이 아니다.

계단식의 전제는 "조금 풀면 그만큼만 움직인다"인데, **높은 기둥은 밑동이 풀리면 위 전체가
지지를 잃는다 — 파괴가 국소적이지 않다.** 계단을 잘게 나눠도 임계 노출량에서 똑같이 간다.

최종 단면이 결과를 말해준다:

```
반경 2.5cm → 29.0    12.5cm → 31.5    22.5cm → 31.2      최고점 34.2
```

**중심이 가장 낮다.** 원뿔이 아니라 가운데가 꺼진 둔덕 — 격렬한 붕괴가 모래를 바깥으로 던졌다.

> **상충** — 높은 기둥(H/R 2.5)은 한 번에 붕괴하고, 낮은 기둥(H/R 1.0)은 평평한 꼭대기가 남는다.
> **원통 들어올리기로는 이 상충을 못 벗어난다.**

### #21 부어 쌓기 — 불안정 상태를 만들지 않는다

```

부어   더미를 한 알씩 키운다                →  불안정 상태가 존재한 적이 없다
```

문서가 기각했던 근거("쏟는 속도·낙하 높이가 변수")는 **실험실 논리**였다 — 시드를 고정한
시뮬은 재현되고, 그 변수들은 무관성 검사로 확인하면 된다. 경사판은 임의 상수가 오히려 더 많았다.

## 실행 #23 — 2074 cm/s 의 정체: 생성 높이가 여전히 폭주하고 있었다 (2026-09-09)

### 계기 — 사건 검출기

붓는 중 최대속력이 충돌 속도 √(2gh) 의 N배를 넘는 **새 기록**이 나올 때마다 그 입자의
위치·이전 위치·속도·접촉 목록(상대, gap, λn, λt)을 찍는다(`-event=3`).
반복별 추적(`-traceframe/-traceidx`)도 함께 넣었지만 쓸 일이 없었다 — 첫 출력에서 끝났다.

```
[event 0] 프레임  46  |v| 310 (3.1배)  나이 18프레임  #590  v(0 0 −310)  접촉 8개 전부 gap>0 λn=0
[event 1] 프레임  64  |v| 376 (3.8배)  나이 22프레임  #603  v(0 0 −376)  접촉 10개 전부 gap>0 λn=0
[event 2] 프레임  89  |v| 457 (4.6배)  나이 27프레임  #623  v(0 0 −457)
[event 3] 프레임 115  |v| 555 (5.6배)  나이 33프레임  #643  v(0 0 −555)   이 시점 더미 "높이" 244cm
```

**넷 다 접촉이 하나도 없는 수직 자유낙하다.** 속도가 정확히 g × 나이(33프레임 → 539 cm/s)고,
사건마다 나이가 늘어난다. 솔버가 만든 속도가 아니라 **높은 데서 오래 떨어진 것**이다.
677개를 부었는데 최고점이 244cm — 생성 높이가 폭주하고 있었다.

### 원인 — 공중 입자가 기준점이 된다

#22 의 수정은 생성 높이 기준을 "전체 최고점"에서 "축 근처 최고점"으로 **범위만 좁혔다.**
축 근처에는 **방금 놓은 입자**가 있다. 2프레임 뒤 그 입자는 0.5cm밖에 안 떨어졌고,
다음 입자는 그 위 1지름에 놓인다 — 놓을 때마다 4.5cm 씩 올라가는 사슬이다.
낙하 높이가 클수록 사슬의 한 칸이 커지므로 최대속력이 낙하 높이에 비례했던 것도 이것으로 설명된다.

→ 기준을 **정지한 입자만**(|v| < 0.1·√(g·d) ≈ 7 cm/s)으로. 방금 놓은 입자는 한 프레임 뒤 16 cm/s 라 자동으로 빠진다.

```
                    붓는중 최대   프로파일   법선중앙   차이    시간
낙하 1d   전(#22)      2074        27.7°      36.3°     8.6    64초
          후            238        30.0°      37.9°     8.0    23초
낙하 3d   전(#22)      3675        28.3°      35.0°     6.7    65초
          후            285        29.7°      37.7°     8.0    24초
```

최대속력이 충돌 속도의 2.4배(1d)·1.7배(3d)로 내려왔고, 각도가 낙하 높이에 **무관**해졌다 — 무관성 검사 하나 통과.
실행 시간이 1/3로 준 것은 공중에 떠 있던 입자들이 사라진 결과다.

> **같은 결함을 두 번 고쳤다.** #22 에서 "튄 입자가 기준을 올린다"를 봤으면서 범위를 좁히는
> 것으로 끝냈다. 기준이 잘못된 것은 **어디**가 아니라 **무엇**(정지한 것)이었다.

### 남은 것 — 퇴적물이 원뿔이 아니라 메사다

두 판독의 차이는 8.0°로 오히려 벌어졌다. 최종 위치를 CSV로 떨어뜨려(`-dumppos`) 오프라인으로 봤다.

```
충전율 0.59 (r<20, 5<z<20)     정상 밀도. 겹침 최대 0.05cm, 떠 있는 입자 0
배위수 평균 4.5                 접촉 gap 중앙값 0.000 — 다 붙어 있다
```

밀도는 물리적이다. **모양이 문제다.** 5cm 셀별 표면 높이:

```

r 10~20   27.1   │  기울기 9°  — 평탄한 꼭대기
r 20~30   25.6   │
r 30~40   22.2   ┘
r 40~50   15.5   ┐  기울기 36° — 옆면
r 50~60    7.4   ┘
```

**꼭대기가 반경 35cm까지 평평하고 옆면만 36°다.** 프로파일 직선 맞춤(30°)은 평탄부와 옆면을 평균한 것이고,
법선 중앙값(37.9°)은 넓이가 큰 옆면을 잡는다. 둘 다 제 할 일을 했다 — 시험체가 원뿔이 아니다.
기존 "반경 구간별 최고점" 단면은 튄 입자 하나가 구간을 대표해 이 모양을 못 보여줬다.

가설: 착지 충격의 횡방향 튐이 재료를 착지 지점 밖으로 밀어낸다. 판별: 낙하 높이 × 산포 반경 스윕.

```
낙하  산포   프로파일  법선중앙  차이
 1d   0.5d    32.7°     36.0°    3.3
 1d   1.5d    32.4°     36.3°    4.0
 1d   2.5d    30.0°     37.9°    8.0
 2d   0.5d    34.5°     33.1°    1.4
 2d   2.5d    29.5°     36.0°    6.5
```

**산포 반경이 결정 변수고 낙하 높이는 아니다.** 충격 가설은 기각 — 평탄 꼭대기는 착지 발자국이었다.
산포 0.5d(점 공급원)로 확정. 낙하 0.25·0.5d 는 1.05D 여유를 영원히 못 찾아 **무한 루프**였다
→ 붓기 루프에 정체 상한(600프레임) 추가.

## 실행 #24 — 각도가 입자 수·반복 수를 따라간다: 크리프 (2026-09-09)

산포 0.5d 로 두 판독이 맞았으니 통과인가? **입자 수를 바꿔봤다.**

```
입자   600 :  42.1° / 40.9°    높이 38.5  반경 55
입자  1200 :  32.7° / 36.0°    높이 37.2  반경 70
입자  2400 :  26.0° / 27.9°    높이 41.3  반경 85
```

**높이가 40cm 에서 멈추고 반경만 늘어난다.** 크기에 따라 변하는 각은 재료 상수가 아니다.
같은 더미를 반복 수·μ·유지 시간으로 찔러봤다 (`-hold=1800`: 정지 판정 뒤 30초 더 돌리고 다시 잰다).

```
반복  45 :  23.5°   유지 후 19.8°   높이 29.9 → 26.6     크리프 |v| 0.086 cm/s
반복  90 :  32.7°   유지 후 24.5°   높이 37.2 → 29.9              0.079
반복 180 :  43.8°   유지 후 36.9°   높이 51.3 → 40.9              0.078

μ 0.4 / 0.7 / 1.0 / 1.5  (반복 90) :  31.0° / 32.7° / 31.4° / 32.0°     ← μ 무관
```

**각도는 반복 수에 비례하고 μ 와 무관하다.** 그리고 "정지"한 더미가 30초에 7cm 주저앉는다.
재고 있던 것은 안식각이 아니라 **천천히 무너지는 더미의 스냅숏**이었고, 그 높이를 정하는 것은 마찰이 아니라 솔버 수렴도다.

### 서브스텝은 안 듣는다

Müller 2020 의 처방(반복 대신 서브스텝, 잔차 ∝ h²)을 시험했다.

```
ss×it   2×9   5×9   10×9   20×9   5×18   5×36   10×18   10×36   1×90   1×180
합계     18    45     90    180     90    180    180     360     90     180
각도    13°   21°    23°    29°    24°    32°    29°     38°    33°     44°
크리프  0.12  0.11  0.079  0.094  0.095  0.085  0.085   0.089  0.079  0.078
```

**각도는 총 반복 수만 따라가고 크리프는 전부 0.08~0.12.** 서브스텝의 h² 이득이 없다.
이유 — SP 는 속도를 다음 스텝으로 넘긴다. 미수렴 잔차는 위치가 아니라 **속도**에 남고,
(잔차 비율) × (프레임당 중력 임펄스) 는 서브스텝으로 쪼개도 합이 같다.
PBD 에서 서브스텝이 듣는 것은 위치 잔차라서다. **우리 크리프는 위치 잔차가 아니다.**

### 워밍 스타트 — 크리프가 사라진다

매 서브스텝 λ=0 에서 시작하던 것을, 직전 λ를 속도 임펄스로 먼저 적용하고 거기서 반복하게 했다
(Catto 2005, [terms/warm-starting.md](../research/terms/warm-starting.md), papers C3 결론 3번).

```
                          각도       크리프      유지 30초 높이
차가운 시작   μ0.4        31.0°     0.08         −7cm
워밍 (전부)   μ0.4        51.7°     0.0017       0.0cm   ← 크리프 50배 감소
워밍 법선만   μ0.4        43.2°     0.099        −8cm    ← 크리프 그대로
```

**크리프의 정체는 접선(마찰) 잔차다** — 법선만 워밍하면 그대로고 접선까지 워밍하면 사라진다.
정지마찰이 스텝 안의 상대 변위만 막고 `PrevPos` 가 매 스텝 리셋되니, 미수렴 잔차가 영구 미끄러짐으로 굳던 것이다.

그런데 더미가 **52~62°로 서고 μ와 무관하다.** μ=0 조차 39~45°.
접선 재투영·원뿔 재클램프, 닿은 쌍만 워밍(`gap ≤ 0.05cm`), Kv 0.1→1.0 을 차례로 시험 — 전부 무효.
하중 검산(바닥 수직 임펄스 합 / 무게 = **1.00~1.07**)으로 λn 인플레이션도 배제.

→ 남은 것: **각도가 반복 수에 무관해졌다.** μ=0.2 에서 반복 45/90/180 → 40.2 / 40.9 / 39.7°.
자가 처음으로 μ 만 재고 있다. μ 단조: 0.1→34°, 0.2→41°, 0.3→45°, 0.4→52°, 0.7→61°.

## 실행 #25 — 45°의 정체: 정사각 격자 바닥이 결정을 키웠다 (2026-09-09)

```
                    내부 배위수   충전율
워밍 μ0.1            10.1        0.70     ← 결정 (FCC 12 / 0.74)
```

→ 바닥 격자에 무작위 흔들림(`BaseJitter`, 반경 배수).

```

       흔들림 0.6  :  27.5° / 29.9°   차이  2.3
μ0.3   흔들림 0/0.3/0.6 :  45~47°     차이 1~2    ← 결정화 없던 구간, 변화 없음
```

이 모델의 안식각은 μ=0.1→29°, 0.3→46° — 회전이 잠긴 구의 기하학적 맞물림 위에 마찰이 얹힌다.
**34°는 μ≈0.15 근처.** 단일 입자 시험은 변함없이 통과(−0.9~−2.5°).

> **"검증용 시험체가 비현실적" 패턴의 다섯 번째.** 이번엔 거친 바닥 자체였다.
> Goujon 2003 의 rough plane 은 *무작위* 거칠기다. 격자 거칠기는 거칠기가 아니라 템플릿이다.

> **경사판(θm)도 같은 병을 앓고 있었다.** 차가운 시작으로 μ=0.1/0.3/0.7 전부 70°까지 안 무너진다 —
> #18 벽 수정 뒤 재측정을 안 한 채 남겨둔 값이었고, 바닥 흔들림이 0.05R 뿐이다. 워밍 + 흔들림으로 재측정할 것.

## 실행 #27 — 점착 결합 구현과 점착의 자 (2026-09-09)

설계와 근거는 [m0-spike.md §2-6](m0-spike.md). 구현 순서는 테스트 먼저 — 솔버를 비운 채 빌드해 실패를 본 뒤 채웠다.

### 단위 검사 — 구현 전 실패, 구현 후 통과

```
                    생성  살아있음  끊김   기대 늘어남   실측     판정
사슬 1 (구현 전)      1      1       0     1.000cm    92.5cm   실패 — 바닥까지 떨어짐
사슬 1 (구현 후)      1      1       0     1.000cm    1.000cm  ★ mgα 그대로
사슬 2                2      1       1                         ★ 위 결합(무게 2 > 1.5) 파단
사슬 3                3      2       1                         ★
```

워밍 on/off 모두 같다. XPBD 컴플라이언스의 고정점 `C = mg·α` 가 반복 90 안에 잡힌다.

### 점착의 자 — 절토 높이 스윕 (`-cut`)

닫힌 상자에 격자 채움 → 마른 채 다짐 → `W=0.15` 로 결합 → +X 벽만 제거 → 30초. Terzaghi `H_c = (4c/γ)·tan(45°+φ/2)` 로 역산.

**시험체 결함 둘을 먼저 잡았다.**

| 결함 | 증상 | 수정 |
|---|---|---|
| 자유 격자 흔들림 0.3R 이 간격 D 에서 **초기 겹침 1.5cm** | 5층이 25cm 아닌 37cm, 충전율 0.35 — 솔버가 침투를 밀어내며 부풂 | 자유 격자 간격 `D + 2J`. 바닥만 흔들던 부어 쌓기는 무사했던 이유 |
| 결합 휴지 길이 = 현재 거리 (침투 쌍은 < D) | 벽을 열자 12층 높이가 **46 → 81cm 로 솟음** — 결합은 D 아래로 당기고 접촉은 D 로 밀어 매 반복 다툼 | 휴지 길이 하한 D. 인장만 받는 결합은 D 에서 시작해야 한다 |

그리고 계측 둘: 높이는 최고점이 아니라 **98 백분위**(#23 단면의 교훈 그대로), 붕괴 판정은 면 띠가 아니라 **전체 이동비 15%**
— 벽에 기대 있던 바깥 열이 떨어지는 표피 탈락(6층: 면 25%, 전체 4%)을 활동면 파괴와 가르기 위해서.

**BondStrength 1.5 (Rumpf 역산값)**

```
 층   높이     결합 생성/끊김   면 이동  전체 이동  런아웃   판정
  6   17.1cm    2280 /   37     24.8%     3.8%    11cm    섬 (표피 탈락)
  9   28.7      3704 /  460     45.2%    21.4%    26      ★ 붕괴
 12   37.6      5181 / 1134     66.8%    39.6%    31      ★ 붕괴
 15   45.7      6619 / 2871     81.9%    73.0%    40      ★ 붕괴
```

**H_c ≈ 17~29cm → c ≈ 270~430 Pa.** Rumpf 상한(1561 Pa)의 1/4~1/6.
이건 결함이 아니라 문헌이 예고한 값이다 — Kendall 1988: 순차 파단 때문에 Rumpf 는 2~5배 과대,
거기에 우리 충전율 0.45(ε 0.55 → `(1−ε)/ε` 0.82, 설계 가정 1.5)를 곱하면 170~430 Pa. **자가 예측 범위 안을 읽었다.**
그래서 §2-6 ⑥ 대로 `BondStrength` 는 시작값이고 여기서 교정한다: `c ∝ F` 이므로 1.5 kPa 에 ≈ 5 가 필요하다.

**교정 스윕 — 강도를 5배 올려도 H_c 가 30% 밖에 안 오른다**

```
BondStrength   9층(29cm)  12층(38cm)  15층(46cm)  18층(53cm)   H_c        c
   1.5          붕괴        붕괴        붕괴          —        17~29cm   270~430 Pa
   3            붕괴(16%)   붕괴        붕괴        붕괴       17~29     270~430
   5            섬          붕괴        붕괴        붕괴       29~38     430~590
   8            섬          붕괴        섬(15%)     붕괴       29~38     430~590   ← 높이에 비단조
```

Terzaghi 대로면 `H_c ∝ c ∝ F` 인데 **강도에 거의 반응하지 않는다.** 전단 파괴가 아니다.

판정도 바꿨다. 이동비는 표피 탈락과 활동면을 못 가르므로 **상단 띠(표면 1D 제외)의 95백분위 X 후퇴 > 2D** 로.

**장치가 아니라 μ 0.13 의 무작위 성긴 충전이 준안정 상태를 못 벗어나는 것이다.** 회전이 잠긴 구는 마찰이 낮으면 소산이 거의 없고,
격자 블록은 규칙적 충전이라 그 문제가 없다(#27 의 절토 자가 격자에서 잘 돌았던 이유). 부어 쌓은 열린 더미가 멀쩡했던 것은 사면이 안식각으로 흘러내려 스스로 안정화했기 때문이다.
→ **준비 단계 전용 속도 감쇠**(DEM local damping, 프레임당 5%). 붓기·다지기·정지에만 걸고 준비 창부터 끈다 — 감쇠 없이 정지해 있어야 준비다.

**감쇠는 실패했다 — 두 방향 모두.** 붓기부터 걸면 재배치 속도까지 죽여 충전 0.40(84cm)으로 얼어붙고, 마지막 정지에만 걸면
얼렸다가 준비 창에서 끄는 순간 **순환이 다시 시작**해 열 창 동안 42~54%. 준안정 이완이면 감쇠 뒤 정지가 유지됐어야 한다.
**자립하는 에너지원이다.** 열린 더미(#26)와 격자 블록(B)은 조용하므로 조합은 "무작위 충전 + 상자 벽 + 낮은 μ".
후보: 살짝 떨어진 쌍에 남는 워밍 λ(허용 gap 0.05cm)의 반발 킥이 갇힌 계에서 소산되지 못한다. 워밍 허용 0 / 워밍 끔 / Kv 1.0 으로 가른다.

```
(a) 워밍 허용 gap 0     →  55~60%     그대로
(b) 워밍 끔             →  27~37%     그대로 (조금 덜하고 −4cm 주저앉음)
(c) Kv 1.0              →  49~55%     그대로
```

**솔버 쪽 변수는 전부 소거.** 남는 것은 마찰 없는 상자 벽 — 벽에 붙은 층이 수직으로 자유롭게 미끄러지는 경로.
격자 블록은 규칙적이라 벽 층도 맞물려 있고, 열린 더미는 벽이 없다. → 형틀 벽에 Coulomb 마찰(`WallFriction`, 지면과 같은 구조).

```
벽 μ 0.13   →  17~44%     거의 그대로
벽 μ 0.5    →   2~16%     크게 줄지만 남고, 감쇠 안 함
```

**벽은 원인의 일부다.** 벽 마찰이 Janssen 효과로 바닥 하중을 덜어 주니 줄어든 것으로 읽힌다 — 즉 순환은 **하중**을 따라간다.
격자 블록도 21층(59cm)은 조용하고 24층부터 끓었다. 하중이 눌러 대는 곳은 **바닥**이고, 바닥 격자는 흔들림 0.3R 로 **고정 구끼리 겹쳐** 있다.
겹친 두 고정 구 사이 홈에 앉은 자유 입자는 두 접촉을 동시에 만족할 수 없어 솔버가 영원히 밀어 올리고 내린다 — 하중이 클수록 심하게.
→ 바닥 흔들림 0 / 0.1 로 가른다.

```
바닥 흔들림 0.1  →  37~59%     그대로
바닥 흔들림 0    →  38~60%     그대로
```

바닥도 아니다. 소거표:

| 후보 | 결과 |
|---|---|
| 워밍 허용 gap · 워밍 자체 · Kv | 그대로 |
| 바닥 격자 겹침 | 그대로 |
| 벽 마찰 | 0.5 에서 50% → 2~16%. **부분** |
| μ | 0.5 에서 0%. **결정적** |
| 높이 | 격자 21층(59cm) 조용 · 24층(70cm) 끓음 |

남은 구분: **높이(하중) 자체인가, 상자 구속인가.** 조용했던 열린 더미는 40~50cm 였다. 열린 더미를 6000개(≈70cm)로 쌓아 가른다 —
끓으면 이 모델의 낮은 μ 재료는 자기 무게 60cm 위에서 불안정하다는 뜻이고, 그건 절토 자가 아니라 **설계의 문제**다(1~2m 성).

```
열린 더미 6000개 (66cm, μ 0.13, 반복 90)  →  크리프 0.004 · 높이 변화 0 · 불평형비 3×10⁻⁵.  조용하다
```

**높이가 아니라 상자다.** 그리고 소거표를 다시 보니 답이 코드에 있었다 — 워밍 스타트(#24)에서 접촉과 지면 λ 는 이어받게 했지만
**벽 λ 는 매 서브스텝 0 으로 지우고 있었다.** 벽에 눌린 입자는 횡압 지지를 매 스텝 처음부터 다시 쌓고, 그 미수렴 잔차가 #24 의 크리프와
같은 기제로 벽 층을 흔든다. 횡압은 높이에 비례하니 60cm 위에서 터지고, 벽 마찰이 그 잔차를 소산시켜 줄어든 것도, μ 0.5 가 잠재운 것도 맞는다.
격자 블록은 규칙적이라 벽 층이 맞물려 덜 흔들렸을 뿐이다.

> **#18 과 같은 실수를 되풀이했다.** 그때는 벽만 SP 규약에서 빠졌고, 이번엔 벽만 워밍에서 빠졌다.
> "규약을 바꾸면 전부 바꿔야 한다"를 두 번째로 어겼다 — 형틀은 비계라는 생각이 두 번 다 원인.

→ 벽 λ 를 **벽별(±X·±Y)로** 들고 워밍한다. 한 스칼라에 네 벽을 섞어 쌓던 것도 이 참에 고친다.

(부수 관측: 6000개 더미가 29.5° — 1200개의 32.9° 보다 3° 낮다. 시드 하나라 미상. μ 0.13 의 크기 의존이 남아 있을 수 있어 #26 의 무관성을 6000 에서 재확인할 것.)

```
벽 워밍 뒤 붓기 60cm 블록 :  준비 첫 창 0.0% · 드리프트 0 · 충전 0.55 · 실행 500 → 65초
```
