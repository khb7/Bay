## 상태 (칸마다)

| 채널 | 뜻 | 형식 |
|---|---|---|
| `b` | 지형 높이 | float |
| `h` | 물 깊이 | float |
| `hu, hv` | 유량 (운동량) | float2 |
| `s` | 뜬 모래 농도 | float |

- KP07 은 칸 중심 `(h, hu, hv)` + 칸 경계(꼭짓점) 지형 `b`. 바닥 경사 항을 경계 지형에서 계산해 정지 수면이 유지된다 (well-balanced).
- 버퍼 = 풀드 구조 버퍼 두 벌 (핑퐁). 텍스처는 렌더 쪽 내보내기만.

## 패스 (한 서브스텝)

```
0. 도구 스탬프       b 에 파기 · 쌓기 (M2 스탬프와 같은 구조체) — T6
1. 파도 주입         바다 쪽 경계 칸 (h, hu) = 이봉 스펙트럼 32 성분 합 (G-6c, 위상 jitter)
2. 재구성 + 유속     minmod 기울기 → 칸 경계 값, 마른 칸 u 특이점 제거 (KP07 식 2.17)
3. 경계 유량         central-upwind 유량 (x · y), 국소 파속 a = |u| ± √(gh)
4. 갱신              SSP-RK2 (두 단계) — Δt = 0.25·Δx / max a (CFL 1/4, KP07 정리 3.1)
5. 모래              Exner: (1−p)∂b/∂t = −∇·q,  q = A·|u|²u  (바닥 운반)
                     s: 침식 · 침강 (Kd > Ks → 침강 지연) · 반라그랑주 이류
6. 열침식            이웃 경사 > 안식각이면 아래로 (Jákó & Tóth 2011)
7. 내보내기          b, h → 렌더 텍스처 (WPO)
```
- CFL: 파속 최대 √(g·0.5m) + 3 m/s ≈ 5 m/s, 칸 5cm → Δt ≤ 2.5ms → **프레임당 서브스텝 6~7 번**. T5 에서 비용을 보고 칸 크기 · 영역을 정한다.

## 단계

| 단계 | 내용 | 검증 (통과 기준) |
|---|---|---|
| **T1** KP07 풀이 | 1D 띠 (폭 몇 칸) 로 시작. 버퍼 · 패스 · CPU 대조판 (작은 격자에서 같은 식을 CPU 로) | ① **정지 수면**: 울퉁불퉁한 바닥 위 평평한 물이 1000 스텝 뒤 \|u\| < 1e-6 m/s · ② **질량 보존** 오차 < 1e-5 (단정밀도) · ③ 마른 곳으로 흘러 들어가 멈춤 (KP07 4 장 시험) · ④ CPU = GPU |
| **T2** 처오름 검증 | 1:19.85 경사에 고립파 (Synolakis) | ① H/d = 0.0185: 최대 처오름이 **R/d = 2.831·√cot β·(H/d)^1.25 의 ±10%** · ② H/d = 0.3 (부서짐): NaN · 음수 수심 없이 bore 로 올라가고 실험 시계열(Synolakis 2008 Fig.11)과 모양 비교 |
| **T3** 파도 | 이봉 스펙트럼 경계 주입 + 경사 해변 2D | ① 160 초 반복이 안 보인다 (jitter) · ② 파군 (세트) 이 저절로 · ③ 처오름 선이 매번 다르다 — **사용자 화면 판정** |
| **T4** 모래 | Exner + `s` + 열침식 | ① **모래 질량 보존** Σ(b·(1−p) + s·h) 변화 < 0.1% · ② 잔잔한 파도 → 해변 위쪽 순 퇴적, 큰 파도 → 순 침식 (부호) · ③ 안식각 넘는 경사가 완화 · 눈에 보이는 속도인지 사용자 판정 (계수 A 과장 정도) |
| **T5** 렌더 · 비용 | 평면 메시 + WPO (지형 · 수면), 물 색 최소한. 패스별 타임스탬프 | 1024² (또는 정한 크기) 가 예산 안. 서브스텝 수 · 칸 크기 결정 |
| **T6** 도구 | M2 스탬프를 격자 `b` 에도 (파기 · 쌓기 · 물붓기 = h 더하기) | 입자 · 격자 둘 다 같은 스탬프로 |

각 단계 m3-log 에 기록 후 커밋.

## 하지 않는 것
- 입자 ↔ 격자 결합 (파도 하중 · 장애물 · 파괴 환원) — M4. 참고 문헌은 D-M3-1 (Chentanez & Müller 2010).
- `W` · 지하수면 · 침투 · 증발 — M5 (F · E 절). 침투가 둔덕을 만드는 효과도 M5 에서.
- 쇄파의 말리는 모양 (plunging) · 물보라 — 얕은 물은 bore 로만 표현한다. 시각 효과는 M8.
- 쇄파 전 분산 (Boussinesq) — 필요하면 바깥 바다만 다른 방법으로.
