## 2. 지금의 파이프라인 (GPU, 프레임마다)

```
시뮬 위치 버퍼 (FSandGpuSim, float4) ── 내려받기 없음
 ① 이웃 격자 (셀 10cm, 셀 안 입자 번호 순 정렬 — 결정성)
    이웃 수 · 치우침 · 다듬은 중심 x̄ (λ 0.9) · 가중 공분산
 ② 표면 입자 = 이웃 < 25 또는 치우침 > 0.15 (C14, #4)
    고유분해 → Yu & Turk 이방성 커널 G (k_r 4 · k_s 자동 · KnRamp 8)
    등위값 = 0.6 × 0.25 (내부 φ 고정, #19)
 ③ 활성 8³ 영역 → 슬롯 (#23) · 표면 입자 7.5cm 띠
    영역마다 그룹 하나: 커널 목록 정렬 후 점마다 모으기 (원자 연산 없음)
 ④ Surface Nets (영역 안 접두합 번호 — 결정적) · 법선 = −∇φ
    가중 라플라시안 평활화 25 회 — 위치 · 법선 (C13 splashsurf, #17 · #20)
 ⑤ 위치 · 접선 · 색인 → FLocalVertexFactory 정점 버퍼 그대로, 색인 꼬리는 퇴화 삼각형
    그리는 수 = 지난 색인 수(비동기) × 1.25 (#21)
```
- **CPU 판(`FSandSurfaceBuilder`)이 정답지**: 모든 단계를 CPU 와 대조했다 — 정점 · 삼각형 수 · 부피 · 지표가 전 시험 장면에서 같고, GPU 는 같은 입력에서 비트 단위로 같다 (#10~#23).
- 셀 1.25cm · h 5cm · 이웃 반경 10cm · 띠 7.5cm.

## 4. 바뀐 · 새로 정한 것 (논문 그대로가 아닌 것)

| 항목 | 우리 값 | 왜 |
|---|---|---|
| KnRamp | 구 복귀 크기를 이웃 수로 (k_n 0.5 → 1, 이웃 8 개에서) | 2 층 얇은 벽이 구 복귀로 얇아지던 것 (#2) |
| 표면 입자 | 이웃 수 + **치우침** (Barecasco 2013 의 우리 판) | 다져진 표면이 이웃 25 개를 넘어 띠가 끊기던 것 (#4) |
| 내부 φ | **0.6 고정** (측정 대신) | 작은 더미는 내부 판정이 소수만 골라 등위값이 튐 (#11 · #19) |
| 평활화 | splashsurf 규칙 · 이웃 = 면 맞댄 셀 6 개 · **법선도** | Surface Nets 연결과 같고 GPU 에서 싸다 (#17 · #20) |
| 그리기 | 간접 그리기 대신 퇴화 삼각형 꼬리 | VSM 그림자가 간접 인자를 덮어써 0 개를 그림 (#13) |

## 5. 사용자 판정으로 남은 것

1. **모양 · 질감 전반** — `img/m1-nrm-f270.png` (마름) · `img/m1-wet08-f270.png` (젖음 0.8) · `img/m1-big20k-f270.png` (2만 입자 큰 둔덕). 큰 장면: `-sandcount=20000 -sandboxhalf=80`. 시험: `UnrealEditor.exe BeachSimulator.uproject /Engine/Maps/Templates/Template_Default -game -sandsurfacetest -sandsim -sandscene=pour [-sandwet=0.8] [-sandsmooth=N]`
2. 평활화 25 회의 대가 — 작은 뭉치(3~7 입자) 부피 −21%. 10 회면 −10% 지만 둔덕 혹이 남는다 (`img/m1-smooth0/10/25-f270.png`).
3. 젖은 모래 거칠기 0.2 (papers L-3 ① 값) — 다소 반들거려 보일 수 있다.
4. 둔덕 가장자리의 물결 · 작은 돌기 — 바닥에 흩어진 알갱이를 알갱이로 남기는 가중 때문 (의도).
