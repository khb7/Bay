## 1. 단계

### 단계 A — 표면 입자 판정 개선 (근거 C14)

- 판정 2 단계: ① 이웃 수 < BandNEps(25) ② 나머지 중 **치우침** d_i = |Σ_j (x_j − x_i)| / (N_i · r_i) > `SurfDev` → 표면.
  - Barecasco 2013 (이웃 방향 벡터 합) · Liu 2022 (위치 발산, 문턱은 장면마다 다시 잼).
- 문턱 정하기: 판(입력 위층 = 정답 표면)에서 위층 / 내부의 d 분포를 찍어 둘을 가르는 값. 기둥에서 확인.
- 스위치 `-surfdev=` (0 = 끔, 지금 동작).
- **통과**: 기둥 `-bandr 7.5` 부피비 ≥ 0.9 (지금 0.68, 띠 전체 0.94) · 판 · 벽 · 부스러기 지표 #2 값 유지 (±0.02).
- 실패 시: 모호 구간만 원뿔 검사(Liu, 반경 2.5Δx · 45°) 추가.

### 단계 B — 부분 영역 조밀 격자 (근거 C14 splashsurf 소스)

- 띠 격자 AABB 를 영역(S³ 셀)으로 나눔. 영역마다 스레드 1 개(ParallelFor):
  1. 영역 + 여백 안 입자 모으기. 여백 = ceil(지지 반경 / 셀) × 셀 × 1.01 (splashsurf 식).
  2. 영역 지역 조밀 배열(S+1)³ 에 뿌리기 — **원자 없음 · 띠 검사 없음**.
  3. 영역 안 Surface Nets → 지역 정점 · 면. 경계 모서리 정점만 전역 모서리 색인 해시로 합침, 나머지는 접두합 오프셋 복사.
- 활성 영역 = 단계 A 표면 입자(+ BandR)가 닿는 영역만. 내부 · 빈 영역은 건너뜀 (splashsurf 는 기본에서 띠를 안 쓰지만, 우리 장면은 내부 입자가 많아 영역 단위로 거르는 이득이 크다고 봄 — 측정으로 확인).
- **S 값**: splashsurf 64 는 수백만 입자 기준. 기둥은 셀 1.25 에서 한 변 ≈ 80 셀이라 64³ 이면 영역 ~8 개로 스레드가 놀고, 영역 하나가 L2 를 넘는다(65³×4B ≈ 1.1 MB). **16 · 32 · 64 를 스윕해 정함.**
- 성긴 영역(입자 ≤ max(최대/20, 100)) 해시 경로는 부스러기 장면에서 필요할 때만.
- **통과**: 같은 입력에서 메시가 지금 구현과 같다 (정점 수 ±0.5%, 부피 · 지표 동일) · 기둥 장 + 메시 ≥ 5 배 빠름.

### 단계 C — SIMD (근거 C14: splashsurf AVX2+FMA 8 레인, f32 만)

- 단계 B 뿌리기 안쪽 루프(한 입자 · 한 줄의 x 방향 셀)를 8 레인으로. UE `VectorRegister4Float` 는 4 폭이라 우선 그것으로, 부족하면 AVX2 intrinsic.
- **통과**: B 대비 장 계산 ≥ 2 배 · 결과 동일 (부동소수 순서 차이 허용 1e-5).

## 2. 측정 방법

- `-mesh -scenes=slab,wall,debris1,debris3,debris7,column -fields=aniso -knramp=8 -isofrac=0.25 -cell=1.25 [-bandr=7.5 -surfdev= -subdomain=]`
- 단계별 ms (이웃 · 커널 · 장 · 메시) 와 스레드 수를 함께 기록. 3 회 중앙값.
- 시험은 BelowNormal 우선순위, 하나씩.

## 3. 그다음 (이 계획 밖)

- 목표 미달이면: 이웃 단계(21 ms) — 시뮬 이웃/격자 재사용 · 잠든 영역 장 캐시 → 그래도면 GPU 메시화 (milestones 실패 분기).
- 품질 경로 B (등방 + 가중 라플라시안 평활화, C13) 를 셀 2.5 에서 A 와 비교.
