# M0 계측 — 자와 계기

> **절차**는 [m0-spike.md §3-0](m0-spike.md), **여정**은 [m0-log.md](m0-log.md),
> **문헌**은 [papers.md §A-R](../research/papers.md).
>
> 이 문서는 **"지금 자가 어떻게 생겼고, 나온 값을 얼마나 믿을 수 있는가"** 만 다룬다.
> 로그는 시간순이라 현재 상태를 알려면 19번을 되짚어야 하고, §3-0은 절차서라
> 오차가 어디서 오는지를 담지 않는다. 그 사이가 이 문서다.

---

## 0. 왜 계측 문서가 따로 필요한가

M0의 안식각은 **게임이 34°를 필요로 해서 재는 게 아니다.** `μ` 마찰이 제대로 도는지
확인하는 유일한 방법이라 잰다 ([m0-spike.md §4](m0-spike.md)).

그래서 **값보다 값을 믿을 수 있는지가 먼저**고, 이 세션에서 실제로 그게 문제였다.

```
19번의 실행 중 물리를 잰 것은 소수다.
나머지는 전부 "재는 장치가 작동하는가"를 확인하다 발견한 것들이다.
```

## 1. 계측기 지도 — 무엇이 무엇을 검증하는가

각 계기가 아래 것을 보증해야 위 것이 의미를 갖는다. **사슬이다.**

```
                    θr = 34° ± 3          ← 최종 판정
                          ↑
        ┌─────────────────┴─────────────────┐
   각도 판독기                          시험체(퇴적물)
   프로파일 · 법선중앙                   원뿔인가 · 무작위인가 (#25 배위수)
        ↑                                   ↑
   자 교정 (#6)                   ┌──────────┼──────────┐
   합성 원뿔 15~55°            안정성(#12)  거친 바닥(#19·#25)  유지 재측정(#24)
   ±1~3° 통과                 높이 유지     넓게 · 흔들림 0.3R    30초 뒤 그대로인가
                                        ↑
                              하중 검산 (#24) — 바닥 임펄스 / 무게 = 1
                                        ↑
                                   잡음 바닥 (#19)
                                   수렴하는가 — 10초
                                        ↑
                                   솔버 (SP + 워밍 스타트 #24)
                                        ↑
                                   단일 입자 시험 (#8)
                                   마찰 공식이 μ 를 따르는가
```

**아래에서 위로 통과시킨다.** 잡음 바닥이 발산하면 그 위의 모든 값이 무의미하다.

## 2. 계기 일곱

### 2-1. 단일 입자 시험 (#8) — 마찰 공식

거친 바닥 위 입자 **하나**를 기울인다. 더미가 아니므로 **하중 전달이 필요 없고**,
따라서 **마찰 공식만** 시험한다.

```
μ 0.1 → 1.88°   0.4 → 18.15°   1.0 → 41.33°   1.5 → 52.00°
μ 를 15배 바꾸는 동안 오차가 −3.7° 로 일정  (PBD 시절)
```

> **이 시험이 진단을 뒤집었다.** 비례가 완벽하다는 것은 **마찰 공식이 무죄**라는 뜻이고,
> 무너지는 것은 더미에서만이므로 범인은 **하중 전달**로 좁혀졌다.

[Sequential Positions](../research/papers.md) 교체 후 **−0.9 ~ −2.5°** 로 개선.
속도 역산을 없앤 것 하나로 절편 오차가 사라졌다(#11).

### 2-2. 자 교정 (#6) — 각도 판독기

**합성 원뿔**(각을 아는 시험체)을 만들어 판독기를 검증한다. 독립적인 두 방식을 쓴다.

```
프로파일 기울기   반경 구간별 최고점에 직선 맞춤
법선 중앙값       표면 입자의 지역 법선 히스토그램
```

| 실제 | 프로파일 | 법선중앙 |
|---|---|---|
| 15.0 | 14.7 | 17.9 |
| 30.0 | 29.6 | 29.2 |
| **34.0** | **33.2** | **34.6** |
| 45.0 | 43.8 | 45.4 |
| 55.0 | 55.3 | 55.3 |

**±1~3° 안에서 일치 → 자는 믿을 수 있다.**
두 방식이 실제 측정에서 3° 넘게 벌어지면 그건 자가 아니라 **퇴적물이 원뿔이 아니라는 신호**다.

> 1차 교정에서 34° 구간의 표본이 **0개**였다. 표면 판정이 상대 기준(더미 중앙값의 70%)이라
> 얇은 더미에서 아무도 안 뽑혔고, 제외 구간이 절대값이라 낮은 원뿔은 통째로 지워졌다.
> **통과 기준이 있는 구간에서 작동하지 않는 자였다.**

### 2-3. 안정성 검사 (#12) — 다지기 후 높이

수평에서 다지기만 하고 **최종 높이**를 본다. 6층이면 27.5cm 여야 한다.

| 반복 | 정지 | 최종 높이 | |
|---|---|---|---|
| 20 | 못 함 | 94.6cm | 부풂 |
| 30 | 못 함 | 79.1cm | 부풂 |
| **45** | 169프레임 | **27.5cm** | ★ |
| 60 | 152프레임 | 27.5cm | ★ |

**반복 45 미만은 부정확한 게 아니라 불안정하다.** 그 아래 각도는 터지는 더미 위의 값이다.

> **부호가 뒤집힌다.** 불안정 영역에서는 모멘텀 `a=0.5`가 각을 18.2→9.2°로 **낮추는** 것으로
> 보였는데, 안정 영역에서는 10.3→18.5°로 **올린다.** 결론의 방향 자체가 반대로 나온다.

### 2-4. ★ 잡음 바닥 (#19) — 가장 값싼 계기

**기울이지 않은 수평 상태에서 10초.** 물리적으로 완전히 정지해야 하므로
남는 속력은 전부 솔버 잡음이다. **부호와 기울기만 본다.**

```
반복  45 :  0.018 → 0.050 cm/s    올라간다 = 발산
반복  90 :  0.0069 → 0.0055       내려간다 = 수렴  ★
반복 180 :  0.0069 → 0.0050
```

반복 90의 바닥은 `√(gd)` 대비 **7×10⁻⁵**, 임계 `ε=0.002`보다 28배 아래다.
**임계가 문제가 아니라 반복 45가 그 장면에서 수렴하지 않는 것이 문제였다.**

> 10초면 끝난다. 기둥을 통째로 다져보는 것(212초)보다 20배 싸다.
> **새 장면·새 설정마다 이것부터 통과시킨다.**

### 2-5. ★ 유지 재측정 (#24) — 정지한 것이 정지해 있는가

정지 판정(§2-2) 뒤 **1800프레임(30초)을 더 돌리고 다시 잰다.** 판정은 평균 |v| < 0.14 cm/s 를 보는데,
그 아래의 0.08 cm/s 로도 더미는 30초에 7cm 주저앉는다.

```
차가운 시작   각 32.7° → 24.5°   높이 37.2 → 29.9   크리프 |v| 0.079 cm/s
워밍 스타트   각 34.4° → 34.4°   높이 42.1 → 42.1              0.002
```

**차가운 시작에서 잰 각도는 전부 붕괴 중의 스냅숏이었다** — 반복 수를 따라가고 μ 와 무관했던 이유.

### 2-6. 하중 검산 (#24) — λn 이 무게를 말하는가

고정 바닥과 지면이 받는 수직 임펄스의 합을 자유 입자 총 무게 임펄스로 나눈다. **1 이 정답.**
워밍 스타트가 λ 를 부풀리는지 의심할 때 이것 하나로 배제했다 (실측 0.97~1.13).

### 2-7. 유지 시간 스윕 (#14) — 판정이 무엇을 재는가

사태라면 **관찰 시간과 무관**해야 한다.

```
유지 시간    μ=0.3            μ=0.4
 1초        15.72° (−0.98)   20.10° (−1.70)
 4초        13.81° (−2.89)   17.64° (−4.16)
16초         8.07° (−8.63)    9.16° (−12.64)
```

**단조 감소 = 판정이 사태가 아니라 [크리프](../research/terms/creep.md) 누적을 재고 있다.**

이 스윕이 **−3.5° 절편의 정체를 밝혔다** — 유지 1초의 오차 −1.0/−1.7°가
단일 입자 시험(−0.9~−2.5°)과 같은 크기다.
**솔버의 마찰은 이미 맞았고, 나머지는 전부 판정이 만든 것이었다.**

## 3. 붕괴 판정 4종과 실패 방식 (#15)

경사판(`θm`)에만 해당한다. 원통은 최종 정지 상태를 재므로 이 문제가 없다.

| 판정 | 유지 시간 무관 | μ 단조 | 실패 지점 |
|---|---|---|---|
| 누적 변위 > `0.5r` | ✗ | ○ | **크리프도 시간만 주면 임계를 넘는다** |
| §2-2 그대로 | ○ | ✗ | **60프레임 "연속"이 스파이크 한 번에 부러진다.** 구간 평균은 임계의 1/10인데도 거의 전부 "정지 못 함" |
| 앞/뒤 속도 비교 (전체) | ○ | ○ | 닫힌 상자의 **벽에 눌린 입자**가 안 죽는다 → 1°에서도 무너짐 |
| 앞/뒤 속도 비교 (중앙 60%) | △ | ○ | 창이 길면 앞뒤 평균이 가까워져 **잡음이 부등호를 결정** |

> **★ 한 시험으로는 못 걸렀다.** 유지 시간 스윕과 μ 단조성을 **둘 다** 봐야 넷이 갈렸다.
> 어느 하나만 봤으면 §2-2(시간 무관)나 변위(μ 단조)를 통과시켰을 것이다.

**판단** — `θ_start`(개시각)는 "아무 일도 없음"과 "막 시작함"의 경계라
판정이 언제나 잡음과 크리프 위에 놓인다. **원리적으로 취약하다.**
그래서 주 교정을 `θr`(끝 상태)로 옮겼다 — 끝 상태는 경계가 뚜렷하다.
원통 들어올리기(#17~#19)를 거쳐 지금은 **부어 쌓기**(#21~)다 — 원통은 원리적으로 기각(#20, [m0-spike.md §3-0-D](m0-spike.md)).

## 4. ★ 계통 오차 예산

**이 문서의 값어치는 이 표다.** 최종 값을 볼 때 "얼마를 믿어야 하나"에 답한다.

| 오차원 | 어느 측정 | 방향 | 크기 | 상태 |
|---|---|---|---|---|
| 크리프 누적 | 경사판 | **낮춤** | 유지 4초에 −2~−3° | ✓ #24 **워밍 스타트로 원인 제거** (접선 잔차) |
| `θm` 을 `θr` 기준과 비교 | 비교 자체 | **격차 확대** | 2~5° | ✓ #16에서 분리 |
| 벽 규약 위반 (`SolveWalls`) | 경사판·원통 | 부풂 | 큼, 미정량 | ✓ #18 수정 — **경사판 재측정 필요** |
| 거친 바닥이 좁음 | 원통 | 두 방식 불일치 | 6~8° | ✓ #19 수정 |
| 수렴 부족 (반복 부족) | 전부 | **무효화** | — | ✓ 잡음 바닥으로 차단 |
| 램프 1초로 전이 미종료 | 경사판 | 낮춤 | 초반 60μm/스텝 | **미해결** |
| 회전 자유도 없음 | 전부 | **올림** | μ0.1→29° · 0.3→46°. 기하 맞물림 ≈ +25° | ✓ #25 실측 — `μ` 를 유효값(0.15)으로 흡수 |
| 잔여 마찰 오차 | 전부 | 낮춤 | −0.9 ~ −2.5° | **미해결** |
| 퇴적물이 아직 원뿔 아님 | 부어 | 두 방식 불일치 | 6.7 → 1.6° | ✓ #23·#25 — 산포 0.5d · 바닥 흔들림 |
| 붓는 중 최대속력 사건 (2074 cm/s) | 부어 | 생성 높이 폭주 | 33프레임 자유낙하 | ✓ #23 — 정지 입자만 기준 |
| 접촉 목록 프레임당 1회 | 부어 | — | — | 무관해짐 — 크리프는 속도 잔차라 서브스텝이 안 듣는다 (#24). `ss=1` |
| **솔버 크리프 (차가운 시작)** | 전부 | **각도 = f(반복 수)** | 30초에 −7cm | ✓ #24 워밍 스타트 |
| **격자 바닥 결정화** | 부어 · 경사판 | **올림** | μ≤0.2 에서 45~55° | ✓ #25 바닥 흔들림 0.3R. **경사판은 아직** |

**정리** — 해결 열, 미해결 둘(램프 · 잔여 마찰 오차). **θr 은 닫혔다.** 남은 것은 경사판(θm) 재측정이다.

## 5. 문헌 vs 우리 것 — 전체 집계

| 문헌 근거 있음 | 우리 설계 (근거 없음) |
|---|---|
| 측정법 선택 (A-R1) | 부어 쌓기: 낙하 높이 1d · 산포 0.5d · 공급 2개/2프레임 (무관성 확인) |
| 기둥 붕괴 기각 (A-R2) | 입자 1200 |
| 거친 바닥 필요성 (A-R3 · Goujon 2003) | 반경 배율 1.2 · **흔들림 0.3R** (격자는 템플릿이다 #25) |
| 워밍 스타트 (Catto 2005 · C3) | gap 허용 0.05cm · 접선 재투영 |
| 재는 값이 `θm`/`θr` (A-R4) | 경사판: 유지 시간 · 트리거 · 관찰 구역 60% · 램프 1초 |
| 두께 의존성 (A-R5) | 이분 탐색 8회 |
| 준정적 = 관성수 (A-R6) | §2-2 임계 `0.01·(r/dt)` |
| 정지 판정은 무차원 비율 (A-R7) | 잡음 바닥 임계 `ε=0.002` |

> **경사판 쪽에 임의 상수가 몰려 있다.** 끝 상태(`θr`)가 주 교정이 된 이유 중 하나다 —
> 부어 쌓기는 남는 축이 낙하 높이·공급 속도 둘뿐이고, 둘 다 무관성 검사로 닫힌다.

## 6. 반복된 실패 패턴

같은 모양이 **다섯 번** 나왔다.

```
자를 의심했는데 시험체가 문제였다
```

| # | 의심한 것 | 실제 원인 |
|---|---|---|
| 6 | 각도 판독기 | 1차는 진짜 자 문제, **2차는 합성 원뿔의 격자 계단** |
| 12 | 마찰 공식 (μ 축 역전) | **더미가 터지고 있었다** (반복 부족) |
| 16 | 측정 정확도 | **퇴적물이 원뿔이 아니었다** (`H/R=1`) |
| 19 | 두 판독 방식의 불일치 | **거친 바닥이 퇴적물보다 좁았다** |
| 25 | 마찰 모델 (μ=0.05 에 45°) | **정사각 격자 바닥이 FCC 결정을 키웠다** — 거칠기가 아니라 템플릿 |

> **계기를 먼저 검증하라 — 그리고 시험체도 계기다.**
> 검증용 시험체가 비현실적이면 멀쩡한 자를 불량으로 판정하고,
> 측정용 시험체가 조건을 안 맞추면 멀쩡한 자로 엉뚱한 것을 잰다.

두 번째 패턴도 있다 — **규약을 일부만 바꾸면 안 바꾼 쪽이 오염원이 된다.**
[SP](../research/papers.md) 로 옮기면서 지면은 옮기고 벽은 "형틀은 비계니까"라며 남겼는데,
그 벽이 속도 역산 고리를 되살려 18층 기둥을 터뜨렸다(#18).

## 7. 현재 신뢰 구간

```
마찰 공식     ✓ 검증됨      단일 입자에서 μ 15배 구간 비례, 오차 −0.9~−2.5°
각도 판독기   ✓ 검증됨      합성 원뿔 15~55° 를 ±1~3°
솔버 수렴     ✓ 조건부      반복 ≥ 90 (18층). 잡음 바닥으로 매번 확인
하중 전달     ✓ 검증됨      깊이에 선형 = ρgh (반복 60, μ=0.4)

크리프        ✓ 제거        워밍 스타트. 30초 유지에 각·높이 변화 0 (#24)
```
