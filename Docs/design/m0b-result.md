## 5. M1 에 넘기는 것

- **비동기 위치 리드백이 필요하다.** GPU 상태 전량 내려받기 ≈ 0.1 µs/입자 (5만 4.5~5.6 ms) — 매 프레임 동기면 5만 프레임의 1/3. 위치만 · 한 프레임 늦게 받아야 한다. (#60)
- **커맨드릿의 5 ms 고정비는 게임 비용이 아니다.** 매 프레임 `SubmitAndBlockUntilGPUIdle` + 통계 리드백. 게임 루프에선 대기 없이 겹쳐 돌린다 — 그때의 실제 프레임 비용을 M1 에서 다시 잰다. (#60)
- **GPU 예산**: 5만 정지 8.5 ms (재우기 5.7) · 다짐 중 9.7 ms. 렌더링에 남는 몫은 16 ms − 이것.
- **단계 비율**: 반복 78~92% · 이웃 탐색 8~17%. 더 줄여야 하면 반복이 유일한 큰 손잡이다. (#60)
- 측정 도구: `-perf -window -diag -stages -trace -seed`, `ApplyGpuProfile`. M1 의 렌더 경로에도 같은 타임스탬프 방식(RHI `RQT_AbsoluteTime`, C11) 을 쓸 수 있다.

## 6. 남은 선택 과제 (M0-b 범위 밖)

- 재우기 v2: 도구 영역 센서 (Chrono "active box" 와 같은 생각, C11) · 관문 G3 (정지 기둥 위 붓기) · 굳음 대책 W1~W3.
- 전체 여유 모드 대신 잠든 쌍 보존 (Box2D 식 접촉 보존).
- 10만 깊이 한계.
- 결합/접촉 반복 분리 (#35 판정: 접촉 30 · 결합 120) — 반복이 GPU 의 80% 라 남은 큰 손잡이.
