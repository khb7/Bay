## 원칙 — 불확실한 것부터

조사 문서는 격자 침식(Mei 2007)부터 하라고 되어 있다. **그 순서를 뒤집는다.**

터널·아치·덩어리 붕괴가 타협 불가 요구사항이 된 이상, 가장 위험한 미검증 부분은
파도가 아니라 **"입자로 만든 모래성이 실제로 서고, 속을 파도 무너지지 않고,
무너질 땐 덩어리로 떨어지는가"** 다.

### "미검증"의 뜻

논문이 없다는 게 아니다. 개별 요소는 전부 논문이 있다
(XPBD Macklin 2016 / 젖은 모래 점착 Tampubolon 2017 / 강도 곡선 Pakpour 2012).
**이 조합을 한 사례가 없다는 뜻이다.**

```
XPBD + W 구동 점착 + 재결합 없음 + 격자 하이브리드 + 지름 5cm 입자로 터널
```

| 불확실한 것 | 실패하면 |
|---|---|
| 지름 5cm 입자로 **30cm 터널이 서는가** | 한 칸 낮추면 8배 → **성 15채가 1.9채로.** 누적 콘텐츠가 죽는다 |
| 점착이 끊길 때 **덩어리로** 떨어지는가 | 결합 슬롯·`breakStretch` 재설계. 최악엔 표현 방식 재검토 |
| `strengthCurve`의 **절벽이 극적으로 보이는가** | 곡선을 게임용으로 과장 |
| 20만 입자 XPBD가 **실시간인가** | 입자 예산 축소 → 성 크기 제한 |
| 격자와 입자의 **이음매가 자연스러운가** | 블렌딩 계층 추가 |

> ★ **첫 줄은 위험 방향이 반대일 수 있다.** D/d = 30/5 = 6 은 점착이 0이어도 아치가 생기는 구간이고
> (사일로 막힘), 전단대 두께(40~80cm)가 터널 지름보다 커서 붕괴 메커니즘이 격자에 안 들어간다.
> **오차는 "안 선다"가 아니라 "무조건 선다" 쪽으로 생긴다** — 그러면 2행(덩어리 붕괴)이 진짜 차단이 된다.
> 근거와 판정 변경은 [../research/papers.md §B-S](../research/papers.md), [m0-spike.md](m0-spike.md) 3-1.

반면 격자 침식은 논문 + 수많은 공개 구현 + 알려진 결과가 있다. **짜면 된다.**

> 확실한 것을 먼저 만들면 두 달 뒤에 "터널이 안 서네"를 발견하고,
> 그때는 이미 지은 것 대부분을 버려야 한다.

## M0 — 스파이크: 모래성이 서는가

> 상세는 **[m0-spike.md](m0-spike.md)** — 검증별 배치 · 절차 · 판정 · 실패 분기 · 타임박스.
> **결과는 [m0-a-result.md](m0-a-result.md)** — 차단 셋 통과(2026-09-11), 확정 상수, 미결(크기 편향).

**목표는 게임을 만드는 것이 아니라 질문에 답하는 것.** 여기서 만든 코드는 버려도 된다
(배치 하네스만 남는다 — M0-b에서 GPU 결과를 CPU와 대조하는 데 쓴다).

### 만들 것

```
XPBD 입자 시뮬 하나
  접촉 + 마찰 + 점착 제약
  정렬 기반 공간 해시
  손으로 배치한 입자 더미 (도구 없음)
  W는 전역 슬라이더 하나
  렌더링은 그냥 구 (모래처럼 보일 필요 없음)
```

격자도 파도도 조석도 도구도 타일도 없다. **입자와 제약만.**

코어(`FSandSpike`)를 틱·렌더링에서 분리해 **실시간 뷰**와 **최대 속도 배치**가 같은 코어를 쓴다.
★ 항목은 눈으로 보고, 나머지 넷은 숫자 스윕으로 답한다.

### 검증 — 이 다섯이 M0의 전부

| 검증 | 등급 | 통과 기준 |
|---|---|---|
| **안식각** | **전제** | `W=0` 기둥 붕괴가 **34° ± 3°** 에서 멈추는가 — **✓ 통과 (#34): μ 0.15 · 3000개 수렴 크기 · 반복 180** |
| **터널** | **차단** | 지름 30cm를 뚫었을 때 천장이 버티는가 (아치·사각 둘 다) — **✓ 통과 (m0-log #32): 아치 섬 · 사각 붕괴 · 대조군 붕괴** |
| **★ 덩어리 붕괴** | **차단** | `W`를 서서히 낮출 때 **버티다 갑자기, 덩어리로** 무너지는가 — **✓ 통과 (m0-log #33): ΔW 0.012 · 최대 파편 = 상부 블록 전체 · fines 8%** |
| 수직 벽 | 정보성 | **얼마나 얇게까지 되는가** — 물리 한계와 표현 한계의 간격 |
| 성능 | 정보성 | 몇 개까지 도는가 — M0-b GPU 이득의 기준선 |

세 번째가 이 게임의 정체성이다. **부슬부슬 흩어지면 하이트필드와 다를 게 없어지고,
그러면 입자 계층을 도입한 이유가 사라진다.**

**등급의 뜻** — 차단은 못 넘으면 M0-b(GPU)에 착수하지 않는다. 정보성은 값을 기록하되 막지 않는다.
안식각만 층이 다르다: 34°는 검사 대상이 아니라 **뼈대를 교정하는 기준자**라
(마찰 클램프가 제대로 도는지 확인하는 유일한 방법) 여기서 안 나오면
나머지 넷을 **고장난 저울로 재게 된다.** 그래서 M0-b가 아니라 나머지 넷의 실행 자체를 막는다.

### 순서

```
M0-a  CPU 단일 스레드로 다섯 질문에 답한다
M0-b  답이 "예"면 GPU로 옮긴다 (RDG를 처음 만지는 지점)
```

XPBD 자체는 코드가 짧다. 시간이 드는 건 GPU 파이프라인(RDG·버퍼·정렬)이므로,
**M0-a에서 답이 "아니오"면 GPU 작업을 시작하기 전에 설계를 고친다.** 그게 이 순서의 목적.

**타임박스는 구현이 아니라 튜닝에만 건다.** 총 11일 + 3일차 캘리브레이션 체크포인트.
넘으면 "더 하면 될 것 같다"가 아니라 **M0가 답을 준 것**이다.

### 부수 산출물
- `μ` · substep · 반복 수 ← 안식각이 확정. **μ 유효값 0.15 (수렴 크기 3000+) · ss 1 · 반복 180(플래토) · 워밍 스타트 필수 · 예산은 §2-1-a 로 분리** (m0-log #26·#28·#34). `system-design.md` §4 갱신
- 점착 결합 슬롯 수(12개)의 실제 필요량 → **12 로 충분** (넘침 0~1, m0-log #29)
- `breakStretch` 초기값 → **1.3 파라미터** · 형성 1.2 · `BondStrength 3` → c ≈ 1.5 kPa (#29)
- `strengthCurve` 형태의 게임용 보정 정도

## M1 — 렌더링 1단계

### 만들 것
```
입자 위치 → SDF (Yu & Turk 비등방 커널)     CPU 멀티스레드
SDF → Surface Nets → 삼각형                 CPU 멀티스레드
UDynamicMeshComponent로 그리기
W는 정점 컬러에 실어 우회
```
**렌더링 내부 지식 0으로 화면에 모래성이 나오는 것이 목표.**

### 검증

| 검증 | 통과 기준 |
|---|---|
| 평면 | 평평한 면이 **물결치지 않는가** |
| 얇은 벽 | 부풀지 않고 얇게 유지되는가 |
| 부스러기 | 고립 입자가 **덩어리로** 보이는가 (구형 복귀) |
| 예산 | 표면 밴드 20만 셀이 몇 ms인가 (추정 2.5ms) |
| 지연 | 브러시 없이도 형태 변화가 즉각 따라오는가 |

### 실패 시
```
물결침      → λ(위치 평활화)·k_r 튜닝
모서리 뭉갬 → Surface Nets → Dual Contouring
예산 초과   → 3단계 경로의 3단계(GPU 메시화)로. Vertex Factory + 간접 드로우
```

> ⚠ SDF만 GPU로 하고 리드백하는 절충은 피할 것. 50~65ms 지연으로 손맛이 나쁘다.
> **입자 위치만 리드백(36KB)하고 나머지는 전부 CPU.**

## M2 — 도구 최소 3종

### 만들 것
```
FToolStamp 구조 확립 — 격자·입자 양쪽에 같은 스탬프를 보낸다
FScenePicker (깊이 버퍼 픽킹)
파기 · 쌓기 · 물붓기
연속 브러시 (프레임 간 보간)
```

### ◀ 이 시점에 플레이 가능
**파도 없는 모래성 샌드박스.** 모래를 파고 쌓고 물을 부어 성을 만들 수 있다.

### 검증

| 검증 | 통과 기준 |
|---|---|
| 손맛 | 브러시가 즉각 반응하는가 (지연 체감) |
| **쌓기의 `W` 상속** | 젖은 곳 근처에서 쌓아야 잘 뭉치는 게 **체감되는가** |
| 해자 창발 | 쌓다 보면 주변이 파여 해자가 생기는가 |
| 물붓기 3효과 | 회복·충격·과포화가 다 느껴지는가. 부은 직후가 가장 약한가 |

**여기서 재미가 없으면 이후 마일스톤이 의미 없다.** 파도와 조석은 압박을 더할 뿐,
"모래를 만지는 것" 자체가 재미있어야 한다.

## M3 — 격자 시뮬 (M1·M2와 병렬 가능)

### 만들 것
```
Niagara Grid2D + Simulation Stages
패스: 파도 주입 → 가상 파이프 → d/v 갱신 → 침식·퇴적 → 이류 → 열침식
이봉 스펙트럼 (성분 32개, jitter 필수)
평면 메시 + WPO 지형 · 물 렌더링
```
아직 `W`·지하수면·부유물은 없다. **파도가 오가고 모래가 깎이는 것**까지.

### 검증

| 검증 | 통과 기준 |
|---|---|
| 파도 | uprush/backwash가 자연스러운가. **160초 반복이 안 보이는가**(jitter) |
| 세트 | 이봉 스펙트럼에서 파군이 저절로 나오는가 |
| 침식 | 눈에 보이는 속도로 지형이 변하는가 (`Kc`/`Ks`/`Kd` 과장 정도 결정) |
| 열침식 | 경사가 안식각으로 완화되는가 |
| **ripple** | `exposureGain` 항으로 잔물결이 창발하는가 ← **검증 필요 항목** |
| **rill** | backwash 채널화가 나오는가 ← **검증 필요 항목** |
| 성능 | 1024² 9패스가 예산에 드는가 |

위험이 낮은 구간이다. 논문대로 짜면 된다.

## M4 ★ — 브릿지

두 번째 위험 구간. **두 계층을 잇는 곳이 가장 깨지기 쉽다.**

### 만들 것
```
격자 → 구조물   파도 하중 · 수분 공급 · 증발 · 지면 충돌
구조물 → 격자   파괴 환원 · 그림자 마스크 · ★ 장애물 마스크(z축 비트마스크)
SandTile / SandTileGrid (4m 타일, sleep/wake)
```

### ◀ 이 시점에 플레이 가능
**파도가 성을 부순다.** 게임의 핵심 상호작용이 여기서 완성된다.

### 검증

| 검증 | 통과 기준 |
|---|---|
| 장애물 마스크 | 물이 성을 **통과하지 않고 돌아가는가** |
| **세굴** | 성 옆·뒤가 파이는가. 기단이 파여 성이 주저앉는가 |
| 파괴 환원 | 씻겨간 입자가 격자 `s`로 넘어가는가 (질량 보존) |
| **이음매** | 성 밑동과 지면이 만나는 선이 자연스러운가 ← **불확실** |
| 1프레임 지연 | 파도 하중이 늦게 도착하는 게 눈에 띄는가 (추정 3cm 오차) |
| sleep/wake | 파도가 잠든 타일을 제때 깨우는가 |

### 실패 시
```
이음매가 보임    → 밑동 블렌딩 계층 추가 (SDF 결합 또는 셰이더 페이드)
지연이 보임      → 브릿지를 격자 스텝 안으로 당기거나, 예측 보정
```

## M5 — 환경

### 만들 것
```
UEnvironmentClock (RealTime / SimTime / timeScale **1× 기본**, 디버그용 설정값)
조석 · 지하수면 닫힌 해 · exit point
수분 W: 지하수 평형 · 침투 · 배수 · 증발(2단계) · 모세관
부유물(debris) 채널 → swash mark
태양 · 그림자 → 증발률
```

### ◀ 이 시점에 게임 루프 완성
**전부 1× 실시간.** 물가가 시간당 4.5m 다가오는 조석 압박 안에서,
표면이 15~30분마다 마르는 건조 압박이 겹친다. 앞은 파도, 뒤는 마름.
(세션보다 긴 주기는 세션 시작 시 선택, 기다림은 균일 고배속 건너뛰기)

### 검증

| 검증 | 통과 기준 |
|---|---|
| **마른 성이 무너짐** | 버티다 갑자기 무너지는 게 **관찰 가능한 시간 안에** 일어나는가 |
| exit point 이동 | 조석에 따라 물가와 최적 지점이 이동하는가 |
| **우물** | 구덩이를 파면 물이 차오르는가. 뒤로 갈수록 깊이 파야 하는가 |
| 방향성 | **양지쪽 벽이 먼저 마르는가.** 성 그림자가 발밑을 지키는가 |
| swash mark | 흰 선이 여러 겹으로 남고 다음 파도가 지우는가 |
| **1× 체감** | **압축 없이도** 조석·건조가 세션 안에서 느껴지는가. 안 느껴지면 `timeScale`이 아니라 **세션 시작 조건**(밀물 시작 등)으로 해결 |

**⚠ `timeScale`로 해결하지 말 것.** 비균일 배속은 지하수면 감쇠 길이를 1/5로 압축하고
(`L` 6.9m→1.4m) 프리셋별 조차 차이를 지운다 — `system-design.md` §시간 참조.
체감이 부족하면 **증발 상수**를 조정하거나 **세션 시작 조건**을 바꾼다.

## M6 — 도구 나머지 8종

형틀 · 다지기 · 깎기 · 절단 · 터널 · 분무 · 불기 · 고정

| 도구 | 검증 |
|---|---|
| **형틀** | 틀 안에서 다지면 확실히 단단해지는가. **틀을 빼는 순간이 극적인가** |
| 절단 | 평평한 면·직각이 나오는가 (Surface Nets 품질에 의존) |
| 터널 | 관통이 되는가. 천장이 버티는가 (M0에서 이미 확인) |
| 깎기 + 불기 | 부스러기가 쌓이고, 불면 날아가고, 성 본체는 안 움직이는가 |
| 고정 | 파도가 막을 벗기고 **속이 마른 성이 통째로 무너지는가** |
