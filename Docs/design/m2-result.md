## 1. milestones M2 검증 표의 답

| 검증 | 답 | 근거 |
|---|---|---|
| 손맛 (지연 체감) | **사용자 판정 대기** — 도구는 다음 스텝 맨 앞에서 GPU 가 소비 (0~1 프레임). 커서 높이장은 비동기 리드백이라 몇 프레임 늦다 | #5 · #6 |

| 해자 창발 | **사용자 판정** — 쌓기는 손 재고에서만 하므로 쌓은 양만큼 어딘가는 파였다 (질량 보존이 구조로 보장) | #2 · #4 |
| 물붓기 3효과 | 회복 (W 곡선 → 사건 결합) ✓ · 충격 (아래로 속도) ✓ · 과포화 (W > 0.9 에서 cohesion 0) ✓ · **"부은 직후가 가장 약한가"** 는 임시 배수 τ 10 s 로만 — 제대로 된 배수는 M5 | #2 · #3 · #7 |

## 2. 만든 것

```
입자 풀 (T1)        죽은 칸 = 무덤 자리에 고정. 번호를 안 바꾼다 — 접촉 · 결합 · 메셔가 그대로
도구 스탬프 (T2)    CPU 는 스탬프 구조체만 → GPU StampCS 가 스텝 맨 앞에서 소비
  파기             구 안 입자 → 손 재고 (W 같이), 무덤으로. 손 용량 600
  물붓기           W += 양·(1 − d²/r²), 아래로 충격, 결합 Coh 를 W 에서 다시
  쌓기 (T3)        손 재고 뒤에서부터 꺼내 무덤 칸을 되살려 육각 자리에
사건 결합 (#3)      물붓기 · 쌓기가 표시한 입자의 닿은 쌍에만 생성 (결정 A, papers C17)
                   + 사건 프레임마다 죽은 결합 칸 압축 (#7)
플레이 맵 (T4)      -game -sandplay — 자유 카메라 · 높이장 커서 · 연속 브러시 · 손 막대
```
- **질량 보존**: 산 입자 + 손 = 일정. 모든 시험 매 프레임 확인 (3289 / 21225).
- 결합은 저절로 다시 붙지 않는다 — 사건 때만 (m0-spike ① 유지).
