# M4 — 브릿지: 파도가 성을 부순다 (계획 초안, 2026-11-09)

> milestones M4 · system-design §2 (실행 순서) · §4 `FFieldBridge`. 근거: [papers.md](../research/papers.md) **D-M4** · D-M3 (격자) · B (cohesion(W)) · C (XPBD).

## 지금 상태
- 입자 (M0–M2): `FSandGpuSim`, 단위 cm, 바닥 = 평면 z = 0 (`P.z <= Radius`), 장면 = `-sandplay`.
- 격자 (M3): `FSandGridGpu`, 단위 m, 장면 = `-sandwaves`. 서로 모른다.

## 순서

| 단계 | 만들 것 | 통과 기준 |
|---|---|---|
| **T1** 한 장면 | 파도 장면에 입자 시뮬. 입자 바닥 = 격자 `b` (꼭짓점 이선형 높이 · 법선, cm↔m 변환). 쌓기 도구 = 입자 (M2), 파기 = 격자 (T6) | 입자 더미가 경사 해변 위에 선다 · 판 구덩이 옆에서 미끄러져 들어간다 · 비용 — 통과 (m4-log #1), 도구 쌓기 연결 남음 |
| **T2** 장애물 마스크 | 입자 → 칸별 `uint64` 점유 비트 (지면 기준 높이 칸) → 바닥부터 연속 높이 `b_struct`. 유효 바닥 = `b + b_struct` (침식은 `b` 만). 바뀐 칸은 T6 경로처럼 `w` · `BSort` 갱신 | 물이 성을 **돌아간다** · 터널은 뚫린다 · 물 부피 보존 — 격자 시험 통과 (m4-log #2), 게임 화면은 처오름이 잠가 못 봄 |
| **T3** 젖음 | 물이 닿은 입자 W 상승 (h > 0 칸 · 입자 높이 < 수면) → cohesion(W) 과포화로 약화 | 파도에 잠긴 밑동이 젖어 약해진다 (사용자 화면 판정) — 구현 (m4-log #3), 판정 대기 |
| **T4** 파도 하중 | ① 벽 (b_struct 칸): 운동량 균형 반작용 `ρ g h̄ ∇b_struct ΔA` 를 그 칸 젖은 겉 입자에 나눔 (D-M4-1, 계수 없음 — 2026-11-09 사용자 승인) ② 그 밖 잠긴 입자: 부력 + 구 항력 (D-M4-2) | 하중 크기를 정지 수압 · 댐 붕괴 벽 충격 실험값과 대조 (자료는 구현 전 조사) — ① 구현 · 정수압 비 0.998 · Lobovský 첨두 0.34–0.67 배 (m4-log #4, papers D-M4-6). ② 구현 · 항력이 45 s 처오름에 블록 73 cm 끌고 감, 부력만은 안 움직임 (m4-log #5, papers D-M4-7) |
| **T5** 파괴 환원 | 결합 0 · 잠김 · 움직이는 입자 → 삭제, 부피를 격자 `b` (또는 T4b `s`) 로. 질량 보존 | Σ(입자 부피 + 격자 모래) 보존 < 0.1% — 구현 · 차이 0.01 % 통과, 잠긴 블록은 약 1 s 안에 전부 둔덕으로 (m4-log #6, papers D-M4-8) |
| **T6** 타일 sleep/wake | 4 m 타일 · 파도가 깨움 (세부는 아래 T6 절) | 비용 · 깨우기 지연 — 사전 측정: 거의 정지한 28 800 입자 = 시뮬 8.1 + 메시 4.7 ms (m4-log #8) |

- **실행 순서** (system-design §2): 도구 → 격자 스텝 → 격자→입자 (하중 · 젖음, 1 프레임 지연 허용) → 입자 스텝 → 입자→격자 (마스크 · 환원). 두 시뮬 모두 RDG 라 같은 프레임 안에서 순서대로 넣으면 GPU 버퍼를 공유한다 (CPU 왕복 없음).
- 단위: 격자 m · 입자 cm 그대로 두고 브릿지 패스에서 변환.

## 미리 아는 한계
- 말굽 와류 세굴은 안 나온다 (D-M4-3) — 수축 흐름 세굴만.
- 하이트필드 장애물이라 막다른 터널에도 물이 지나가고 지붕이 물을 누르지 못한다 (system-design 수용).
- 파도 하중 ①은 정수압 근사 — 쇄파 충격 첨두는 작게 나올 수 있다. T4 에서 실험값과 대조해 본다.

## T6 계획 (2026-11-10, 승인 대기)
system-design §소유권 타일 · §타일 상태 전이. 근거: 스트림 압축 = 접두합 (이미 있는 AddScan), papers C (블록 얼리기 — 잠든 쪽은 고정 입자처럼 받친다).
1. **패스별 GPU 시간** (RDG GPU 프로파일) — 8.1 ms 중 정렬 · 쌍 · 반복 · 통계 몫을 먼저 본다. 가장 큰 것부터.
2. **타일 상태**: 4 m 타일, 타일 안 입자가 모두 잠들면 잠듦. 깨우기 = 입자 하나라도 깸 · 격자 물 (h > 3 mm) 이 타일에 들어옴 · 도구 스탬프 · 이웃 타일 각성.
3. **활성 목록 압축**: 프레임마다 활성 타일 입자 + 잠든 이웃 타일의 경계 띠 (고정 입자로) 를 접두합으로 모아 입자별 패스를 간접 디스패치. 잠든 타일 입자는 정렬 입력에서 빠진다.
4. **메시**: 잠든 타일은 지난 메시 그대로 — 활성 타일 영역만 다시.
- 통과: 28 800 잠든 입자 장면 프레임 → 입자 없음 (9.15 ms) + 1 ms 안 · 파도 도달 → 깸 1 프레임 · T1–T5 결과 그대로.
