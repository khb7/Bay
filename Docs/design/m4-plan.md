# M4 — 브릿지: 파도가 성을 부순다 (계획 초안, 2026-11-09)

> milestones M4 · system-design §2 (실행 순서) · §4 `FFieldBridge`. 근거: [papers.md](../research/papers.md) **D-M4** · D-M3 (격자) · B (cohesion(W)) · C (XPBD).

## 지금 상태
- 입자 (M0–M2): `FSandGpuSim`, 단위 cm, 바닥 = 평면 z = 0 (`P.z <= Radius`), 장면 = `-sandplay`.
- 격자 (M3): `FSandGridGpu`, 단위 m, 장면 = `-sandwaves`. 서로 모른다.

## 순서

| 단계 | 만들 것 | 통과 기준 |
|---|---|---|
| **T1** 한 장면 | 파도 장면에 입자 시뮬. 입자 바닥 = 격자 `b` (꼭짓점 이선형 높이 · 법선, cm↔m 변환). 쌓기 도구 = 입자 (M2), 파기 = 격자 (T6) | 입자 더미가 경사 해변 위에 선다 · 판 구덩이 옆에서 미끄러져 들어간다 · 비용 |
| **T2** 장애물 마스크 | 입자 → 칸별 `uint64` 점유 비트 (지면 기준 높이 칸) → 바닥부터 연속 높이 `b_struct`. 유효 바닥 = `b + b_struct` (침식은 `b` 만). 바뀐 칸은 T6 경로처럼 `w` · `BSort` 갱신 | 물이 성을 **돌아간다** · 터널은 뚫린다 · 물 부피 보존 |
| **T3** 젖음 | 물이 닿은 입자 W 상승 (h > 0 칸 · 입자 높이 < 수면) → cohesion(W) 과포화로 약화 | 파도에 잠긴 밑동이 젖어 약해진다 (사용자 화면 판정) |
| **T4** 파도 하중 | ① 벽 (b_struct 칸): 운동량 균형 반작용 `ρ g h̄ ∇b_struct ΔA` 를 그 칸 젖은 겉 입자에 나눔 (D-M4-1, 계수 없음) ② 그 밖 잠긴 입자: 부력 + 구 항력 (D-M4-2) | 하중 크기를 정지 수압 · 댐 붕괴 벽 충격 실험값과 대조 (자료는 구현 전 조사) |
| **T5** 파괴 환원 | 결합 0 · 잠김 · 움직이는 입자 → 삭제, 부피를 격자 `b` (또는 T4b `s`) 로. 질량 보존 | Σ(입자 부피 + 격자 모래) 보존 < 0.1% |
| **T6** 타일 sleep/wake | 4 m 타일 · 파도가 깨움 | 비용 · 깨우기 지연 |

- **실행 순서** (system-design §2): 도구 → 격자 스텝 → 격자→입자 (하중 · 젖음, 1 프레임 지연 허용) → 입자 스텝 → 입자→격자 (마스크 · 환원). 두 시뮬 모두 RDG 라 같은 프레임 안에서 순서대로 넣으면 GPU 버퍼를 공유한다 (CPU 왕복 없음).
- 단위: 격자 m · 입자 cm 그대로 두고 브릿지 패스에서 변환.

## 미리 아는 한계
- 말굽 와류 세굴은 안 나온다 (D-M4-3) — 수축 흐름 세굴만.
- 하이트필드 장애물이라 막다른 터널에도 물이 지나가고 지붕이 물을 누르지 못한다 (system-design 수용).
- 파도 하중 ①은 정수압 근사 — 쇄파 충격 첨두는 작게 나올 수 있다. T4 에서 실험값과 대조해 본다.
