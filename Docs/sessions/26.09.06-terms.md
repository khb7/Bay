## 2. ★★ MPM 문서가 우리 설계로 읽힌다

[terms/mpm-particle-vs-grain.md](../research/terms/mpm-particle-vs-grain.md)는 **MPM 논문을 읽을 때의 주의사항**인데,
"우리 프로젝트 얘기가 아니다"가 어디에도 안 적혀 있었다. 실제로 그렇게 읽혔다.

| | 입자 하나의 정체 | 크기가 물리에 들어가나 | 거시 강도는 |
|---|---|---|---|
| DEM | 알갱이 1개 | 들어간다 | 접촉에서 창발 |
| **MPM** | 연속체 표본점 | **안 들어간다** — 순전히 해상도 | 구성 모델이 Pa로 직접 준다 |
| **우리 (XPBD 업스케일 결합 입자)** | 둘 다 아님 | 들어간다 | 접촉·결합에서 창발 |

**왜 이 구분이 실무적인가 — MPM이었다면 [papers.md §B-S2](../research/papers.md)가 통째로 불필요하다.**

```
MPM    cohesion 을 Pa 로 꽂으면 끝. 입자를 5cm 로 잡든 1cm 로 잡든 강도는 안 변한다
우리   접촉으로 강도를 만든다 → σ_t ∝ 1/d 가 그대로 물린다
       → 실제 모세관력의 약 220배를 넣는 상황, "점착에는 자가 없다"(B-S3) 가 여기서 나온다
```

→ 해당 문서에 ⚠ 절로 3범주 표와 이 대비를 박아넣었다.

> **일반화하면**: `terms/` 에는 *"우리가 쓰는 것"* 과 *"남의 논문을 읽기 위한 것"* 이 섞여 있는데
> 그 표시가 없다. 이번엔 하나를 고쳤을 뿐이다. [mpm.md](../research/terms/mpm.md)·[pic-flip-apic.md](../research/terms/pic-flip-apic.md)·
> [deformation-gradient.md](../research/terms/deformation-gradient.md) 등 A절 계열이 같은 위험을 안고 있다.

## 3. 입자 기초 — 읽는 순서 5층

주제별 색인에는 없던 것. **뒤 층이 앞 층을 전제한다.**

```
1층  왜 입자인가            lagrangian-vs-eulerian → mpm-particle-vs-grain → continuum
                            (+ 이번에 만든 fem 이 여기 붙는다)
 ↓
2층  솔버 골격  ← 80%       pbd → constraint → ★lagrange-multiplier
                            → stiffness → pbd-stiffness-compliance → compliance → xpbd
                            → iteration-relaxation → gauss-seidel-jacobi-sor → substep
 ↓
3층  모래가 되는 지점        coulomb-friction → return-mapping → angle-of-repose → friction-angle
                            = M0 가 지금 서 있는 층
 ↓
4층  젖은 모래 = 점착        cohesion → capillary-bridge → wet-granular-regimes
                            → papers.md §B-S2 (σ_t ∝ 1/d)
 ↓
5층  GPU 실전               neighbor-search → spatial-hash → radix-sort → prefix-sum
                            → graph-coloring / simulation-stages / dispatch·barrier·pass
```

**2층의 중심은 [λ](../research/terms/lagrange-multiplier.md) 하나다.** §C2의 `f_n = λn/h²`, §C3의 *"λn이 하중을 못 받는 상태"*,
§C4의 `λt < μs·λn` 게이트 — 세 논문의 논쟁이 전부 이 값 하나를 두고 벌어진다.

논문은 `C1 Macklin 2014 → XPBD 2016 → C2 Müller 2020 → C4 Frâncu 2014` 순.
**C3(Guendelman)은 깊은 더미를 겪은 뒤에** 읽어야 읽힌다.

## 4. 메운 공백 셋

| 새 문서 | 어디서 참조되고 있었나 | 없어서 생긴 문제 |
|---|---|---|
| [fem.md](../research/terms/fem.md) | lagrangian-vs-eulerian · mpm · polar-decomposition | MPM·PBD가 둘 다 *"FEM이 아닌 것"* 으로 자기를 설명하는데 그 FEM이 미정의 |
| [warm-starting.md](../research/terms/warm-starting.md) | [papers.md §C3](../research/papers.md) 결론 3번 · **[26.09.06 UE·문헌](26.09.06-ue-and-literature.md) §크리프가 이미 링크를 걸어두고 있었다** | 결론에 이름만 있고 내용이 없었다. 링크는 죽어 있었다 |
| [mass-scaling.md](../research/terms/mass-scaling.md) | §C3 표 — 무한 질량의 대안 | 위와 같음 |

> ★ **`warm-starting.md` 는 이미 참조되고 있었다.** [26.09.06 UE·문헌](26.09.06-ue-and-literature.md)이 크리프 대책으로
> `[워밍 스타트](../research/terms/warm-starting.md)` 링크를 걸어뒀는데 대상 파일이 없었다.
> 이번에 Docs 전체 상대 링크를 훑었고, **지금은 죽은 링크가 하나도 없다.**

**세 문서에 담긴 것 중 기존 문서에 없던 판단**

- **FEM 기각 이유는 속도가 아니라 위상(topology)** 이다. 무한히 빨라져도 모래엔 안 맞는다 —
  재료가 섞이는 순간 "붙어 있는 메시"라는 전제 자체가 사라진다
- **워밍 스타트 vs shock propagation** = 무게를 느낀 상태를 *보존*하느냐 *버리고 굳히느냐*.
  ⚠ 단 Frâncu §7이 *"Jacobi 계열에선 GS만큼 극적이지 않다"* 고 명시 — 기대치를 낮출 것
- ⚠ **명칭 정정** — §C3이 대안으로 지목한 Tonge 2012의 실제 기법명은 *mass **splitting*** 이다.
  "질량 스케일링"은 상위 계열명. 문헌을 찾을 때 두 단어를 다 넣어야 한다
- ★ **질량 스케일링은 교정 실험을 오염시킨다.** 유효 질량 → `λn` → `μ·λn` 마찰 예산이 바뀌어
  안식각이 물성이 아니라 솔버 설정의 함수가 된다. **교정을 먼저 끝내고 성능 대책으로 나중에 켤 것**
