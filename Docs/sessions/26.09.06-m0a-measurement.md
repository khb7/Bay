## 한 줄 요약

**코드는 거의 안 고쳤는데 하루가 갔다. 전부 "무엇을 재고 있었나"였다.**

```
붕괴 판정   네 번 교체    −3.5° 절편이 물리가 아니라 판정이 만든 것으로 판명
재는 값     정체 정정      θm 을 재면서 θr 기준과 비교하고 있었다
측정법      두 번 더 교체  경사판 → 원통 들어올리기 → 부어 쌓기
```

전날이 "솔버가 맞는가"였다면 오늘은 **"자가 무엇을 가리키는가"** 였다.
그리고 **하루의 절반은 계기를 만드는 데 썼다** — 그게 매번 시간을 아꼈다.

## 1. 이어받은 상태

```
마찰 공식      단일 입자에서 오차 1~2°     ✓ 전날 확정
안식각         atan(μ) − 3.5°             ✗ 절편의 정체가 미상
```

**−3.5° 가 물리인지 절차인지 가르는 것**으로 시작했다.
[papers.md §A-R7](../research/papers.md)이 가설을 줬다 — *"N초 붙잡고 변위"는
사태가 아니라 [크리프](../research/terms/creep.md)를 잴 수 있다.*

---

## 2. ★ −3.5° 는 물리가 아니었다

### 크리프가 실재한다 (#13)

`μ=0.4`(임계 17.6°)에서 **5°로 붙잡고 16초**. 물리적으로 확실히 버텨야 하는 각이다.

```
        평균 속력      초당 변위
 1초    0.361  ↓       0.016  ↑
16초    0.144  ↓       0.035  ↑      6초 이후 일정 = 스텝당 5.8μm
```

**두 양이 반대로 움직인다.** 평균 속력은 방향을 안 보므로 제자리 떨림이 잦아들며 내려가고,
변위는 방향을 보므로 **한쪽으로 흐른 것만 남는다.** 흔들림은 죽고 드리프트는 안 죽는다.

### 유지 시간 스윕이 확정했다 (#14)

사태라면 관찰 시간과 무관해야 한다.

```
유지 시간    μ=0.3            μ=0.4
 1초        15.72° (−0.98)   20.10° (−1.70)
 4초        13.81° (−2.89)   17.64° (−4.16)
16초         8.07° (−8.63)    9.16° (−12.64)
```

**단조 감소 = 판정이 사태가 아니라 크리프 누적을 재고 있다.**

그리고 뜻밖의 소득 — **유지 1초 오차가 −1.0/−1.7°로, 단일 입자 시험(−0.9~−2.5°)과 같은 크기다.**
솔버의 마찰은 이미 맞았고 **−3.5° 는 전부 판정이 만든 것**이었다.

### 판정 4종, 실패 방식이 매번 달랐다 (#15)

| 판정 | 유지 시간 무관 | μ 단조 | 실패 지점 |
|---|---|---|---|
| 누적 변위 > `0.5r` | ✗ | ○ | 크리프도 시간만 주면 임계를 넘는다 |
| §2-2 그대로 | ○ | ✗ | **60프레임 "연속"이 스파이크 한 번에 부러진다** |
| 앞/뒤 속도 비교 (전체) | ○ | ○ | 닫힌 상자의 **벽에 눌린 입자**가 안 죽는다 |
| 앞/뒤 속도 비교 (중앙 60%) | △ | ○ | 창이 길면 **잡음이 부등호를 결정** |

> **★ 한 시험으로는 못 걸렀다.** 유지 시간 스윕과 `μ` 단조성을 **둘 다** 봐야 넷이 갈렸다.
> 어느 하나만 봤으면 §2-2(시간 무관)나 변위(μ 단조)를 통과시켰을 것이다.

**판단** — `θ_start`(개시각)는 "아무 일도 없음"과 "막 시작함"의 경계라
판정이 언제나 잡음과 크리프 위에 놓인다. **원리적으로 취약하다.**

## 3. ★ 재는 값이 틀렸다 — `θm` vs `θr` (#16)

실행이 아니라 판단이다. [A-R4](../research/papers.md)를 우리 문서에 대조한 결과.

```
θm  최대안정각   정지한 더미가 무너지기 시작하는 각    ← 경사판이 재는 것
θr  안식각      사태가 끝난 뒤 남은 표면의 각          ← 34° 가 가리키는 것
                2~5° 차이 (Jaeger 1989)
```

`talusDry` 34°가 `θr`인 결정적 근거는 **격자 모델의 정의**였다 —
[열침식](../research/terms/thermal-erosion.md)이 `경사 > talus 면 아래로 옮긴다`이므로,
**옮기기를 멈추는 각**이 곧 `talusDry`, 즉 "흐른 뒤 남는 각" = `θr`.

**기준과 측정 대상이 어긋나 있었고, 방향도 나쁘다** — 기준을 `θm`(36~39°)으로 올리면
격차가 오히려 벌어진다.

> **부산물** — 격자는 각도가 하나뿐이라 `talus`보다 가파른 경사를 만들 수 없고,
> 입자는 `θr`~`θm` 사이에 **불안정하지만 서 있는 상태**를 가진다.
> 그 이력이 ★덩어리 붕괴가 요구하는 "버티다 갑자기 무너진다"의 물리적 정체다.
> **결함이 아니라 입자 계층의 존재 이유였다.**

## 4. 벽이 규약을 어기고 있었다 (#17~#19)

`θr`을 재려고 원통 들어올리기를 만들었더니 18층 기둥이 다지기에서 부풀었다.
**반복도 서브스텝도 안 들었다** — 어느 축으로도 경향이 없었다. 수치가 아니라 구조라는 신호.

```cpp
// SolveWalls — 위치만 자르고 속도는 그대로
Pos[i].X *= Sc;  Pos[i].Y *= Sc;
```

**전날 없앤 고리를 벽에서 되살린 꼴이었다.** SP의 핵심은 임펄스 하나에서 `v`와 `x`를 함께 내는
것인데 벽만 위치를 잘랐다. PBD 경로에서는 어차피 역산했으므로 무해했고, 6층 상자는 벽 접촉
비율이 작아 안 드러났다. 좁은 원통에 18층 하중이 걸리자 크게 터졌다.

`SolveWallsSP`로 교체하니 78cm → 63cm로 다져졌다(입방 0.52 → 조밀 0.64의 19% 수축과 일치).

> **솔버 규약을 바꿀 때 일부만 바꾸면 안 바꾼 쪽이 통째로 오염원이 된다.**
> 전날의 ②와 같은 실수이고, 이번엔 하루를 먹었다.
> **경사판 `θm` 값들도 이 결함 상태에서 잰 것이라 재측정 대상이다.**

### 계기 둘을 더 만들었다

| 계기 | 발견한 것 | 비용 |
|---|---|---|
| **유지 시간 스윕** (#14) | 붕괴 판정이 크리프를 잰다 | 실행 3회 |
| **★ 잡음 바닥** (#19) | 반복 45는 잔류 속력이 **오른다**(발산) | **10초** |

잡음 바닥이 가장 값싸다 — 기울이지 않은 수평 10초, **잔류 속력의 기울기 부호만** 본다.
기둥을 통째로 다져보는 것(212초)보다 20배 싸다. **새 장면·새 설정마다 이것부터 통과시킨다.**

거친 바닥이 기둥 밑에만 깔려 있던 것도 여기서 나왔다 — 퇴적 원뿔의 바깥 절반이 매끄러운
지면 위라 **바닥 마찰이 반경에 따라 달라졌고**, 기울기가 둘인 퇴적물이 되어 두 판독 방식이
6~8° 어긋났다. 고정층을 기둥 반경의 2.5배로 확장.

## 5. 측정법을 두 번 더 바꿨다 (#20~#22)

| 방법 | 왜 버렸나 |
|---|---|
| 경사판 (`θm`) | 재는 값이 기준과 다르다(§3). 붕괴 판정도 네 번 갈아엎었다 |
| 원통 들어올리기 | **파괴가 국소적이지 않다.** 밑동을 풀면 기둥 전체가 한 번에 무너진다. 계단을 잘게 나눠도 같다 |
| **부어 쌓기** | 현재. **불안정 상태를 애초에 만들지 않는다** |

### 기각 근거가 실험실 논리였다

문서의 원 문구는 *"쏟는 속도·낙하 높이·구멍 크기가 전부 변수라 두 번 돌려도 다른 더미가 나온다"*
였는데 — **그건 실험실의 문제지 시드 고정 시뮬의 문제가 아니다.** 바이트 단위로 재현된다.

남는 것은 "결과가 그 변수에 의존한다"인데, **경사판은 임의 상수가 더 많았다**
(유지 시간·트리거·관찰 구역·이분 탐색).

> **실험실 논리를 시뮬에 그대로 적용하면 안 된다.** 재현성 문제의 상당수가 시뮬에서는 사라지고,
> 대신 그 방법이 요구하는 **임의 상수의 개수**가 진짜 기준이 된다.

## 6. 극단에서만 터지는 결함들

새 장면을 만들 때마다 하나씩 나왔다. 공통점이 있다.

```
벽 제약이 SP 규약 미준수     느린 6층에서는 안 보이고 18층에서 터진다
접촉 여유 상한이 2r          느린 입자는 안 놓치고 2000 cm/s 에서 통과해버린다
생성 높이가 전역 최고점 참조  한 번 튀기 전까지는 안 드러난다
```

**정상 범위에서는 보이지 않다가 극단에서 터진다.**
접촉 여유는 M4(파도가 성을 때림)에서 같은 조건이 되므로 **지금 고친 것이 그때를 산 것**이다.

## 7. 타임박스가 답한 것

3일 상한에 도달했다. 문서 규칙은 *"더 하면 될 것 같다가 아니라 M0가 답을 줬다는 뜻"* 이다.

**다만 답은 "아니오"가 아니었다.**

```
마찰 공식      단일 입자에서 오차 1~2°                    ✓
하중 전달      λn 이 깊이에 선형 (ρgh 대비 0.91~1.00)     ✓
μ 반응성       0.2/0.3/0.4 에서 단조 증가                 ✓
안식각 절대값  ✗ 미확정
```

**상한이 잡아낸 것은 설계 결함이 아니라 측정의 어려움**이었다.

그리고 안식각을 "전제"로 올린 이유 자체가 *"마찰 클램프가 제대로 도는지 확인하는 유일한 방법"*
이었는데, **그 확인은 단일 입자 시험이 이미 해줬다.** 34°는 게임 튜닝 값이지 뼈대 교정에
반드시 필요한 값이 아니다.

→ **`μ = 0.7`을 잠정값으로 박고 3-1(터널)로 간다.** 터널은 각도가 아니라 "천장이 버티는가"를
묻는 차단 검증이라 `μ` 정밀도에 답이 뒤집히지 않는다. 거기서 "아니오"면 안식각을 아무리 맞춰도
소용없고, "예"면 그때 마저 닫는다.
