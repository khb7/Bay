## 한 줄 요약

**M0-a가 측정에서 막혀 있는 동안, 옆에서 용어와 문헌을 붙인 세션.**
질문 하나가 문서 하나를 만드는 식으로 진행됐고, 도중에 **M0의 병목에 정확히 대응하는 논문 둘**을 찾았다.

```

문헌    papers.md C3 · C4        솔버 수렴 — 적층 하중 전달
        papers.md A-R4~A-R7      측정 프로토콜 — 재는 값의 정체
계측    m0-ruler.md 신설         계기·오차 예산의 단면
```

## 1. 성격 — 두 갈래가 한 세션에 있었다

```
앞쪽   UE 기초 학습        Unity 출신이라 UE 를 처음 만진다
뒤쪽   M0 지원 문헌 조사    앞쪽 질문이 용어 공백을 드러내며 자연스럽게 넘어갔다
```

경계는 **"jitter가 뭘 흔드는 거냐"** 였다. UE 문서를 읽다 나온 질문인데,
답하려니 스펙트럼 이산화가 필요했고, 거기서 리만 합이 나오고, 그게 시간 적분으로,
다시 XPBD의 라그랑주 승수로 이어졌다. **용어집 공백이 사슬로 드러났다.**

## 2. UE 기초 — Unity 감각에서 뒤집을 것들

문답으로 처리하고 문서로 안 남긴 것들. 정리해두면 다음에 안 묻는다.

| | Unity | UE |
|---|---|---|
| 단위 | 1 = 1m | **1 = 1cm** (성 2~3m = 200~300 uu) |
| 축 | Y-up | **Z-up** |
| 좌표 정밀도 | float | **double** (LWC) — `FVector`는 double3 |
| 회전 | 쿼터니언 기본 | **`FRotator`**(오일러, 도 단위) 기본. `+`는 회전 합성이 아니다 |
| 전역 상수 | static | Niagara **네임스페이스**가 저장 위치·갱신 주기·쓰기 권한을 함께 정한다 |

**그중 하나는 설계 문서로 갔다** — [system-design.md §2 수치 타입](../design/system-design.md).
`FVector`(double3)를 입자 30만 개 배열에 쓰면 메모리 2배, SIMD 절반, GPU는 1/32~1/64다.
**시뮬 내부는 `float`/`FVector3f`, 엔진 경계만 `FVector`, 누적 스칼라만 `double`.**

## 4. ★ M0 병목에 문헌을 붙였다

M0-a가 **"Jacobi는 하중이 안 가고 GS는 에너지를 주입한다"** 로 갇혀 있었다.
그 진단을 그대로 문헌에 대조했다.

### 솔버 — papers.md C3 · C4

| | 무엇을 말하나 |
|---|---|
| **C3. Guendelman 2003** | 깊은 더미 수렴의 정본. **처방보다 경고가 값졌다** — shock propagation을 먼저 걸면 "무게를 느끼지 못한다"(시소 실험). 반복의 대체가 아니라 마무리다 |
| **C4. Frâncu 2014 ★★** | 입자 + Jacobi + 마찰이 정확히 우리 설정. 모멘텀 항 하나(식 38)와 **Sequential Positions**(§6 Algorithm 1) |

**C4 §6이 M0의 진단을 정정했다.** 에너지 주입 고리의 출처는 GS의 즉시 갱신이 아니라
**PBD가 `v = (p−x)/h`로 속도를 역산한다는 것**이다 — GS를 버려도 PBD인 한 고리는 남는다.
SP는 임펄스 하나에서 `v`와 `x`를 함께 내어 그 고리를 원천 차단한다.

> M0-a가 SP로 교체했고 **단일 입자 오차가 −3.7° 상수 → −0.9~−2.5°** 로 떨어졌다
> ([m0-log.md](../design/m0-log.md) #11). 문헌 하나가 하루를 아꼈다.

### 측정 — papers.md A-R4~A-R7

| | 무엇을 말하나 |
|---|---|
| **A-R4. Jaeger 1989 ★★** | `θm`(최대안정각) ≠ `θr`(안식각), 2~5° 차이. **경사판은 정의상 `θm`을 잰다** |
| **A-R5. Pouliquen 1999 ★★** | `θ_start`/`θ_stop`은 층 두께의 함수. 경사판에 표준 프로토콜이 있다 |
| **A-R6. GDR MiDi 2004** | 준정적은 관성수 `I ≲ 10⁻³`. 기울기 속도를 숫자로 정당화한다 |
| **A-R7** | 정지 판정에 속도(cm/s) 표준값은 없다. 문헌은 전부 **무차원 비율** |

**A-R4가 M0의 기준을 통째로 바꿨다** — `talusDry` 34°가 `θr`인데 경사판으로 `θm`을 재고 있었다.
주 교정이 원통 들어올리기로 옮겨갔다([m0-log.md](../design/m0-log.md) #16).

**덤** — Albert et al. 1997이 `θm`을 **응집력의 함수로** 계산하고 젖은 입상체에 적용했다.
경사판이 재는 양을 그대로 `W`의 함수로 주므로 **M1의 `cohesion(W)` 검증 곡선**이 된다.

## 5. ★ 크리프 — 가설에서 확정까지

이 세션에서 가장 값진 사슬이다. **문헌 → 가설 → M0 실측 → 확정**이 하루 안에 돌았다.

```
① A-R7 을 정리하다  "N초 붙잡고 변위"는 사태가 아니라 크리프를 잴 수 있다  ← 가설
② M0 에 넘김        유지 시간을 축으로 스윕하면 갈린다                    ← 검증 설계
③ M0 실측 (#13·#14) 1/4/16초 → 15.7 / 13.8 / 8.1°  단조 감소            ← 확정
④ 뜻밖의 소득       유지 1초 오차 −1.0/−1.7° = 단일 입자와 같은 크기
                    → −3.5° 는 물리가 아니라 판정이 만든 것이었다
```

**그리고 사용자가 한 번 더 밀었다** — *"5°에서 계속 흘러내리면 그건 움직이는 게 맞지 않나."*
맞는 지적이었고, 그래서 [creep.md](../research/terms/creep.md)가 나왔다.

```
문제 A  안식각을 재려면 사태와 크리프를 구분해야 한다   → 판정 교체가 해결
문제 B  5°에서 모래가 흐르면 안 된다                   → 판정 교체가 해결 못 한다
```

**B는 별도로 남는다.** `0.035 cm/s = 시간당 126cm`이고 `timeScale`이 1× 실시간이므로
**성이 시간당 1m씩 주저앉는다**는 뜻이다. 게임 정의("30분 뒤에 보러 가는 것이 콘텐츠")에 직접 걸린다.

그리고 계기가 하나 딸려 나왔다 — **크리프 속도가 수렴도 지표**다.
반복을 올려 줄면 수렴 부족, 안 줄면 구조 문제. 목표선도 물리가 정해준다: **일정하면 안 되고 잦아들어야 한다.**

## 6. ★ 도중에 뒤집은 것 — 정정 이력

이 시리즈에서 가장 값진 절이다. **내가 틀린 것부터.**

| 뒤집은 것 | 무엇이 틀렸나 |
|---|---|
| **"Krylov 계열엔 반복당 한 칸 제한이 없다"** | 원문을 받아 읽으니 Frâncu 식 (38)은 **전역 내적을 뺀 국소 근사**였다. 정보는 여전히 반복당 한 칸이고, 이득은 heavy-ball 가속에서 온다 |
| **−3.5°에 더미 수준 설명을 붙였다** | 층 두께·벽 지지·관찰 창을 갖다 댔는데 그 값은 **단일 입자 시험**의 것이다. 입자가 하나면 그 셋은 전부 무의미하다 |
| **"§3-0이 낡았다"** | 오래된 읽기를 기준으로 말했다. 이미 3-0-A/B/C로 재구성돼 있었다 |
| **"앞/뒤 비교는 절대 크기를 안 쓴다"** | 과장. 길이 척도는 빠지지만 상수가 0이 되진 않는다(비율 임계·창 길이·잡음 바닥) |
| **`timeScale` 25× 기준으로 ⚠를 썼다** | 이미 1× 실시간으로 폐기된 결정이었다. 옛 문서 상태로 쓴 것 |

**M0 세션이 정정한 것.**

| | |
|---|---|
| **§2-2를 그대로 쓰자는 제안** | 실패했다. **60프레임 "연속"이 스파이크 한 번에 부러진다** — 구간 평균은 임계의 1/10인데도 거의 전부 "정지 못 함"이 됐고 `μ` 순서가 뒤집혔다 |
| 이분 탐색 이력 오염 우려 | 구현에 없었다. 매 시행이 `RestoreState`로 같은 다진 상태에서 출발한다 |
| 두 −3.5°가 같은 원인이라는 추정 | 근거가 약하다고 반박받았다. 절차가 다르므로 각각 확인이 필요하다 |

> **★ 교훈 — 문헌의 정신이 맞아도 기존 구현이 그것을 못 받을 수 있다.**
> A-R7의 "무차원 비율로 판정하라"는 옳았는데, 그 정신을 §2-2에 얹으니
> **"연속"이라는 기존 조건이 통째로 부러졌다.**
> 제안을 넘기기 전에 **대상 구현의 형태**를 확인해야 한다.
