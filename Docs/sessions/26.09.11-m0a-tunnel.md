## 1. 경사판 (#30)

벽 워밍 뒤에도 70° 까지 안 무너진다. `lastSlide` 가 세 실행 모두 정확히 0 — 판정 계측이 죽어 있다. 정보성이라 3-2 직전으로 이월.

## 2. 크기 편향 (#31)

6000개 더미(반경 24d)가 1200개(14d)보다 5° 완만하다. 시드 3개, 크리프·하중·불평형비 정상. Coetzee 의 수렴 조건(≥10~20d) 안쪽에서 교정한 값이라
**μ 0.13 은 1200 크기의 값**이다. 게임 규모(2만 개)에서는 29° 근처일 수 있다. 미결로 올리고 M0-b 전에 12000+ 에서 재교정.

## 3. 터널 (#32)

블록은 상자 붓기 + 램프 다지기 + 벽 워밍 + 준비 창(0%). W 0.15 결합 → X 축 관통 터널 한 번에 제거 → 30초.
첫 크래시(제거 뒤 압축 배열을 옛 인덱스로 읽음)를 잡고 연기 시험 한 번, 그다음 묶음 12회.

```
원형 30  선다 (0.1%)        사각 30  붕괴 (98.9%)        대조군 W=0  둘 다 붕괴
```

문서 실패 분기의 첫 줄 그대로다. B-S1 손계산(사각 아슬아슬 · 아치 여유)과 맞고, 대조군이 무너져 기하가 아닌 점착의 답임이 확인됐다. 튜닝 없이 통과.

## 4. 덩어리 붕괴 (#33) ★

터널 블록에서 W 를 2분에 걸쳐 0 으로. 창마다 새로 움직인 입자를 그 순간의 결합 그래프로 파편화.
첫 실행에서 하한 눈금자의 기준 위치 버그(유지 뒤로 잡아 뚫자마자 무너진 대조군의 이동이 0)를 잡았다.

```
W 0.113 까지 버팀 → 0.100 에서 5초 안에 36% 이동 → 최대 파편 1025 = 상부 블록 전체 침하.  MWMS 713 vs 하한 ''' + LOW + u'''
```

**통과. 게임의 정체성 요구("버티다 갑자기, 덩어리로")가 튜닝 없이 나왔다.** 상한 눈금자 정의(breakStretch 3)는 연성이라 상한이 아니었다 — 폐기.
