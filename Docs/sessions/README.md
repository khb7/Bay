# 세션 기록 — 시간순

각 세션이 **어떤 모양으로 흘렀는가**를 담는다. 주제별 정리는 결과만 남기고 경로를 지우므로,
"왜 그렇게 정했는지"와 **"무엇을 도중에 뒤집었는지"** 는 여기에만 있다.

| | 세션 | 날짜 | 남긴 것 |
|---|---|---|---|
| 01 | **[조사](01-research.md)** | 2026-09-04~05 | 논문 130여편 · 용어 156개 · 파라미터 프리셋. ★정정 이력 |
| 02 | **[설계](02-design.md)** | 2026-09-04~05 | 아키텍처 확정 · 기각 근거 · 구현 순서 M0~M8 |
| 03 | **[M0-a 구현](03-m0a-implementation.md)** | 2026-09-05 | UE 프로젝트 · XPBD 입자 코어 · 계기 5종. 안식각은 미확정 |

## 세션별 성격

**01 조사** — 무엇을 만들지 정하기 전에 무엇이 가능한지 알아본 기록.
정정 이력(§4)이 값지다. 같은 함정에 다시 안 빠지려면 그것부터.

**02 설계** — 조사 결과를 놓고 내린 결정과 **기각한 것들의 근거**.
"설계하지 않았는데 나오는 것들" 절이 원칙 §0(창발 우선)이 실제로 작동한 증거다.

**03 M0-a 구현** — 첫 코드. **물리보다 측정이 어려웠던 세션**이다.
계기를 네 번 만들었고 측정법을 네 번 바꿨다. 판단이 두 번 뒤집혔고 그 원인이 전부
"터진 더미 위에서 쟀다"였다 — 다음 세션이 물려받을 가장 중요한 교훈.

## 반복해서 나온 패턴

세 세션에 걸쳐 같은 종류의 실수가 반복됐다. **새 작업을 시작할 때 이 목록부터 볼 것.**

| 패턴 | 어디서 |
|---|---|
| **측정값이 이상하면 물리보다 계기를 먼저 의심** | 03 §3 — 네 번 다 계기 문제였다 |
| **검증용 시험체가 비현실적이면 멀쩡한 자를 불량 판정** | 03 §3 — 격자 계단이 −5° 편향을 만들었다 |
| **규약을 바꾸면 전부 바꿔야 한다** | 03 §2 — 벽만 남겨둔 것이 하루를 먹었다 |
| **실험실 논리를 시뮬에 그대로 적용하지 말 것** | 03 §4 — 부어 쌓기 기각 근거가 그것이었다 |
| **정상 범위에서 안 보이는 결함이 극단에서 터진다** | 03 §5 — 접촉 여유·벽 제약·생성 높이 |
