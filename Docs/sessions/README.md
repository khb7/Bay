"왜 그렇게 정했는지"와 **"무엇을 도중에 뒤집었는지"** 는 여기에만 있다.

## 세션별 성격

**26.09.04 조사** — 무엇을 만들지 정하기 전에 무엇이 가능한지 알아본 기록.
정정 이력(§4)이 값지다. 같은 함정에 다시 안 빠지려면 그것부터.

**26.09.04 설계** — 조사 결과를 놓고 내린 결정과 **기각한 것들의 근거**.
"설계하지 않았는데 나오는 것들" 절이 원칙 §0(창발 우선)이 실제로 작동한 증거다.

**26.09.05 M0-a 구현** — 첫 코드. 프로젝트 생성부터 코어까지 반나절, 나머지는 전부 마찰 하나였다.
마찰 공식을 네 번 갈아엎어 단일 입자 오차 1~2°까지 닫았다. 계기 둘(자 교정·안정성)이
**결론의 부호를 두 번 뒤집었다** — "터진 더미 위에서 쟀다"가 원인.

**26.09.06 M0-a 측정** — 코드는 거의 안 고쳤는데 하루가 갔다. 전부 **"무엇을 재고 있었나"** 였다.
붕괴 판정 넷, 측정법 둘을 갈아엎었고 −3.5° 절편이 물리가 아니라 판정의 산물로 판명됐다.
§2의 "한 시험으로는 못 걸렀다"가 다음 세션이 물려받을 교훈.

**26.09.06 해상도와 점착** — 코드는 한 줄도 안 고친 **문헌 세션**. 질문 하나("5cm 입자로 30cm 터널이
서는가")가 실험 설계 전체를 바꿨다. 전날의 교훈이 문헌 층위에서 반복됐다 —
**자(`c[Pa]`)가 없으면 어떤 논문도 못 쓴다.**

**26.09.06 UE 학습·문헌 지원** — M0-a가 측정에서 막힌 동안 옆에서 돈 세션.
UE 기초 질문이 용어 공백을 사슬로 드러냈고, 그 끝에서 **M0 병목에 정확히 대응하는 논문 둘**이 나왔다.
정정 이력(§6)에 내가 틀린 것 다섯과 M0가 반박한 것 셋이 있다.

**26.09.09 M0-a 크리프와 결정** — "2074 cm/s 한 줄"로 시작해 안식각을 닫은 세션. 첫 가설 셋(충격·서브스텝·마찰)이 전부 기각됐고,
답은 솔버(워밍 스타트)와 시험체(격자 바닥) 양쪽에 있었다. §8 의 실수 기록 — "숫자가 하나까지 같으면 코드가 안 바뀐 것".

**26.09.09 DEM 캘리브레이션** — 코드 한 줄 안 고친 **문헌 세션**. "솔버 상수가 뭔가"라는 용어 질문에서 시작해
§2-1 표의 구조가 틀렸다는 데까지 갔다. 가장 값진 것은 새 문서가 아니라 **`substep`·반복이 애초에 캘리브레이션 대상이 아니었다는 것**(§3) —
판정 기준이 솔버 안에 있는 값을 34°로 튜닝하면 미수렴을 물리 파라미터로 쓰게 된다.
§7 이 이 세션의 반전이다: 제안한 검사를 **병렬 세션의 #25 실측이 이미 통과**하고 있었다.

**26.09.10 점착 결합과 벽** — 점착을 짜고 자를 세우는 데 결함 여섯을 걷어냈고, 사용자의 §2-1-a 가 예산과 μ 를 분리했다.
마지막 반나절은 "상자에 부은 블록이 왜 끓는가"였고 답은 #18 의 재판: 벽만 워밍에서 빠져 있었다.

**26.09.06 용어** — 질문 넷이 **감사(audit) 노릇**을 한 세션. 코드 변경 없음.
가장 값진 것은 새 문서가 아니라 **MPM 용어 문서가 우리 설계로 오독된다는 발견**(§2)이다.
주제별 색인에 없던 **입자 기초 읽기 순서 5층**(§3)이 여기 있다.

## 반복해서 나온 패턴

일곱 세션에 걸쳐 같은 종류의 실수가 반복됐다. **새 작업을 시작할 때 이 목록부터 볼 것.**

| 패턴 | 어디서 |
|---|---|
| **측정값이 이상하면 물리보다 계기를 먼저 의심** | 26.09.05 §3 · 26.09.06 측정 §4 — 매번 계기 문제였다 |
| **검증용 시험체가 비현실적이면 멀쩡한 자를 불량 판정** | 26.09.05 §3 — 격자 계단이 −5° 편향을 만들었다 |
| **규약을 바꾸면 전부 바꿔야 한다** | 26.09.06 측정 §4 — 벽만 남겨둔 것이 하루를 먹었다 |
| **실험실 논리를 시뮬에 그대로 적용하지 말 것** | 26.09.06 측정 §5 — 부어 쌓기 기각 근거가 그것이었다 |
| **정상 범위에서 안 보이는 결함이 극단에서 터진다** | 26.09.06 측정 §6 — 접촉 여유·벽 제약·생성 높이 |
| **문헌의 정신이 맞아도 기존 구현이 그것을 못 받을 수 있다** | 26.09.06 UE §6 — §2-2 의 "연속" 조건이 통째로 부러졌다 |
| **자가 없으면 문헌도 못 쓴다 — 병목은 늘 계기 쪽** | 26.09.05 §3 · 26.09.06 해상도 §3 — 각도 다음은 강도였다 |
| **같은 "무너진다"라도 파괴 모드가 다르면 다른 값을 잰다** | 26.09.05 §4(기둥 붕괴) · 26.09.06 해상도 §4(얇은 벽) |
| **불확실 목록은 방향까지 틀릴 수 있다** | 26.09.06 해상도 §1 — 위험이 "안 선다"가 아니라 "무조건 선다"였다 |
| **자동 생성과 수동 관리가 섞이면 수동 쪽이 조용히 어긋난다** | 26.09.06 용어 §5 — 푸터는 스크립트, 색인은 손. 9개가 벌어져 있었다 |
| **남의 논문을 읽기 위한 문서가 우리 설계로 읽힌다** | 26.09.06 용어 §2 — MPM 규약을 우리 규약으로 오독 |
| **통과처럼 보이면 물리 아닌 변수(입자 수·반복 수)를 바꿔본다** | 26.09.09 §3 — 34.5° "통과"가 입자 수에 따라 42°~26° 였다 |
| **결과가 숫자 하나까지 같으면 코드가 안 바뀐 것** | 26.09.09 §8 — 잘못된 디렉터리·인자 순서로 무효 실행 세 세트 |
| **거칠기와 템플릿은 다르다 — 무작위가 아니면 결정이 자란다** | 26.09.09 §6 — 정사각 격자 바닥이 FCC 를 키워 45° |
| **소거표가 다 비면 코드에서 빠진 규약을 찾아라** | 26.09.10 §6 — 가설 여섯 뒤에 벽 λ 워밍 누락. #18 의 재판 |
| **시험체가 절토 전에 정지해 있는지부터 잰다** | 26.09.10 §6 — 준비 창 시계열이 무효 교정 두 세트를 걸렀다 |
| **문헌은 답보다 '무엇이 미지수인가'를 먼저 고쳐준다** | 26.09.09 캘리브 §3 — 미지수 셋 중 둘은 애초에 대상이 아니었다 |
| **환산이 필요하면 그 논문이 이미 했는지부터 본다** | 26.09.09 캘리브 §5 — 초록만 보고 유도하다 2배를 틀렸다. 원문 4쪽에 식이 있었다 |
| **우리 데이터가 이미 답을 갖고 있을 수 있다** | 26.09.09 캘리브 §7 — 새 스윕을 제안했는데 #25 가 이미 통과 |
| **논문 요약 도구는 없는 내용을 만들어낸다 — 원문 확인 전엔 못 쓴다** | 26.09.09 캘리브 §9-⑤ |
