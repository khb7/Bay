## 2. 마찰을 네 번 틀렸다

첫 실행이 26.5°를 냈다(목표 34°). 원인을 쫓는 과정에서 **범인이 계속 바뀌었다.**

| # | 증상 | 진단 | 수정 |
|---|---|---|---|
| 1 | 각이 낮다 | `μ`×침투량 클램프가 하중을 못 받는다 | — |
| 2 | 더미가 부풀어오른다 | **즉시 반영이 마찰 되먹임 고리를 만든다** | Gauss-Seidel → Jacobi 평균 |
| 3 | 반복이 마찰 계수가 된다 | **반복마다 예산이 새로 주어진다** | 누적 임펄스 클램프 |
| 4 | `μ` 가 여전히 무반응 | **PBD 의 `v = (p−x)/h` 역산이 진짜 출처** | Sequential Positions |

**④가 나온 경로가 이 날의 핵심이다.** ②에서 Gauss-Seidel을 범인으로 지목해 Jacobi로 바꿨는데,
그러자 이번엔 하중이 바닥까지 못 갔다. 둘 다 실패한 뒤에야
[papers.md C4 §6](../research/papers.md)이 원인을 정정해줬다 —
**고리의 출처는 즉시 갱신이 아니라 PBD의 속도 역산**이고, GS를 버려도 PBD인 한 고리는 남는다.

Sequential Positions는 임펄스 하나에서 `v`와 `x`를 함께 낸다.
그것 하나로 **단일 입자 오차가 −3.7° 상수 → −0.9~−2.5°** 로 떨어졌다.

> ⚠ **같은 실수가 다음 날 한 번 더 나온다** — 벽 제약만 옛 방식으로 남아 있었다.
> 규약을 바꾸면서 일부만 바꾸면 안 바꾼 쪽이 통째로 오염원이 된다.

**결말** — 단일 입자가 `atan(μ)` 를 오차 **1~2°** 로 따라간다. 마찰 공식은 무죄다.

## 3. 계기가 먼저 필요했다 — 둘

물리를 보려던 시도가 두 번 다 **계기 문제**로 판명됐다.

| 계기 | 발견한 것 | 그 전까지 |
|---|---|---|
| **자 교정** (합성 원뿔) | 각도 측정기가 15~34° 에서 **표본 0개** | 26.5° 를 물리로 해석하고 있었다 |
| **안정성 검사** (다지기 후 높이) | 반복 45 미만은 더미가 **터진다** | 터진 더미 위에서 각을 쟀다 |

**안정성 검사가 결론의 부호를 뒤집었다.**

```
불안정 영역(it=30)   모멘텀 a=0.5 → 각이 18.2 → 9.2°    "모멘텀이 해롭다"
안정 영역(it=60)     같은 설정   → 10.3 → 18.5°  ★     이롭다
```

`μ` 축이 역전으로 보이던 것도 같은 원인이었다 — **강한 재료일수록 더 심하게 터지고 있었다.**

시험체 자체가 틀린 적도 있다. 자 교정이 −5° 편향을 보고했는데 **측정기가 아니라 합성 원뿔이
문제**였다 — 완벽한 격자의 계단 표면. jitter 를 넣자 사라졌다.

> **검증용 시험체가 비현실적이면 멀쩡한 자를 불량으로 판정한다.**

## 4. 측정법 첫 전환 — 기둥 붕괴 → 경사판

자를 교정하고 나서 재보니 두 판독 방식이 **14° 벌어졌다.** 단면을 찍어보니 원인이 나왔다 —
**퇴적물이 원뿔이 아니었다.** 꼭대기가 평평하고 옆면만 경사져 있었다.

문헌을 열자 더 근본적인 문제가 있었다([papers.md §A-R](../research/papers.md) 신설).

```
기둥 붕괴는 안식각 측정법이 아니다        런아웃·최종높이를 종횡비의 함수로 보는 실험
퇴적물 경사 ≠ 재료의 안식각               종횡비와 기둥반지름/입자지름 비에도 의존한다
```

→ **경사판(tilting box)으로 전환.** 퇴적물 모양을 해석할 필요 없이 "언제 움직이기 시작하는가"
하나만 본다. 기둥 붕괴는 원래 목적인 ★덩어리 붕괴(3-2) 관찰용으로 남겼다.

경사판도 **세 번 다시 만들었다** — 닫힌 상자+속도 판정(벽이 받친다), 열린 수로+변위 판정(퍼짐을
사태로 오인), 그리고 채택된 닫힌 상자+정적 유지.
