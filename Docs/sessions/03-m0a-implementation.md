## 2. 마찰을 세 번 틀렸다

첫 실행이 26.5°를 냈다(목표 34°). 원인을 쫓는 과정에서 **범인이 계속 바뀌었다.**

| # | 증상 | 진단 | 수정 |
|---|---|---|---|
| 1 | 각이 낮다 | `μ`×침투량 클램프가 하중을 못 받는다 | — |
| 2 | 더미가 부풀어오른다 | **즉시 반영이 마찰 되먹임 고리를 만든다** | Gauss-Seidel → Jacobi 평균 |
| 3 | 반복이 마찰 계수가 된다 | **반복마다 예산이 새로 주어진다** | 누적 임펄스 클램프 |
| 4 | `μ` 가 여전히 무반응 | **PBD 의 `v = (p−x)/h` 역산이 진짜 출처** | Sequential Positions |
| 5 | 18층 기둥만 터진다 | **벽 제약만 옛 방식으로 남아 있었다** | `SolveWallsSP` |

**②와 ⑤가 같은 실수다.** 규약을 바꾸면서 일부만 바꿨고, 안 바꾼 쪽이 통째로 오염원이 됐다.
지면은 SP 로 옮기고 벽은 "형틀은 비계니까"라며 남겨둔 판단이 두 번째 하루를 먹었다.

> **솔버 규약은 부분 적용이 안 된다.** 같은 계 안에 있으면 비계도 같은 규약을 따라야 한다.

**결말** — 단일 입자가 `atan(μ)` 를 오차 **1~2°** 로 따라간다. 마찰은 맞다.

## 3. 계기가 먼저 필요했다 — 네 번

물리를 보려던 시도가 번번이 **계기 문제**로 판명됐다. 그때마다 계기를 하나씩 만들었다.

| 계기 | 발견한 것 | 그 전까지 |
|---|---|---|
| **자 교정** (합성 원뿔) | 각도 측정기가 15~34° 에서 **표본 0개** | 26.5° 를 물리로 해석하고 있었다 |
| **안정성 검사** (다지기 후 높이) | 반복 45 미만은 더미가 **터진다** | 터진 더미 위에서 각을 쟀다 |
| **유지 시간 스윕** | 붕괴 판정이 **크리프를 잰다** | −3.5° 를 물리로 해석하고 있었다 |
| **잡음 바닥** (수평 10초) | 반복 45 는 잔류 속력이 **오른다** | 기둥을 통째로 다져봐야 알았다 |

**두 번은 결론의 부호가 뒤집혔다.**

```
"모멘텀이 해롭다"   →  터진 더미에서 낸 결론. 안정 영역에서는 이롭다
"μ 가 역전한다"     →  강한 재료일수록 더 심하게 터지고 있었을 뿐
```

> **"측정값이 이상하다"를 물리로 해석하기 전에 계기를 의심할 것.**
> 잡음 바닥이 가장 값싸다 — 10초 돌려 잔류 속력의 **기울기 부호**만 보면 그 설정의 가부를 안다.

시험체 자체가 틀린 적도 있다. 자 교정이 −5° 편향을 보고했는데 **측정기가 아니라 합성 원뿔이
문제**였다 — 완벽한 격자의 계단 표면. jitter 를 넣자 사라졌다.
**검증용 시험체가 비현실적이면 멀쩡한 자를 불량으로 판정한다.**

## 4. 측정법을 네 번 바꿨다

| 방법 | 왜 버렸나 |
|---|---|
| 기둥 붕괴 | **안식각 측정법이 아니다.** 런아웃을 종횡비의 함수로 보는 실험이고, 퇴적물 경사는 재료 상수가 아니다 |
| 경사판 (θm) | 재는 값이 `θm` 인데 기준 34° 는 `θr` 이었다. 붕괴 판정도 네 번 갈아엎었다 |
| 원통 들어올리기 | **파괴가 국소적이지 않다.** 밑동을 풀면 기둥 전체가 한 번에 무너진다. 계단을 잘게 나눠도 같다 |
| 부어 쌓기 | 현재. 불안정 상태를 애초에 만들지 않는다 |

### 문헌이 두 번 결정적이었다

**① `θm` ≠ `θr`** (Jaeger 1989) — 정지한 더미가 무너지는 각과 흐른 뒤 남는 각은 2~5° 다르다.
`talusDry` 34° 는 **격자 열침식의 정의상** `θr` 이다("옮기기를 멈추는 각").
**기준과 측정 대상이 어긋나 있었다.**

**② 부어 쌓기 기각 근거가 실험실 논리였다** — "쏟는 속도·낙하 높이가 변수라 재현이 안 된다"는
실험실의 문제지 시드 고정 시뮬의 문제가 아니다. 오히려 경사판이 임의 상수가 더 많았다.

## 5. 극단에서만 터지는 결함들

새 장면을 만들 때마다 하나씩 나왔다. 공통점이 있다.

```
벽 제약이 SP 규약 미준수     느린 6층에서는 안 보이고 18층에서 터진다
접촉 여유 상한이 2r          느린 입자는 안 놓치고 2000 cm/s 에서 통과해버린다
생성 높이가 전역 최고점 참조  한 번 튀기 전까지는 안 드러난다
```

**정상 범위에서는 보이지 않다가 극단에서 터진다.**
접촉 여유는 M4(파도가 성을 때림)에서 같은 조건이 되므로 **지금 고친 것이 그때를 산 것**이다.

## 6. 타임박스가 답한 것

3일 상한에 도달했다. 문서 규칙은 *"더 하면 될 것 같다가 아니라 M0가 답을 줬다는 뜻"* 이다.

**다만 답은 "아니오"가 아니었다.**

```
마찰 공식      단일 입자에서 오차 1~2°                    ✓
하중 전달      λn 이 깊이에 선형 (ρgh 대비 0.91~1.00)     ✓
μ 반응성       0.2/0.3/0.4 에서 단조 증가                 ✓
안식각 절대값  ✗ 미확정
```

**상한이 잡아낸 것은 설계 결함이 아니라 측정의 어려움**이었다.

그리고 안식각을 "전제"로 올린 이유 자체가 *"마찰 클램프가 제대로 도는지 확인하는 유일한 방법"*
이었는데, **그 확인은 단일 입자 시험이 이미 해줬다.** 34° 는 게임 튜닝 값이지 뼈대 교정에
반드시 필요한 값이 아니다.

→ **`μ = 0.7` 을 잠정값으로 박고 3-1(터널)로 간다.** 터널은 각도가 아니라 "천장이 버티는가"를
묻는 차단 검증이라 `μ` 정밀도에 답이 뒤집히지 않는다. 거기서 "아니오"면 안식각을 아무리 맞춰도
소용없고, "예"면 그때 마저 닫는다.
