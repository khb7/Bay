# 26.09.10 — 점착 결합과 점착의 자: 벽이 두 번째로 빠졌다

> 결과는 [../design/m0-log.md](../design/m0-log.md) #27~#29, 설계 근거는 [../design/m0-spike.md §2-6](../design/m0-spike.md).
> 이 문서는 **어떻게 흘렀고 무엇을 도중에 뒤집었는가**만.

## 0. 출발점

전날 θr 이 닫혔고, 남은 시험(벽·터널·덩어리)은 전부 점착이 필요했다. 스파이크 코어에 점착 제약이 없었다.
사용자가 논문 근거를 요구해 결정 11개마다 어느 논문이 받치는지 표로 적고 시작했다 (§2-6).

## 1. 결합 제약 — 테스트가 먼저 실패했다 (#27)

솔버를 비운 채 빌드해 매달린 입자가 바닥까지 떨어지는 것을 보고, 채운 뒤 mgα 1.000cm 그대로 서는 것을 봤다. 사슬 2·3 은 위 결합이 끊어졌다.
XPBD 컴플라이언스·인장만·영구 목록·워밍 — 설계대로 한 번에 통과.

## 2. 점착의 자 — 시험체 결함이 넷, 계기 결함이 둘

절토 높이 스윕을 만들자마자 5층이 25cm 아닌 37cm 로 부풀었다(격자 흔들림 초기 겹침). 벽을 열자 12층 높이가 46→81cm 로 솟았다(결합 휴지 길이가 D 아래).
높이는 튄 입자 하나가 대표하고 있었고(98 백분위로), 붕괴 판정은 표피 탈락과 활동면을 못 갈랐다(상단 후퇴로).
그 뒤에야 첫 숫자: H_c 17~29cm, c ≈ 270~430 Pa. Rumpf 상한의 1/4~1/6 — **문헌(Kendall)이 예고한 범위**였다.

## 3. 뒤집힌 가설 ①: 강도가 아니라 연결도

강도를 5배 올려도 H_c 가 30% 밖에 안 올랐다. 거리 제약만인 결합은 결합 1~2개로 매달린 입자의 회전을 못 막는다.
형성 거리 1.05→1.2 로 두 번째 이웃까지 묶자 53cm 까지 전부 섰다. 강도는 무죄, 그물이 물렁했다.

## 4. 뒤집힌 가설 ②: 스프링이 아니라 고원

그런데 서 있는 면이 5~13cm 밖으로 부풀었다 — 젤리. §2-6 ⑦ 에 미리 적어둔 편차였다: 파단 거리에서야 최대 힘이 되는 스프링은 평상 하중에서 6% 씩 늘어난다.
강성 스프링(변형 2%) + 힘 고원(λ 클램프)으로 바꾸자 부풂이 −3~+1cm 로 줄고 H_c 가 강도를 따라갔다.

## 5. 사용자의 개입 — §2-1-a

"substep·반복을 μ 와 같은 축에 놓지 마라." 예산은 34° 를 안 보고 수렴으로, μ 만 34° 로. 그리고 예측: 워밍이 각을 올렸으니 μ 0.15 는 과대평가.
격자를 돌리니 μ 0.3 은 반복 23 부터 플래토, μ 0.15 는 90~180 에서야 플래토(35.4°). **예측대로.** 반복 180·시드 3 으로 μ 0.13.
서브스텝은 예산을 태울수록 나빠진다는 것도 여기서.

## 6. 뒤집힌 가설 ③④⑤⑥: 순환의 원인 찾기 (#29)

교정을 24층 이상으로 올리자 준비 창(새 계기)이 "절토 전부터 1/3 이 움직인다"고 잡았다. 격자 채움을 버리고 상자에 붓기로 바꿨는데
부은 블록은 창마다 35~50% 가 순환하고 감쇠하지 않았다. 여기서 가설 여섯이 차례로 죽었다:

| 가설 | 시험 | 결과 |
|---|---|---|
| 압밀이 느리다 | 감쇠 걸기 | 얼렸다 끄면 다시 순환 — 자립 에너지원 |
| 낮은 μ 의 준안정 | μ 0.5 | 0% (억제되지만 원인 설명은 아님) |
| 워밍 허용 gap · 워밍 · Kv | 각각 | 그대로 |
| 바닥 고정 구 겹침 | 흔들림 0 · 0.1 | 그대로 |
| 벽 마찰 없음 | 벽 μ 0.5 | 50 → 2~16%. 부분 |
| 높이(하중) 자체 | 열린 더미 66cm | 조용 → **상자다** |

소거표를 놓고 코드를 다시 보니 **벽 λ 만 워밍에서 빠져 있었다.** 벽별 λ 배열로 워밍하자 첫 창 0.0%, 충전 0.55, 실행 500→65초.

## 7. 실수 기록

| 실수 | 비용 |
|---|---|
| 벽만 워밍에서 누락 (#18 과 같은 종류) | 진단 실행 열 세트, 반나절 |
| 절토 스윕이 반복 수를 90 으로 고정한 채 `-iterations` 를 무시 — 잘못 잰 실행을 죽이고 재실행 | 15분 |
| 다지기 중력을 계단으로 바꿔 워밍 λ 가 블록을 차올림 (+8.7cm) | 실행 두 번 |

> **"소거표가 다 비면 코드에서 빠진 것을 찾아라."** 이번엔 규약 누락이었고, 지난번(#18)도 그랬다.
