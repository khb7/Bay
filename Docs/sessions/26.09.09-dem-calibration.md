# 26.09.09 — DEM 캘리브레이션: "솔버 상수"를 묻다가 스윕 설계가 바뀌었다

> 코드 변경 없음. 결과는 [../research/terms/dem-calibration.md](../research/terms/dem-calibration.md)·[shear-box.md](../research/terms/shear-box.md),
> 설계 반영은 [../design/m0-spike.md](../design/m0-spike.md) §2-1·§2-1-a.
> 이 문서는 **어떻게 흘렀고 무엇을 도중에 뒤집었는가**만.
>
> 같은 날 [M0-a 크리프와 결정](26.09.09-m0a-creep-and-crystal.md) 세션이 병렬로 돌았다.
> **그 세션의 #25 실측이 이 세션의 마지막 답이 됐다** (§7).

## 0. 출발점

질문 하나였다 — **"m0-spike 에 나오는 '솔버 상수'가 뭔데 `substep`·반복·`μ` 를 그렇게 부르나?"**
용어 확인으로 끝날 줄 알았는데 그 표의 구조 자체가 틀렸다는 데까지 갔다.

## 1. 이름은 맞았다 — 문헌 관행 그대로였다

DEM 쪽은 이런 값을 *calibrated parameter* 라 부르고 *material property* 와 **명시적으로 구분**한다.
모델·입경·접촉식에 딸린 값이라 이식이 안 되기 때문. `μ` 를 물성표가 아니라 솔버 상수 표에 넣은 판단이 관행 그대로였다.

**바뀐 건 근거의 유무다.** 자체 판단이던 것이 **Coetzee (2017) 리뷰**(Powder Tech 310, 인용 340+)를 갖게 됐다.

## 2. 분야가 통째로 있었다

"물성을 이렇게 튜닝하는 논문이 있나?" → **DEM calibration.** 리뷰가 나올 만큼 쌓여 있고,
표준 절차가 §2-1 이 하려던 것과 같았다 — **벌크 캘리브레이션**(파라미터를 미지수로 두고 덩어리 거동에서 역산).

세 갈래가 걸려들었고 각각이 설계 수정 하나씩이 됐다.

```
모호성        Roessler et al. 2019 Part I      → §3
전단 상자      Roessler & Katterfeld 2018       → §4
회전 없음      Wensrich · Estrada · Bardet      → §5·§6·§7
```

## 3. ★ 뒤집힌 것 ① — 미지수가 셋이 아니라 하나였다

[Roessler, Richter, Katterfeld, Will (2019) Part I](https://www.sciencedirect.com/science/article/pii/S0032591018309380) 의
제목이 통째로 이 문제다 — *"Solving the problem of ambiguous parameter combinations"*.
초록의 핵심은 **"자주 무시된다"** 이고, 무시되는 이유가 **34° 가 나오면 성공처럼 보이기 때문**이다.

```
미지수 3 (substep · 반복 · μ)  vs  관측 1 (34°)   →   해가 점이 아니라 2차원 다양체
```

여기까지는 "복수 실험으로 좁힌다"가 답이었다. 그런데 파고들다 **더 근본적인 게 나왔다.**

| | 판정 기준이 어디 |
|---|---|
| `μ` | **바깥에만.** 34° 에 맞춰 역산할 수밖에 없다 |
| `substep`·반복 | **안에.** "수렴했는가" 는 솔버 내부에서 직접 잰다 |

**둘은 애초에 캘리브레이션 대상이 아니었다.** 반복 수를 34° 에 맞춰 튜닝하면
**미수렴을 물리 파라미터로 쓰게 되고**, 미수렴 저항은 **하중 의존**이라
3-0 에서 맞춘 조합이 3-1~3-4 에서 어긋난다. ①이 터지는 구체적 형태가 이것이다.

→ **[§2-1-a 수렴 연구](../design/m0-spike.md)** 신설. `μ` 를 아무 값에나 고정하고 예산만 스윕해
`θr` 이 안 움직이는 플래토를 찾는다. **잔차 임계값을 미리 정할 필요가 없다 — 플래토 자체가 기준이다.**

```
미지수 3 → 1          비용 128회 → 24회
```

§2-1 의 *"어느 조합이 34°를 최소 비용으로 내는지는 스윕이 답한다"* 가 두 일을 한 문장에 묶고 있었다.
Macklin 2019(Small Steps) 각주도 제자리를 찾았다 — **그건 수렴에 관한 주장이지 안식각에 관한 주장이 아니다.**

### ★ 같은 날 병렬 세션이 돌렸고, 예측이 맞았다 (#28)

```
μ = 0.3   반복 23 에서 이미 플래토 (23→180 에서 ±0.5°)
μ = 0.15  플래토 진입이 반복 90~180.  23→360 에서 31.8 → 35.4°

#26 의 "34.4° 통과" 는 반복 90 의 미수렴 저항이 1° 를 깎아준 값이었다
→ μ = 0.15 는 과대평가.   예산 ss 1 × 반복 180 확정,  μ 0.15 → 0.13 재교정
```

**§2-1-a 가 예측한 두 가지가 그대로 나왔다** — ⑴ *"반복을 더 늘리면 34° 를 넘고 μ 0.15 는 과대평가"*,
⑵ 주의 ③ *"플래토가 μ 에 약간 의존한다"*(0.3 은 23, 0.15 는 180).

부수로 둘 더:
- **서브스텝은 예산을 태울수록 나빠진다.** ss 8 에서 불평형비 100배·크리프 10배·각 1~3° 하락.
  #24 의 "서브스텝은 안 듣는다"가 워밍 뒤에도 유효하다
- **시드 산포 ±1°.** 단일 시드로 0.5° 차이를 읽던 것은 **잡음을 읽은 것**이었다. 이후 교정은 시드 3개 평균

## 4. 전단 상자 — 새 카드

[Roessler & Katterfeld (2018)](https://www.sciencedirect.com/science/article/abs/pii/S0032591018300500) 이
업스케일 입자로 시험들의 **크기 불변성**을 비교했다.

- 원통 인상 안식각은 **느린 인상 속도에서만** 불변 → [3-0-D 기각](../design/m0-spike.md)을 문헌이 뒷받침
- **전단 상자는 불변이면서 더 짧다** ← 새 카드

출력이 넷(`φ_peak`·`φ_cv`·`c`·`ψ`)이라 안식각 하나와 성격이 다르고,
**`c[Pa]` 를 직접 읽는다** — B-S3 이 벽 붕괴 높이에서 역산하려던 그 값이다.

그리고 부수 소득 하나: **B-S5 가 걱정한 전단대(40~80cm)가 도메인 안에 들어가는 유일한 실험**이다.
상자 크기가 우리 선택이므로. 100cm³ 상자에 **9천 입자면 된다**(20만 목표의 4.5%).

→ [terms/shear-box.md](../research/terms/shear-box.md) 신설.

## 5. ★ 뒤집힌 것 ② — 회전 없음은 눈금 밖이 아니었다

[A-R3](../research/papers.md) 이 *"문헌 밖. 실측 필요"* 로 남겨둔 칸이다. 세 번 고쳐 썼다.

```
(1)  "구는 μ 를 올려도 20~25°에서 막힌다"        → 틀림. 자유 회전 전제였다
(2)  "회전 없음 = 무한 구름 마찰"                → 틀림. ∞ 가 아니다
(3)  μ_r = μ                                    → 틀림. 2배 어긋났다
```

(3)이 재밌었다. **Estrada 2011 원문을 받아보니 논문이 같은 환산을 이미 하고 있었다** — *"둘레만큼 굴리는 일"* 을 맞춘다.
논문 식 (1) 의 `M_max = μ_r·ℓ·f_n` 에서 **`ℓ` 은 반경이 아니라 분기 벡터(지름)** 다. 내가 `R` 로 잡았다.

```
W_d = 4π·μ_r·R·N   =   W_ours = μ·N·2πR      →     μ_r = μ/2

식 (3):  μ_r = (1/4)·tan(π/2n_s)   →   μ = 0.15 → μ_r = 0.075 → n_s ≈ 5.4
```

**정오각형쯤이다. 눈금 밖이 아니라 눈금 위 한 점이었다.**
부수적으로 **`μ` > 0.29 면 `n_s` < 3** — 형상 유비의 원리적 상한도 나왔다.

> 교훈: **환산이 안 나오면 그 논문이 이미 했는지부터 본다.** 초록만 보고 직접 유도하다 2배를 틀렸고,
> 원문 4페이지에 식이 번호까지 붙어 있었다.

## 6. ★ 뒤집힌 것 ③ — 40~80cm 은 우리 숫자가 아니다

*"회전을 억제하면 국소화된 파괴 패턴이 실험 관찰과 달라진다"*(Bardet 1994)가 무슨 뜻인지 파다가 나왔다.

[B-S5](../research/papers.md) 의 근거인 **Mühlhaus & Vardoulakis (1987) 는 Cosserat 연속체**다.
전단대에 유한한 두께를 주는 **내부 길이 척도가 입자 회전(couple stress)에서 나온다** — 고전 연속체는 두께가 0 이다.
**우리 모델은 그 변수를 갖고 있지 않다.**

양쪽 끝이 다 틀린다는 것도 이때 나왔다:

```
자유회전 + 구름저항 0     띠가 아예 안 생긴다        Iwashita & Oda 1998
자유회전 + 구름저항 유한   실험과 같은 띠             ← 정답 구간
회전 없음  ← 우리         띠가 생기되 실험과 다르다   Bardet 1994
```

**결론(과대 안정)은 살아남지만 근거가 바뀌면 처방이 바뀐다** — "띠가 커서 안 들어간다"면 해상도로 해결되고,
"회전이 없어서"면 해상도로 해결 안 된다. 입자를 반으로 줄여도 회전은 여전히 없다.

→ 그래서 [B-S8 ③](../research/papers.md) 에 **거짓 통과 분기**가 있다.
회전 부재는 `d` 와 무관한 오차라 `D_crit` 이 cm 로 수렴하고, 지금 판정은 그걸 "물리를 풀고 있다"로 읽는다.
**틀린 값으로 수렴한 것을 맞았다고 읽는다.**

## 7. ★★ 반전 — 답이 이미 데이터에 있었다

Bardet 의 *"회전 억제 시 전역 마찰각은 입자간 마찰각의 선형 함수"* 를 근거로
**`tan θr` vs `μ` 선형성 검사**를 제안하고 "스윕 한 번이면 절편이 나온다"고 적었다.

그러다 회전 추가 비용을 계산하려고 문서를 뒤지다 [m0-ruler §4](../design/m0-ruler.md) 에서 **#25 실측**을 봤다.

```
μ 0.10 → 29°    0.15 → 34°    0.20 → 39°    0.30 → 46°

0.10 → 0.20   +5° 씩 정확히      기울기 100°/μ    ← 완벽한 직선
0.20 → 0.30   +7°               기울기  70°/μ    ← 포화 시작

μ = 0 외삽:   θr(0) = 19°
34° = 19°(마찰 무관) + 15°(마찰)                  맞물림 56% / 마찰 44%
```

**제안한 검사를 병렬 세션의 데이터가 이미 통과하고 있었다.** 새 실험이 필요 없었다.

그리고 교차검증 하나 — 포화가 시작되는 `μ` 0.2~0.3 이
§5 의 다각형 사상이 깨지는 지점(`n_s` = 3, `μ` = 0.29)과 겹친다. **완전히 다른 두 경로가 같은 자리를 가리켰다.**

> 기존 표기 *"기하 맞물림 ≈ +25°"* 는 `θ − arctan μ` 라 `μ` 에 따라 23~29° 로 움직인다.
> `μ` 선형 부분과 무관 부분으로 가르면 **19° 가 상수**다.

> ⚠ **위 네 점은 수렴 연구 이전(#25)의 예산에서 잰 값이다.** #28 이후 예산이 ss 1 × 반복 180 으로 바뀌었다.
> 다만 **분해는 살아남는다** — 새 예산의 재스윕(μ 0.11/0.13/0.15 → 31.2/32.9/35.2°, 시드 3 평균)도
> 기울기 ≈ 100°/μ · 절편 ≈ 20° 로 같은 직선이다. **예산이 바뀌어도 "절반 이상이 마찰과 무관"은 유지된다.**

## 8. 회전을 넣으면 얼마인가

"예산이 엄청 오른다"는 통념을 실제 배열로 확인했다.

```
현재  Pos12 + Vel12 + PrevPos12 + InvMass4 + Delta12 + DeltaScale4  = 56B
추가  AngVel 12 + DeltaOmega 12                                     = +24B  (+43%)
      방향(쿼터니언) 0B — 구에는 필요 없다.  관성 0B — 균일 구라 유도 가능
```

접촉 솔브 **1.5~1.7배.** *"엄청"은 아니다.* 다만 두 가지가 붙는다:

- ⚠ **회전만 넣으면 오히려 나빠진다** — Iwashita & Oda 의 "띠가 안 생기는" 구간으로 간다.
  **구름 저항과 반드시 함께.** 다행히 그건 토크에 거는 같은 리턴 매핑이라 거의 공짜다
- 진짜 비용은 런타임이 아니라 **재교정**이다. `μ_eff`(#28 이후 0.13)는 회전이 없어서 나온 값이고,
  회전을 넣으면 `μ_s`·`μ_r` 이 독립 미지수가 되어 **§3 의 모호성이 진짜로 돌아온다** → 전단 상자가 필수가 된다

**지금 낼 돈이 아니다.** 3-2 에서 띠 두께를 재고 8~16d 가 아니면, 그때가 M0-a 의 *"설계를 고친다"* 다.
